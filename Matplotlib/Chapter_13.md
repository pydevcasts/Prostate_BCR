# 📊 راهنمای جامع نمودار باکس پلات (Box Plot) و تشخیص داده‌های پرت

---

## ✨ مقدمه

نمودار **باکس پلات (Box Plot)**، که به نام **نمودار جعبه‌ای** نیز شناخته می‌شود، یکی از قدرتمندترین ابزارهای آماری برای تحلیل و بصری‌سازی توزیع داده‌ها است.
این نمودار خلاصه‌ای از پنج عدد کلیدی — **کمینه، چارک اول، میانه، چارک سوم و بیشینه غیر پرت** — ارائه می‌دهد و برای شناسایی سریع داده‌های پرت بسیار مفید است.

---

## 🎁 ۱. اجزای اصلی نمودار باکس پلات

* 📌 **میانه (Median)**: نقطه‌ای که داده‌ها را به دو نیمه مساوی تقسیم می‌کند.
* 📦 **جعبه (Box)**: محدوده‌ای بین چارک اول (Q1) و چارک سوم (Q3) که ۵۰٪ میانی داده‌ها را شامل می‌شود.
* 📐 **محدوده بین چارکی (IQR)**: برابر است با `Q3 - Q1` و نشان‌دهنده میزان پراکندگی داده‌های مرکزی است.
* 🪶 **ویسکرها (Whiskers)**: خطوطی که از انتهای جعبه به سمت کمینه و بیشینه داده‌های غیر پرت کشیده می‌شوند.
* ⚠️ **داده‌های پرت (Outliers)**: نقاطی که خارج از محدوده عادی `1.5 × IQR` قرار دارند.

---

## ✏️ ۲. محاسبه چارک‌ها

1. ابتدا داده‌ها را به ترتیب صعودی مرتب کنید.
2. موقعیت چارک‌ها با فرمول زیر محاسبه می‌شود:

   ```
   Position = (P / 100) × (n + 1)
   ```
3. اگر موقعیت عدد اعشاری باشد، از **میان‌یابی خطی (Linear Interpolation)** برای محاسبه مقدار چارک استفاده می‌شود.

---

## 🚨 ۳. تشخیص داده‌های پرت

قاعده‌ی تشخیص داده‌های پرت بر اساس ضریب `1.5 × IQR` است:

* 🔻 **مرز پایین (Lower Bound)**

  ```
  Q1 - (1.5 × IQR)
  ```
* 🔺 **مرز بالا (Upper Bound)**

  ```
  Q3 + (1.5 × IQR)
  ```
* هر داده‌ای که کمتر از مرز پایین یا بیشتر از مرز بالا باشد، **پرت (Outlier)** محسوب می‌شود.

---

## 🔍 ۴. تحلیل و تفسیر باکس پلات

* 📈 **توزیع متقارن**: میانه در وسط جعبه و ویسکرها تقریباً هم‌اندازه هستند.
* ➡️ **انحراف به راست (Positive Skewness)**: میانه به سمت چپ (نزدیک Q1) متمایل است و ویسکر بالایی بلندتر است.
* ⬅️ **انحراف به چپ (Negative Skewness)**: میانه به سمت راست (نزدیک Q3) متمایل است و ویسکر پایینی بلندتر است.

---

## 🌍 ۵. کاربردها در دنیای واقعی

* 🏭 **کنترل کیفیت (Quality Control)**: بررسی ثبات فرآیند تولید و شناسایی محصولات معیوب.
* 💰 **تحلیل مالی (Financial Analysis)**: بررسی بازده دارایی‌ها و تشخیص نوسانات (Volatility).
* 🧬 **بیوانفورماتیک (Bioinformatics)**: مقایسه توزیع داده‌های ژنتیکی و بیوشیمیایی بین گروه‌ها.

---

## ⚙️ ۶. نکات تکمیلی و ملاحظات

* ضریب `1.5` استاندارد است، اما در برخی کاربردها از `3.0` برای شناسایی **پرت‌های شدید (Extreme Outliers)** استفاده می‌شود.
* در نمونه‌های کوچک، برآورد چارک‌ها با عدم‌قطعیت بیشتری همراه است.
* برای **مقایسه چندین گروه داده**، باکس پلات ابزاری فوق‌العاده کارآمد است.

## 🧠  مثال

می‌خواهیم باکس پلات نمرات چند دانش‌آموز را ترسیم کنیم تا **میانه، چارک‌ها و داده‌های پرت** را مشاهده کنیم.

---

## 💻 کد پایتون کامل و توضیح‌دار

```python
# 📦 نصب کتابخانه‌ها (در صورت نیاز)
# !pip install matplotlib seaborn

import matplotlib.pyplot as plt
import seaborn as sns

# 🎓 داده نمونه (نمرات دانش‌آموزان)
scores = [45, 50, 52, 55, 58, 60, 62, 63, 65, 66, 68, 70, 72, 74, 76, 78, 80, 85, 90, 100]

# 📊 ایجاد نمودار باکس پلات
plt.figure(figsize=(6, 4))
sns.boxplot(data=scores, color="skyblue", width=0.4)

# ✨ تنظیمات ظاهری نمودار
plt.title("📦 نمودار باکس پلات نمرات دانش‌آموزان", fontsize=14)
plt.ylabel("نمره", fontsize=12)
plt.grid(axis='y', linestyle='--', alpha=0.6)

# 🧩 نمایش نمودار
plt.show()
```

---

## 📈 خروجی (توضیح)

بعد از اجرای کد، نموداری به شما نشان داده می‌شود که شامل موارد زیر است:

* 📍 **خط وسط جعبه (میانه)** → مقدار متوسط داده‌ها (مثلاً حدود 70)
* 🟦 **خود جعبه** → محدوده بین چارک اول (Q1) و چارک سوم (Q3)
* 🔹 **خطوط بیرونی (ویسکرها)** → داده‌های غیر پرت نزدیک به حداقل و حداکثر
* 🔴 **نقاط جدا (Outliers)** → نمراتی که از بقیه فاصله دارند (مثلاً 100 ممکن است پرت باشد)

---

## 🧩 نکته آموزشی

برای مشاهده حدود چارک‌ها و IQR به‌صورت عددی، می‌توانید از NumPy استفاده کنید:

```python
import numpy as np

Q1 = np.percentile(scores, 25)
Q2 = np.percentile(scores, 50)
Q3 = np.percentile(scores, 75)
IQR = Q3 - Q1

print("Q1 =", Q1)
print("Median (Q2) =", Q2)
print("Q3 =", Q3)
print("IQR =", IQR)
```
