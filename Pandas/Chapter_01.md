### 🔹 ۱. مقدمه

کتابخانه **Pandas** یکی از مهم‌ترین ابزارها در حوزه‌ی **علم داده (Data Science)** و **تحلیل داده‌ها** است.
این کتابخانه به ما کمک می‌کند تا داده‌ها را:

* بخوانیم (از فایل‌های CSV, Excel, SQL و …)
* بررسی و تحلیل کنیم
* پاک‌سازی کنیم (Data Cleaning)
* گروه‌بندی و خلاصه‌سازی کنیم
* و در نهایت روی داده‌ها تجسم‌سازی انجام دهیم.

Pandas در واقع پلی است بین داده‌های خام و مدل‌های یادگیری ماشین.

---

### 🔹 ۲. نصب Pandas

برای نصب پانداس کافی است در محیط **ترمینال یا Jupyter Notebook** دستور زیر را اجرا کنید:

```bash
pip install pandas
```

📌 اگر از محیط **Anaconda** استفاده می‌کنید، پانداس به طور پیش‌فرض نصب است.

---

### 🔹 ۳. وارد کردن Pandas در پایتون

```python
import pandas as pd
```

📌 به طور قراردادی، همیشه پانداس را با نام کوتاه **pd** وارد می‌کنیم.

---

### 🔹 ۴. بررسی نسخه Pandas

```python
import pandas as pd

print(pd.__version__)
```

📌 این دستور نسخه نصب‌شده Pandas را نمایش می‌دهد.

---

### 🔹 ۵. ساختار کلی داده‌ها در Pandas

Pandas دو ساختار داده‌ای اصلی دارد:

1. **Series** → یک آرایه یک‌بعدی (مشابه لیست یا ستون در جدول)
2. **DataFrame** → یک جدول دوبعدی (شامل ردیف‌ها و ستون‌ها)

این دو ساختار، پایه و اساس کار با داده‌ها در پانداس هستند و در فصل‌های بعدی آن‌ها را دقیق بررسی خواهیم کرد.
