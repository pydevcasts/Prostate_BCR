### 🔹 ۱. معرفی Series

**Series** در Pandas یک **آرایه یک‌بعدی** است که شامل:

* داده‌ها (Data)
* ایندکس (Index)

می‌شود.
می‌توانید آن را مثل یک ستون از جدول در نظر بگیرید.

---

### 🔹 ۲. ساخت Series از لیست

```python
import pandas as pd

data = [10, 20, 30, 40, 50]
s = pd.Series(data)

print(s)
```

📌 خروجی:

```
0    10
1    20
2    30
3    40
4    50
dtype: int64
```

* ستون سمت چپ **ایندکس** است.
* ستون سمت راست **مقادیر داده‌ها** هستند.

---

### 🔹 ۳. تعیین ایندکس دلخواه

```python
s = pd.Series([10, 20, 30], index=["a", "b", "c"])
print(s)
```

📌 خروجی:

```
a    10
b    20
c    30
dtype: int64
```

اینجا ایندکس‌ها را خودمان تعیین کردیم.

---

### 🔹 ۴. دسترسی به داده‌ها (Indexing)

```python
print(s["a"])    # دسترسی با برچسب ایندکس
print(s[1])      # دسترسی با موقعیت ایندکس
```

📌 خروجی:

```
10
20
```

---

### 🔹 ۵. عملیات ریاضی روی Series

```python
s = pd.Series([1, 2, 3, 4])

print(s + 10)    # اضافه کردن عدد به همه مقادیر
print(s * 2)     # ضرب همه مقادیر
print(s.mean())  # میانگین
print(s.max())   # بیشترین مقدار
```

📌 خروجی:

```
0    11
1    12
2    13
3    14
dtype: int64

0    2
1    4
2    6
3    8
dtype: int64

2.5
4
```

---

### 🔹 ۶. ساخت Series از دیکشنری

```python
data = {"Ali": 85, "Sara": 90, "Reza": 75}
grades = pd.Series(data)

print(grades)
```

📌 خروجی:

```
Ali     85
Sara    90
Reza    75
dtype: int64
```
