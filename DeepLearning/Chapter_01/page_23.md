## 🧠 فصل ۱۹ 🎨 مدل‌های مولد (Generative Models)؛ خلق داده از دل یادگیری عمیق

تا اینجا بیشتر مدل‌هایی که بررسی کردیم در دسته مدل‌های «تمایزدهنده» (Discriminative) قرار می‌گرفتند؛ یعنی هدفشان تشخیص یا پیش‌بینی یک برچسب بود. برای مثال، مدل احساسات یک متن را مثبت یا منفی تشخیص می‌داد یا یک تصویر را در یکی از کلاس‌ها قرار می‌داد. اما یک سؤال مهم‌تر وجود دارد: آیا می‌توان مدلی ساخت که خودش داده تولید کند؟

مدل‌های مولد دقیقاً برای همین هدف طراحی شده‌اند. این مدل‌ها به جای اینکه فقط یاد بگیرند «این چیست»، یاد می‌گیرند «این چگونه ساخته می‌شود». در نتیجه می‌توانند داده‌های جدیدی تولید کنند که شبیه داده‌های واقعی هستند.

## 🧠 ایده اصلی مدل‌های مولد

در مدل‌های مولد، هدف یادگیری توزیع احتمال داده‌ها است. یعنی مدل تلاش می‌کند بفهمد داده‌های واقعی چگونه در فضای آماری توزیع شده‌اند.

اگر داده واقعی را با (x) نشان دهیم، هدف مدل یادگیری توزیع زیر است:

[
P(x)
]

یا در حالت شرطی:

[
P(x|y)
]

به این معنا که مدل یاد می‌گیرد چگونه داده‌های جدیدی تولید کند که از نظر آماری شبیه داده‌های واقعی باشند.

برای مثال، اگر مدل روی تصاویر گربه آموزش دیده باشد، می‌تواند تصویر یک گربه جدید تولید کند که قبلاً هرگز وجود نداشته است، اما کاملاً واقعی به نظر می‌رسد.

---

## 🧠 چرا مدل‌های مولد مهم هستند؟

مدل‌های مولد یکی از مهم‌ترین شاخه‌های یادگیری عمیق هستند زیرا توانایی «خلق» دارند. این توانایی باعث شده کاربردهای بسیار گسترده‌ای در صنعت پیدا کنند.

در تولید تصویر، مدل‌های مولد می‌توانند تصاویر واقعی از چهره انسان، حیوانات یا اشیاء تولید کنند. در تولید متن، می‌توانند مقاله، داستان یا پاسخ‌های هوشمند تولید کنند. در حوزه پزشکی، می‌توانند داده‌های مصنوعی برای آموزش مدل‌های دیگر تولید کنند.

## 🧠 انواع مدل‌های مولد

سه خانواده اصلی از مدل‌های مولد در یادگیری عمیق وجود دارد:

* Autoencoderها (به‌ویژه Variational Autoencoder)
* GANها (Generative Adversarial Networks)
* مدل‌های مبتنی بر ترنسفورمر (در نسخه‌های جدیدتر مانند LLMها)

در این فصل ابتدا دو مدل کلاسیک VAE و GAN را بررسی می‌کنیم.

---

## 🧠 Autoencoder چیست؟

Autoencoder یک شبکه عصبی است که هدف آن فشرده‌سازی و سپس بازسازی داده‌ها است. این مدل از دو بخش تشکیل شده است:

* Encoder: داده را به یک نمایش فشرده تبدیل می‌کند
* Decoder: داده فشرده را دوباره بازسازی می‌کند

هدف این است که خروجی تا حد ممکن شبیه ورودی باشد.

📷 [تصویر اینجا قرار گیرد: ساختار Encoder → Latent Space → Decoder]

---

## 🔢 ایده ریاضی Autoencoder

اگر ورودی را (x) و بازسازی را (\hat{x}) نشان دهیم، هدف کاهش خطا است:

[
L = ||x - \hat{x}||^2
]

در اینجا:

* (x): داده اصلی
* (\hat{x}): داده بازسازی‌شده
* (L): خطای بازسازی

هرچه این مقدار کمتر باشد، مدل بهتر توانسته داده را یاد بگیرد.

---

## 🧠 Variational Autoencoder (VAE)

VAE نسخه پیشرفته Autoencoder است. تفاوت اصلی این است که در VAE فضای نهفته (Latent Space) به صورت احتمالاتی مدل‌سازی می‌شود.

به جای اینکه یک بردار ثابت تولید شود، مدل میانگین و واریانس تولید می‌کند و از آن نمونه‌برداری انجام می‌دهد.

فرمول اصلی:

[
z \sim \mathcal{N}(\mu, \sigma^2)
]

این کار باعث می‌شود فضای نهفته پیوسته باشد و بتوان از آن برای تولید داده‌های جدید استفاده کرد.

---

## ⚔️ GAN چیست؟

GAN یا شبکه‌های مولد تخاصمی یکی از انقلابی‌ترین مدل‌های مولد است. این مدل از دو شبکه تشکیل شده است:

* Generator (مولد)
* Discriminator (تشخیص‌دهنده)

مولد تلاش می‌کند داده جعلی تولید کند، در حالی که تشخیص‌دهنده سعی می‌کند واقعی یا جعلی بودن داده را تشخیص دهد. این دو شبکه در یک بازی رقابتی با هم آموزش می‌بینند.

---

## 🎯 تابع هدف GAN

هدف GAN به صورت زیر تعریف می‌شود:

[
\min_G \max_D V(D,G)
]

این رابطه نشان می‌دهد:

* Generator تلاش می‌کند خطا را کم کند
* Discriminator تلاش می‌کند آن را زیاد کند

این رقابت باعث بهبود هم‌زمان هر دو شبکه می‌شود.

## 💻 پروژه عملی فصل: ساخت GAN ساده برای تولید اعداد دست‌نویس (MNIST)

در این پروژه یک GAN ساده برای تولید ارقام دست‌نویس پیاده‌سازی می‌کنیم.

```python id="gan1"
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, transforms
```

---

## 📦 بارگذاری دیتاست MNIST

```python id="gan2"
transform = transforms.Compose([
    transforms.ToTensor()
])

dataset = datasets.MNIST(
    root="./data",
    train=True,
    transform=transform,
    download=True
)

dataloader = torch.utils.data.DataLoader(
    dataset,
    batch_size=64,
    shuffle=True
)
```

---

## 🧠 تعریف Generator

```python id="gan3"
class Generator(nn.Module):

    def __init__(self):

        super().__init__()

        self.model = nn.Sequential(
            nn.Linear(100, 256),
            nn.ReLU(),
            nn.Linear(256, 784),
            nn.Tanh()
        )

    def forward(self, z):

        return self.model(z)
```

---

## 🧠 تعریف Discriminator

```python id="gan4"
class Discriminator(nn.Module):

    def __init__(self):

        super().__init__()

        self.model = nn.Sequential(
            nn.Linear(784, 256),
            nn.ReLU(),
            nn.Linear(256, 1),
            nn.Sigmoid()
        )

    def forward(self, x):

        return self.model(x)
```

---

## ⚙️ آموزش GAN

```python id="gan5"
generator = Generator()
discriminator = Discriminator()

criterion = nn.BCELoss()

optim_g = optim.Adam(generator.parameters(), lr=0.0002)
optim_d = optim.Adam(discriminator.parameters(), lr=0.0002)
```

---

## 🔄 حلقه آموزش

```python id="gan6"
for epoch in range(3):

    for real, _ in dataloader:

        real = real.view(-1, 784)

        batch_size = real.size(0)

        # -----------------
        # Train Discriminator
        # -----------------

        noise = torch.randn(batch_size, 100)
        fake = generator(noise)

        loss_real = criterion(discriminator(real), torch.ones(batch_size, 1))
        loss_fake = criterion(discriminator(fake.detach()), torch.zeros(batch_size, 1))

        loss_d = loss_real + loss_fake

        optim_d.zero_grad()
        loss_d.backward()
        optim_d.step()

        # -----------------
        # Train Generator
        # -----------------

        noise = torch.randn(batch_size, 100)
        fake = generator(noise)

        loss_g = criterion(discriminator(fake), torch.ones(batch_size, 1))

        optim_g.zero_grad()
        loss_g.backward()
        optim_g.step()
```
