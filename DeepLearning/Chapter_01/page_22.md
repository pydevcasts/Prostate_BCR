## 🧠 فصل ۱۸ ⚙️ فاین‌تیونینگ (Fine-Tuning) و یادگیری انتقالی در مدل‌های زبانی بزرگ

مدل‌های زبانی بزرگ مانند GPT و BERT پس از آموزش اولیه روی حجم عظیمی از داده‌ها، یک درک عمومی از زبان به دست می‌آورند. اما در دنیای واقعی، هر مسئله نیازهای خاص خودش را دارد. برای مثال، یک مدل عمومی ممکن است زبان را خوب بفهمد، اما برای تشخیص احساس مشتریان یک فروشگاه آنلاین یا تحلیل گزارش‌های پزشکی به تنظیمات اختصاصی نیاز دارد.

اینجا مفهوم فاین‌تیونینگ (Fine-Tuning) وارد می‌شود. فاین‌تیونینگ یعنی استفاده از یک مدل از پیش آموزش‌دیده و ادامه آموزش آن روی یک دیتاست کوچک‌تر و تخصصی‌تر تا مدل برای یک وظیفه خاص بهینه شود. این کار باعث می‌شود بدون نیاز به آموزش از صفر، به عملکرد بسیار بالایی برسیم.

## 🧠 یادگیری انتقالی چیست؟

یادگیری انتقالی (Transfer Learning) مفهومی گسترده‌تر از فاین‌تیونینگ است. در این روش، دانشی که مدل در یک مسئله یاد گرفته است، به مسئله‌ای دیگر منتقل می‌شود.

برای مثال، مدلی که روی زبان عمومی آموزش دیده است، می‌تواند در تحلیل احساسات، دسته‌بندی متن، یا حتی سیستم‌های پرسش و پاسخ استفاده شود. نکته مهم این است که دیگر نیازی نیست مدل از صفر یاد بگیرد؛ بلکه از دانش قبلی خود استفاده می‌کند.

در واقع، مدل‌های بزرگ مانند GPT و BERT نوعی «دانش عمومی از زبان» را یاد می‌گیرند و سپس در پروژه‌های مختلف با تغییرات کوچک قابل استفاده می‌شوند.

---

## 🔢 ایده ریاضی فاین‌تیونینگ

اگر وزن‌های مدل آموزش‌دیده را با ( \theta_{pre} ) نمایش دهیم، هدف فاین‌تیونینگ به‌صورت زیر است:

[
\theta = \theta_{pre} - \eta \nabla L_{task}
]

در این رابطه:

* ( \theta_{pre} ) وزن‌های مدل از پیش آموزش‌دیده است.
* ( L_{task} ) تابع هزینه مربوط به وظیفه جدید است.
* ( \eta ) نرخ یادگیری است.

نکته مهم این است که مدل دیگر از صفر شروع نمی‌کند، بلکه تنها اصلاحات کوچکی روی دانش قبلی انجام می‌دهد.

## 🧪 مثال عددی ساده

فرض کنید یک وزن در مدل پیش‌آموزش‌دیده برابر باشد با:

[
\theta_{pre} = 0.80
]

گرادیان محاسبه‌شده برای وظیفه جدید برابر است با:

[
\nabla L = 0.10
]

و نرخ یادگیری:

[
\eta = 0.5
]

در این صورت:

[
\theta = 0.80 - (0.5 \times 0.10)
]

ابتدا:

[
0.5 \times 0.10 = 0.05
]

سپس:

[
\theta = 0.75
]

این نشان می‌دهد که مدل فقط به‌صورت جزئی خود را با وظیفه جدید تطبیق داده است.

---

## ⚙️ انواع روش‌های فاین‌تیونینگ

در عمل، فاین‌تیونینگ به چند شکل انجام می‌شود. در روش کامل (Full Fine-Tuning)، تمام وزن‌های مدل دوباره آموزش داده می‌شوند. این روش دقیق اما بسیار پرهزینه است.

در روش سبک‌تر، فقط بخشی از لایه‌ها آموزش داده می‌شوند و بقیه ثابت می‌مانند. این کار باعث کاهش مصرف منابع و جلوگیری از overfitting می‌شود.

در روش‌های مدرن‌تر مانند LoRA (Low-Rank Adaptation)، به جای تغییر مستقیم وزن‌ها، تنها ماتریس‌های کوچکی به مدل اضافه می‌شوند که یادگیری را بسیار سبک‌تر و سریع‌تر می‌کنند.

## 🧠 چرا فاین‌تیونینگ مهم است؟

یکی از دلایل اصلی اهمیت فاین‌تیونینگ، کاهش هزینه آموزش است. آموزش یک مدل بزرگ از صفر ممکن است میلیون‌ها دلار هزینه داشته باشد، اما فاین‌تیونینگ همان مدل روی یک دیتاست کوچک، بسیار ارزان‌تر و سریع‌تر انجام می‌شود.

دلیل دوم، عملکرد بهتر در وظایف خاص است. مدل عمومی ممکن است در بسیاری از حوزه‌ها خوب باشد، اما برای یک کاربرد خاص نیاز به تخصص دارد. فاین‌تیونینگ این تخصص را فراهم می‌کند.

دلیل سوم، استفاده از دانش عمومی مدل است. مدل‌های بزرگ قبلاً زبان، ساختار جملات و مفاهیم عمومی را یاد گرفته‌اند و فقط نیاز به تطبیق دارند.

## 💻 پروژه عملی فصل: فاین‌تیونینگ BERT برای تحلیل احساسات

در این پروژه از مدل آماده BERT استفاده می‌کنیم و آن را برای تحلیل احساسات فاین‌تیون می‌کنیم.

```python id="ft1"
from transformers import BertTokenizer, BertForSequenceClassification
from transformers import Trainer, TrainingArguments
from datasets import load_dataset

dataset = load_dataset("imdb")

tokenizer = BertTokenizer.from_pretrained("bert-base-uncased")
```

---

## 🔤 پیش‌پردازش داده‌ها

```python id="ft2"
def tokenize(batch):

    return tokenizer(
        batch["text"],
        padding=True,
        truncation=True
    )

dataset = dataset.map(tokenize, batched=True)
dataset.set_format("torch")
```

---

## 🧠 تعریف مدل

```python id="ft3"
model = BertForSequenceClassification.from_pretrained(
    "bert-base-uncased",
    num_labels=2
)
```

---

## ⚙️ تنظیمات آموزش

```python id="ft4"
training_args = TrainingArguments(
    output_dir="./results",
    num_train_epochs=2,
    per_device_train_batch_size=8,
    evaluation_strategy="epoch",
    logging_dir="./logs"
)
```

---

## 🚀 اجرای آموزش

```python id="ft5"
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=dataset["train"],
    eval_dataset=dataset["test"]
)

trainer.train()
```
