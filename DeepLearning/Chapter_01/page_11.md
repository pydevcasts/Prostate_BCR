# 📂 مفهوم Dataset

در PyTorch، Dataset ساختاری است که نحوه دسترسی به داده‌ها را تعریف می‌کند.

به زبان ساده، Dataset به PyTorch می‌گوید:

* داده‌ها کجا قرار دارند.
* چگونه باید خوانده شوند.
* هر نمونه شامل چه اطلاعاتی است.

برای مثال در یک پروژه طبقه‌بندی تصاویر، هر نمونه می‌تواند شامل یک تصویر و برچسب مربوط به آن باشد.

Dataset مانند پلی میان داده‌های خام و مدل یادگیری عمیق عمل می‌کند.

---

# 🔍 ساخت Dataset سفارشی

یکی از مزایای مهم PyTorch امکان ایجاد Dataset سفارشی است.

برای این کار باید از کلاس Dataset ارث‌بری کنیم.

نمونه ساده:

```python
from torch.utils.data import Dataset

class MyDataset(Dataset):

    def __init__(self):
        self.data = [1, 2, 3, 4]
        self.labels = [0, 1, 0, 1]

    def __len__(self):
        return len(self.data)

    def __getitem__(self, idx):
        return self.data[idx], self.labels[idx]
```

در این مثال دو تابع بسیار مهم تعریف شده‌اند.

تابع `__len__` تعداد نمونه‌ها را مشخص می‌کند و تابع `__getitem__` نحوه دسترسی به هر نمونه را تعیین می‌نماید.

---

# ⚙️ تابع **len**

این تابع تعداد کل نمونه‌های موجود در Dataset را بازمی‌گرداند.

برای مثال:

```python
dataset = MyDataset()

print(len(dataset))
```

خروجی:

```python

```

خواهد بود.

این تابع توسط PyTorch برای مدیریت پیمایش داده‌ها مورد استفاده قرار می‌گیرد.

# 📥 تابع **getitem**

# 📊 مفهوم Batch

در بسیاری از پروژه‌ها نمی‌توان کل داده‌ها را یکجا به مدل داد.

فرض کنید یک میلیون تصویر در اختیار داریم. پردازش هم‌زمان همه آن‌ها حافظه عظیمی نیاز دارد.

راه‌حل استفاده از Batch است.

در این روش داده‌ها به گروه‌های کوچک‌تر تقسیم می‌شوند.

برای مثال:

[
Batch\ Size = 32
]

به این معنا است که در هر مرحله آموزش تنها ۳۲ نمونه وارد شبکه می‌شوند.

این روش هم مصرف حافظه را کاهش می‌دهد و هم فرآیند یادگیری را پایدارتر می‌کند.

# 🔀 Shuffling یا درهم‌ریزی داده‌ها

یکی از اشتباهات رایج در آموزش مدل‌ها استفاده از داده‌های مرتب‌شده است.

فرض کنید تمام تصاویر گربه در ابتدای مجموعه داده و تمام تصاویر سگ در انتهای آن قرار گرفته باشند.

در چنین شرایطی مدل ممکن است الگوهای نادرستی یاد بگیرد.

به همین دلیل معمولاً قبل از هر دوره آموزشی داده‌ها به‌صورت تصادفی مخلوط می‌شوند.

در PyTorch این کار تنها با یک پارامتر انجام می‌شود:

```python

```

این ویژگی در اکثر پروژه‌های یادگیری عمیق فعال است.

# 🖼️ تبدیل داده‌ها (Transforms)

# 📈 نرمال‌سازی داده‌ها

نرمال‌سازی یکی از مهم‌ترین مراحل پیش‌پردازش است.

اگر ویژگی‌ها در مقیاس‌های بسیار متفاوت قرار داشته باشند، آموزش مدل دشوار می‌شود.

برای مثال:

* سن بین ۰ تا ۱۰۰
* درآمد بین ۰ تا ۱۰۰۰۰۰

در چنین شرایطی ویژگی درآمد بر آموزش مدل غالب خواهد شد.

نرمال‌سازی باعث می‌شود تمام ویژگی‌ها در محدوده‌های مشابه قرار گیرند.

فرمول رایج نرمال‌سازی:

[
x'=
\frac{x-\mu}{\sigma}
]

که در آن:

* (x) مقدار اولیه است.
* (\mu) میانگین داده‌ها است.
* (\sigma) انحراف معیار است.

---

## 🔢 مثال عددی نرمال‌سازی

فرض کنید:

[
x=80
]

[
\mu=50
]

[
\sigma=10
]

داریم:

[
x'=
\frac{80-50}{10}
]

[
x'=3
]

بنابراین مقدار نرمال‌شده برابر ۳ خواهد بود.

# 💻 پروژه عملی فصل: Dataset و DataLoader سفارشی

در این پروژه یک Dataset ساده ایجاد کرده و آن را توسط DataLoader بارگذاری می‌کنیم.

```python
import torch
from torch.utils.data import Dataset
from torch.utils.data import DataLoader

class StudentDataset(Dataset):

    def __init__(self):
        self.features = [
            [18, 15],
            [20, 18],
            [22, 20],
            [25, 22]
        ]

        self.labels = [
            0,
            1,
            1,
            1
        ]

    def __len__(self):
        return len(self.features)

    def __getitem__(self, idx):

        x = torch.tensor(
            self.features[idx],
            dtype=torch.float32
        )

        y = torch.tensor(
            self.labels[idx]
        )

        return x, y

dataset = StudentDataset()

loader = DataLoader(
    dataset,
    batch_size=2,
    shuffle=True
)

for x, y in loader:
    print(x)
    print(y)
```

---

## 🔍 توضیح پروژه

در این مثال داده‌های مربوط به چند دانشجو تعریف شده‌اند. Dataset وظیفه نگهداری و ارائه داده‌ها را بر عهده دارد. سپس DataLoader داده‌ها را در دسته‌های دو عضوی بارگذاری می‌کند.

استفاده از DataLoader در پروژه‌های واقعی باعث می‌شود حتی مجموعه داده‌های بسیار بزرگ نیز به شکل کارآمد مدیریت شوند.
