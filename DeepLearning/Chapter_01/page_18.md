## 🧠 معماری LSTM؛ حافظه‌ای برای وابستگی‌های بلندمدت

پس از آنکه محدودیت‌های RNNهای کلاسیک آشکار شد، پژوهشگران به این نتیجه رسیدند که شبکه باید مکانیزمی داشته باشد تا بتواند به‌صورت کنترل‌شده اطلاعات مهم را حفظ و اطلاعات غیرضروری را حذف کند. این ایده به تولد معماری حافظه بلندمدت کوتاه‌مدت (Long Short-Term Memory) یا LSTM منجر شد.

برخلاف یک سلول RNN معمولی که تنها یک حالت پنهان را نگهداری می‌کند، سلول LSTM دارای یک مسیر حافظه اختصاصی است که می‌تواند اطلاعات را برای مدت طولانی حفظ کند. این ویژگی باعث می‌شود مدل بتواند وابستگی‌های دور را بهتر یاد بگیرد. برای مثال در یک متن چندصدکلمه‌ای، مدل قادر خواهد بود اطلاعات ابتدای متن را هنگام پردازش انتهای متن همچنان در اختیار داشته باشد.

نکته مهم این است که LSTM صرفاً اطلاعات را ذخیره نمی‌کند، بلکه تصمیم می‌گیرد چه چیزی ارزش نگهداری دارد. این تصمیم‌گیری از طریق مجموعه‌ای از دروازه‌ها انجام می‌شود که جریان اطلاعات را کنترل می‌کنند.

## 🚪 دروازه فراموشی

نخستین مؤلفه مهم در LSTM دروازه فراموشی (Forget Gate) است. این بخش مشخص می‌کند چه اطلاعاتی از حافظه قبلی حفظ شوند و چه اطلاعاتی حذف شوند.

رابطه ریاضی این دروازه به شکل زیر است:

[
f_t
===

\sigma
(
W_f
[h_{t-1},x_t]
+
b_f
)
]

در این رابطه:

* (f_t) خروجی دروازه فراموشی است.
* (h_{t-1}) حالت پنهان مرحله قبل است.
* (x_t) ورودی فعلی است.
* (W_f) ماتریس وزن‌ها است.
* (b_f) بایاس است.
* (\sigma) تابع سیگموید است.

از آنجا که خروجی سیگموید بین صفر و یک قرار می‌گیرد، هر مقدار مشخص می‌کند چه سهمی از اطلاعات قبلی نگهداری شود.

اگر خروجی یک نورون برابر ۱ باشد، اطلاعات آن کاملاً حفظ می‌شود. اگر برابر صفر باشد، اطلاعات آن حذف خواهد شد.

برای مثال اگر مقدار حافظه قبلی برابر ۱۰ و خروجی دروازه فراموشی برابر ۰٫۸ باشد:

[
10\times0.8
===========

8
]

بنابراین ۸۰ درصد اطلاعات حفظ شده است.

## 📥 دروازه ورودی

پس از مشخص شدن اطلاعاتی که باید فراموش شوند، نوبت به تعیین اطلاعات جدید می‌رسد.

دروازه ورودی تصمیم می‌گیرد چه اطلاعاتی وارد حافظه شوند.

این مرحله شامل دو بخش است. ابتدا اهمیت اطلاعات جدید تعیین می‌شود:

[
i_t
===

\sigma
(
W_i
[h_{t-1},x_t]
+
b_i
)
]

سپس محتوای جدیدی که قرار است وارد حافظه شود محاسبه می‌شود:

[
\tilde{C_t}
===========

tanh
(
W_c
[h_{t-1},x_t]
+
b_c
)
]

در اینجا:

* (i_t) اهمیت اطلاعات جدید را مشخص می‌کند.
* (\tilde{C_t}) حافظه کاندید است.
* تابع تانژانت هیپربولیک مقادیر را بین ۱- و ۱ محدود می‌کند.

## 💾 به‌روزرسانی حافظه سلول

اکنون حافظه جدید ساخته می‌شود.

فرمول اصلی حافظه به شکل زیر است:

[
C_t
===

f_t
\times
C_{t-1}
+
i_t
\times
\tilde{C_t}
]

این رابطه یکی از مهم‌ترین فرمول‌های کل یادگیری عمیق محسوب می‌شود.

در این معادله:

* بخش اول اطلاعات قبلی را حفظ می‌کند.
* بخش دوم اطلاعات جدید را اضافه می‌کند.

برای درک بهتر فرض کنید:

[
C_{t-1}=10
]

[
f_t=0.8
]

[
i_t=0.6
]

[
\tilde{C_t}=5
]

در این صورت خواهیم داشت:

[
C_t
===

(0.8\times10)
+
(0.6\times5)
]

ابتدا:

[
0.8\times10=8
]

سپس:

[
0.6\times5=3
]

در نتیجه:

[
C_t=11
]

بنابراین حافظه جدید برابر ۱۱ خواهد شد.

## 📤 دروازه خروجی

در نهایت باید مشخص شود چه اطلاعاتی از حافظه به خروجی ارسال شوند.

رابطه دروازه خروجی:

[
o_t
===

\sigma
(
W_o
[h_{t-1},x_t]
+
b_o
)
]

و خروجی نهایی:

[
h_t
===

o_t
\times
tanh(C_t)
]

به این ترتیب مدل تنها بخشی از حافظه را در اختیار لایه‌های بعدی قرار می‌دهد.

## ⚡ معماری GRU

اگرچه LSTM بسیار قدرتمند بود، اما تعداد پارامترهای آن نسبتاً زیاد است. به همین دلیل معماری دیگری به نام واحد بازگشتی دروازه‌دار (Gated Recurrent Unit) یا GRU معرفی شد.

GRU بسیاری از مزایای LSTM را حفظ می‌کند اما ساختار ساده‌تری دارد. در این معماری حافظه سلولی مستقل حذف شده و تنها دو دروازه اصلی وجود دارد:

* دروازه بازنشانی
* دروازه به‌روزرسانی

این سادگی باعث می‌شود آموزش GRU معمولاً سریع‌تر از LSTM انجام شود و در بسیاری از مسائل نیز عملکردی بسیار نزدیک به آن ارائه دهد.

## 🔤 تبدیل متن به بردار عددی

شبکه‌های عصبی قادر به پردازش مستقیم متن نیستند. بنابراین ابتدا باید واژه‌ها به شناسه‌های عددی تبدیل شوند.

```python
from torchtext.vocab import build_vocab_from_iterator

def yield_tokens(data):

    for item in data:
        yield item["text"].split()

vocab = build_vocab_from_iterator(
    yield_tokens(dataset["train"]),
    specials=["<unk>"]
)

vocab.set_default_index(
    vocab["<unk>"]
)
```

در این مرحله فرهنگ واژگان ساخته می‌شود و هر کلمه یک شناسه عددی دریافت می‌کند.

## 🧠 ساخت مدل LSTM

اکنون مدل اصلی را تعریف می‌کنیم.

```python
import torch
import torch.nn as nn

class SentimentLSTM(nn.Module):

    def __init__(self,
                 vocab_size,
                 embed_dim,
                 hidden_dim):

        super().__init__()

        self.embedding = nn.Embedding(
            vocab_size,
            embed_dim
        )

        self.lstm = nn.LSTM(
            embed_dim,
            hidden_dim,
            batch_first=True
        )

        self.fc = nn.Linear(
            hidden_dim,
            2
        )

    def forward(self, x):

        x = self.embedding(x)

        _, (hidden, _) = self.lstm(x)

        output = self.fc(
            hidden[-1]
        )

        return output
```

این مدل ابتدا کلمات را به بردارهای تعبیه‌شده تبدیل می‌کند، سپس توالی را وارد LSTM می‌کند و در نهایت نتیجه طبقه‌بندی را تولید می‌کند.

---

## ⚙️ تعریف تابع هزینه و بهینه‌ساز

```python
model = SentimentLSTM(
    vocab_size=len(vocab),
    embed_dim=128,
    hidden_dim=128
)

criterion = nn.CrossEntropyLoss()

optimizer = torch.optim.Adam(
    model.parameters(),
    lr=0.001
)
```

## 🔄 حلقه آموزش

نمونه‌ای ساده از آموزش:

```python
for epoch in range(3):

    total_loss = 0

    for inputs, labels in train_loader:

        optimizer.zero_grad()

        outputs = model(inputs)

        loss = criterion(
            outputs,
            labels
        )

        loss.backward()

        optimizer.step()

        total_loss += loss.item()

    print(
        f"Epoch {epoch+1}",
        total_loss
    )
```
