# فصل ۱۲ 📊 ارزیابی مدل و معیارهای سنجش عملکرد

## 🎯 اهداف فصل

ساخت یک مدل یادگیری عمیق تنها نیمی از مسیر است. بسیاری از افراد پس از مشاهده مقدار کمی خطا یا دقت بالا تصور می‌کنند مدل آن‌ها آماده استفاده در محیط واقعی است. اما در عمل، ارزیابی مدل یکی از حساس‌ترین مراحل هر پروژه هوش مصنوعی محسوب می‌شود.

فرض کنید مدلی برای تشخیص سرطان ساخته‌اید که دقت ۹۵ درصد دارد. در نگاه اول این عدد فوق‌العاده به نظر می‌رسد. اما اگر بررسی کنیم و متوجه شویم مدل تقریباً تمام بیماران مبتلا را به اشتباه سالم تشخیص می‌دهد، آن دقت ۹۵ درصد عملاً بی‌ارزش خواهد بود. این مثال نشان می‌دهد که تنها نگاه کردن به یک عدد کافی نیست و باید معیارهای مختلفی را بررسی کرد.

در این فصل یاد می‌گیریم چگونه عملکرد مدل را به شکل علمی ارزیابی کنیم، چه معیارهایی برای مسائل مختلف مناسب هستند و چگونه نقاط ضعف مدل را شناسایی کنیم.

---

# 🧠 چرا ارزیابی مدل اهمیت دارد؟

هدف نهایی هر مدل یادگیری ماشین یا یادگیری عمیق، عملکرد مناسب روی داده‌هایی است که قبلاً مشاهده نکرده است. اگر تنها عملکرد روی داده‌های آموزشی را بررسی کنیم، ممکن است مدل دچار بیش‌برازش شده باشد.

به همین دلیل داده‌ها معمولاً به سه بخش تقسیم می‌شوند:

* داده آموزشی (Training Set)
* داده اعتبارسنجی (Validation Set)
* داده آزمون (Test Set)

داده آموزشی برای یادگیری استفاده می‌شود. داده اعتبارسنجی برای تنظیم پارامترها و انتخاب مدل مناسب کاربرد دارد. داده آزمون نیز تنها در پایان پروژه برای ارزیابی نهایی مورد استفاده قرار می‌گیرد.

# 📈 مفهوم Accuracy یا دقت

یکی از ساده‌ترین معیارهای ارزیابی، دقت (Accuracy) است.

دقت نشان می‌دهد چه درصدی از پیش‌بینی‌های مدل صحیح بوده‌اند.

فرمول آن:

[
Accuracy=
\frac{Number\ of\ Correct\ Predictions}
{Total\ Predictions}
]

است.

---

## 🔢 مثال عددی Accuracy

فرض کنید مدل روی ۱۰۰ نمونه آزمایش شده است.

از این تعداد:

* ۹۰ پیش‌بینی صحیح
* ۱۰ پیش‌بینی اشتباه

وجود دارد.

بنابراین:

[
Accuracy=
\frac{90}{100}
]

[
Accuracy=0.9
]

یا:

[
90%
]

دقت برابر ۹۰ درصد خواهد بود.

---

## ⚠️ محدودیت Accuracy

اگر داده‌ها نامتوازن باشند، Accuracy می‌تواند گمراه‌کننده باشد.

فرض کنید در یک مجموعه داده پزشکی:

* ۹۹۰ بیمار سالم
* ۱۰ بیمار مبتلا

وجود داشته باشند.

اگر مدلی تمام افراد را سالم تشخیص دهد:

[
Accuracy=
\frac{990}{1000}
================

99%
]

خواهد بود.

در حالی که مدل حتی یک بیمار واقعی را شناسایی نکرده است.

به همین دلیل در بسیاری از مسائل نمی‌توان تنها به Accuracy اعتماد کرد.

# 📋 ماتریس درهم‌ریختگی (Confusion Matrix)

یکی از مهم‌ترین ابزارهای تحلیل عملکرد مدل، ماتریس درهم‌ریختگی است.

این ماتریس تعداد پیش‌بینی‌های درست و غلط را در دسته‌های مختلف نشان می‌دهد.

در مسائل دودویی چهار حالت وجود دارد:

| مقدار | توضیح     |
| ----- | --------- |
| TP    | مثبت صحیح |
| TN    | منفی صحیح |
| FP    | مثبت کاذب |
| FN    | منفی کاذب |

📷 [تصویر اینجا قرار گیرد: جدول Confusion Matrix با چهار خانه TP، TN، FP و FN]

---

## 🧠 درک TP و TN

مثبت صحیح یا True Positive زمانی رخ می‌دهد که مدل وجود یک کلاس را پیش‌بینی کند و واقعاً آن کلاس وجود داشته باشد.

برای مثال:

مدل سرطان را تشخیص داده و بیمار واقعاً مبتلا باشد.

منفی صحیح یا True Negative نیز زمانی است که مدل عدم وجود بیماری را پیش‌بینی کند و فرد واقعاً سالم باشد.

این دو حالت پیش‌بینی‌های صحیح مدل را تشکیل می‌دهند.

---

## ⚠️ درک FP و FN

مثبت کاذب یا False Positive زمانی رخ می‌دهد که مدل وجود بیماری را اعلام کند اما فرد سالم باشد.

منفی کاذب یا False Negative زمانی است که مدل فرد بیمار را سالم تشخیص دهد.

در بسیاری از کاربردهای پزشکی، FN بسیار خطرناک‌تر از FP است؛ زیرا ممکن است بیماری واقعی نادیده گرفته شود.

---

# 🎯 معیار Precision

دقت مثبت یا Precision نشان می‌دهد از میان تمام نمونه‌هایی که مدل مثبت تشخیص داده است، چه تعداد واقعاً مثبت بوده‌اند.

فرمول:

[
Precision=
\frac{TP}
{TP+FP}
]

است.

---

## 🔢 مثال عددی Precision

فرض کنید:

[
TP=80
]

و

[
FP=20
]

باشد.

داریم:

[
Precision=
\frac{80}
{80+20}
]

[
Precision=
0.8
]

یا:

[
80%
]

بنابراین ۸۰ درصد از پیش‌بینی‌های مثبت مدل صحیح بوده‌اند.

---

# 🎯 معیار Recall

فراخوانی یا Recall نشان می‌دهد مدل چه درصدی از نمونه‌های مثبت واقعی را پیدا کرده است.

فرمول:

[
Recall=
\frac{TP}
{TP+FN}
]

است.

---

## 🔢 مثال عددی Recall

فرض کنید:

[
TP=80
]

و

[
FN=20
]

باشد.

داریم:

[
Recall=
\frac{80}
{80+20}
]

[
Recall=
0.8
]

یا:

[
80%
]

بنابراین مدل توانسته ۸۰ درصد موارد مثبت واقعی را شناسایی کند.

---

# ⚖️ معیار F1 Score

گاهی Precision و Recall با یکدیگر در تعارض قرار می‌گیرند.

برای مثال ممکن است مدلی Precision بالایی داشته باشد اما تعداد زیادی نمونه مثبت واقعی را از دست بدهد.

برای حل این مشکل از معیار F1 استفاده می‌شود.

فرمول:

[
F1=
2\times
\frac
{Precision\times Recall}
{Precision+Recall}
]

است.

این معیار میانگین هارمونیک Precision و Recall را محاسبه می‌کند.

---

## 🔢 مثال عددی F1

فرض کنید:

[
Precision=0.8
]

و

[
Recall=0.6
]

باشد.

داریم:

[
F1=
2\times
\frac
{0.8\times0.6}
{0.8+0.6}
]

[
F1=
0.686
]

تقریباً برابر ۶۹ درصد خواهد بود.

# 📉 منحنی ROC

یکی از ابزارهای بسیار مهم در طبقه‌بندی دودویی منحنی ROC است.

این منحنی رابطه میان:

* نرخ مثبت صحیح (TPR)
* نرخ مثبت کاذب (FPR)

را نمایش می‌دهد.

هرچه منحنی به گوشه بالا و سمت چپ نزدیک‌تر باشد، عملکرد مدل بهتر است.

📷 [تصویر اینجا قرار گیرد: نمودار ROC شامل چند مدل با عملکردهای مختلف]

# 🏆 معیار AUC

برای خلاصه‌سازی منحنی ROC از معیار AUC استفاده می‌شود.

مقدار AUC بین صفر و یک قرار دارد.

تفسیر کلی:

| مقدار AUC     | کیفیت مدل        |
| ------------- | ---------------- |
| 0.5           | مشابه حدس تصادفی |
| 0.7 تا 0.8    | قابل قبول        |
| 0.8 تا 0.9    | خوب              |
| بالاتر از 0.9 | بسیار عالی       |

هرچه AUC بزرگ‌تر باشد، قدرت تفکیک مدل بیشتر است.

# 📊 معیارهای رگرسیون

در مسائل رگرسیون، مفاهیم TP و FP وجود ندارند. به همین دلیل از معیارهای دیگری استفاده می‌شود.

دو معیار رایج عبارت‌اند از:

* میانگین مربعات خطا (MSE)
* ریشه میانگین مربعات خطا (RMSE)

---

## 📐 فرمول MSE

فرمول:

[
MSE=
\frac{1}{n}
\sum_{i=1}^{n}
(y_i-\hat{y_i})^2
]

است.

در این فرمول:

* (y_i) مقدار واقعی است.
* (\hat{y_i}) مقدار پیش‌بینی‌شده است.
* (n) تعداد نمونه‌ها است.

---

## 🔢 مثال عددی MSE

فرض کنید:

مقادیر واقعی:

[
[10,20,30]
]

مقادیر پیش‌بینی:

[
[12,18,29]
]

اختلاف‌ها:

[
2,-2,-1
]

مربعات:

[
4,4,1
]

جمع:

[
9
]

بنابراین:

[
MSE=
\frac{9}{3}
===========

3
]

خواهد بود.

# 💻 پروژه عملی فصل: محاسبه معیارهای ارزیابی

در این پروژه چند معیار مهم را با استفاده از Scikit-Learn محاسبه می‌کنیم.

```python id="w0b2k4"
from sklearn.metrics import (
    accuracy_score,
    precision_score,
    recall_score,
    f1_score
)

y_true = [1, 0, 1, 1, 0]

y_pred = [1, 0, 1, 0, 0]

print(
    accuracy_score(
        y_true,
        y_pred
    )
)

print(
    precision_score(
        y_true,
        y_pred
    )
)

print(
    recall_score(
        y_true,
        y_pred
    )
)

print(
    f1_score(
        y_true,
        y_pred
    )
)
```
