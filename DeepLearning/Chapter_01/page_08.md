## 🧠 PyTorch چیست؟

PyTorch یک چارچوب متن‌باز یادگیری عمیق است که توسط شرکت Meta Platforms توسعه داده شده است. این چارچوب برای انجام محاسبات عددی، ساخت شبکه‌های عصبی، آموزش مدل‌ها و اجرای الگوریتم‌های یادگیری ماشین طراحی شده است.

یکی از مهم‌ترین ویژگی‌های PyTorch استفاده از گراف محاسباتی پویا است. این قابلیت باعث می‌شود فرآیند توسعه و اشکال‌زدایی مدل‌ها بسیار ساده‌تر از بسیاری از چارچوب‌های قدیمی باشد. به همین دلیل PyTorch در میان پژوهشگران و دانشگاه‌ها محبوبیت فوق‌العاده‌ای پیدا کرده است.

علاوه بر این، بسیاری از مدل‌های مشهور امروزی مانند مدل‌های زبانی بزرگ، سامانه‌های تولید تصویر و سیستم‌های پیشرفته پردازش زبان طبیعی بر پایه PyTorch توسعه یافته‌اند. یادگیری این چارچوب در واقع یکی از مهم‌ترین مهارت‌های موردنیاز برای ورود به بازار کار هوش مصنوعی محسوب می‌شود.

## 📦 تنسور چیست؟

اساسی‌ترین مفهوم در PyTorch تنسور (Tensor) است. تنسور را می‌توان نسخه پیشرفته آرایه‌های چندبعدی در کتابخانه NumPy دانست.

یک عدد منفرد یک تنسور صفر بعدی است. یک بردار تنسور یک‌بعدی محسوب می‌شود. یک ماتریس نمونه‌ای از تنسور دوبعدی است و داده‌هایی مانند تصاویر رنگی معمولاً به‌صورت تنسورهای سه یا چهار بعدی نمایش داده می‌شوند.

تقریباً تمام داده‌ها و پارامترهای شبکه عصبی در PyTorch به شکل تنسور ذخیره می‌شوند. به همین دلیل درک این مفهوم اهمیت بسیار زیادی دارد.

## 🔢 ایجاد تنسورهای ساده

برای ایجاد یک تنسور می‌توان از تابع `tensor` استفاده کرد.

```python
import torch

x = torch.tensor([1, 2, 3])

print(x)
```

در این مثال یک تنسور یک‌بعدی شامل سه عدد ایجاد شده است.

اکنون یک ماتریس را بررسی کنیم:

```python
import torch

matrix = torch.tensor([
    [1, 2],
    [3, 4]
])

print(matrix)
```

خروجی یک تنسور دوبعدی خواهد بود که ساختاری مشابه ماتریس دارد.

## ➕ عملیات ریاضی روی تنسورها

## 🚀 استفاده از GPU

یکی از مهم‌ترین قابلیت‌های PyTorch امکان استفاده از پردازنده گرافیکی یا GPU است.

در شبکه‌های عصبی بزرگ، آموزش روی CPU ممکن است ساعت‌ها یا روزها زمان ببرد. اما GPU می‌تواند این زمان را به شدت کاهش دهد.

برای بررسی در دسترس بودن GPU:

```python
import torch

print(torch.cuda.is_available())
```

اگر مقدار `True` نمایش داده شود، می‌توان محاسبات را روی GPU اجرا کرد.

نمونه انتقال داده به GPU:

```python
device = torch.device("cuda")

x = torch.tensor([1, 2, 3])

x = x.to(device)
```

در پروژه‌های واقعی این ویژگی اهمیت بسیار زیادی دارد.

## 🏗️ ساخت اولین شبکه عصبی

اکنون آماده هستیم تا اولین مدل خود را بسازیم.

در PyTorch بیشتر شبکه‌ها با استفاده از ماژول `nn` ایجاد می‌شوند.

نمونه یک شبکه بسیار ساده:

```python
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(2, 8),
    nn.ReLU(),
    nn.Linear(8, 1)
)

print(model)
```

در این مدل:

* لایه اول دارای دو ورودی و هشت نورون است.
* تابع فعال‌سازی ReLU استفاده شده است.
* لایه خروجی یک مقدار تولید می‌کند.

این ساختار یکی از ساده‌ترین نمونه‌های شبکه عصبی چندلایه محسوب می‌شود.

## 📉 تابع هزینه و بهینه‌ساز در PyTorch

برای آموزش مدل به دو جزء مهم نیاز داریم:

۱. تابع هزینه

۲. بهینه‌ساز

برای مثال:

```python
import torch.nn as nn
import torch.optim as optim

criterion = nn.MSELoss()

optimizer = optim.Adam(
    model.parameters(),
    lr=0.001
)
```

تابع `MSELoss` میزان خطا را اندازه‌گیری می‌کند و Adam مسئول به‌روزرسانی وزن‌ها است.

این دو جزء تقریباً در تمام پروژه‌های یادگیری عمیق حضور دارند.

## 🔄 چرخه آموزش مدل

فرآیند آموزش معمولاً شامل مراحل زیر است:

۱. انجام پیش‌بینی

۲. محاسبه خطا

۳. اجرای انتشار پسرو

۴. به‌روزرسانی وزن‌ها

در PyTorch این فرآیند معمولاً به شکل زیر نوشته می‌شود:

```python
optimizer.zero_grad()

predictions = model(inputs)

loss = criterion(
    predictions,
    targets
)

loss.backward()

optimizer.step()
```

این چند خط کد در واقع قلب آموزش شبکه‌های عصبی را تشکیل می‌دهند.

## 💻 پروژه عملی فصل: پیش‌بینی قیمت خانه

در این پروژه یک شبکه عصبی کوچک برای پیش‌بینی قیمت خانه ایجاد می‌کنیم.

```python
import torch
import torch.nn as nn
import torch.optim as optim

X = torch.tensor([
    [50.0],
    [70.0],
    [90.0],
    [110.0]
])

y = torch.tensor([
    [100.0],
    [140.0],
    [180.0],
    [220.0]
])

model = nn.Sequential(
    nn.Linear(1, 8),
    nn.ReLU(),
    nn.Linear(8, 1)
)

criterion = nn.MSELoss()

optimizer = optim.Adam(
    model.parameters(),
    lr=0.01
)

for epoch in range(500):

    predictions = model(X)

    loss = criterion(
        predictions,
        y
    )

    optimizer.zero_grad()

    loss.backward()

    optimizer.step()

print(model(torch.tensor([[120.0]])))
```

### توضیح پروژه

در این مثال متراژ خانه به‌عنوان ورودی و قیمت آن به‌عنوان خروجی استفاده شده است. شبکه تلاش می‌کند رابطه میان این دو متغیر را یاد بگیرد. پس از آموزش، می‌توان متراژ جدیدی به مدل داد و قیمت تقریبی آن را پیش‌بینی کرد.

اگرچه این مثال بسیار ساده است، اما تقریباً تمام پروژه‌های بزرگ یادگیری عمیق از همین ساختار کلی استفاده می‌کنند.
