## 🏗️ بارگذاری داده‌ها

ابتدا دیتاست را دریافت و آماده‌سازی می‌کنیم. در این مرحله تصاویر به Tensor تبدیل می‌شوند و سپس نرمال‌سازی روی آن‌ها انجام می‌شود.

```python
import torch
import torch.nn as nn
import torch.optim as optim

from torchvision import datasets
from torchvision import transforms
from torch.utils.data import DataLoader

transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize(
        (0.5, 0.5, 0.5),
        (0.5, 0.5, 0.5)
    )
])

train_dataset = datasets.CIFAR10(
    root="./data",
    train=True,
    download=True,
    transform=transform
)

test_dataset = datasets.CIFAR10(
    root="./data",
    train=False,
    download=True,
    transform=transform
)

train_loader = DataLoader(
    train_dataset,
    batch_size=64,
    shuffle=True
)

test_loader = DataLoader(
    test_dataset,
    batch_size=64,
    shuffle=False
)
```

در این بخش ابتدا داده‌ها از اینترنت دریافت می‌شوند. سپس تصاویر به Tensor تبدیل شده و مقادیر پیکسل‌ها نرمال‌سازی می‌شوند. در ادامه DataLoader داده‌ها را به دسته‌های ۶۴تایی تقسیم می‌کند تا آموزش سریع‌تر و پایدارتر انجام شود.

## 🧠 ساخت مدل CNN

اکنون یک شبکه کانولوشنی ساده اما واقعی تعریف می‌کنیم.

```python
class CIFARNet(nn.Module):

    def __init__(self):
        super().__init__()

        self.features = nn.Sequential(

            nn.Conv2d(
                3,
                32,
                kernel_size=3,
                padding=1
            ),

            nn.ReLU(),

            nn.MaxPool2d(
                kernel_size=2
            ),

            nn.Conv2d(
                32,
                64,
                kernel_size=3,
                padding=1
            ),

            nn.ReLU(),

            nn.MaxPool2d(
                kernel_size=2
            )
        )

        self.classifier = nn.Sequential(

            nn.Linear(
                64 * 8 * 8,
                256
            ),

            nn.ReLU(),

            nn.Linear(
                256,
                10
            )
        )

    def forward(self, x):

        x = self.features(x)

        x = x.view(
            x.size(0),
            -1
        )

        x = self.classifier(x)

        return x

model = CIFARNet()
```

در این معماری دو لایه کانولوشنی و دو لایه پولینگ استفاده شده‌اند. سپس ویژگی‌های استخراج‌شده وارد بخش طبقه‌بندی می‌شوند و خروجی نهایی ۱۰ کلاس مختلف را پیش‌بینی می‌کند.

## 🔄 حلقه آموزش

اکنون مدل را آموزش می‌دهیم.

```python
epochs = 5

for epoch in range(epochs):

    running_loss = 0

    for images, labels in train_loader:

        optimizer.zero_grad()

        outputs = model(images)

        loss = criterion(
            outputs,
            labels
        )

        loss.backward()

        optimizer.step()

        running_loss += loss.item()

    print(
        f"Epoch {epoch+1} "
        f"Loss: "
        f"{running_loss:.4f}"
    )
```

در هر دوره آموزشی، تصاویر وارد شبکه می‌شوند، خروجی محاسبه می‌شود، مقدار خطا تعیین می‌گردد و سپس انتشار پسرو وزن‌ها را اصلاح می‌کند.

خروجی احتمالی برنامه ممکن است چیزی مشابه زیر باشد:

```text

Epoch 3 Loss: 620.2
Epoch 4 Loss: 542.9
Epoch 5 Loss: 488.1
```

کاهش تدریجی خطا نشان می‌دهد مدل در حال یادگیری است.

## 📊 ارزیابی مدل

پس از آموزش باید عملکرد مدل را روی داده‌هایی که قبلاً مشاهده نکرده است بررسی کنیم.

```python
correct = 0
total = 0

with torch.no_grad():

    for images, labels in test_loader:

        outputs = model(images)

        _, predicted = torch.max(
            outputs,
            1
        )

        total += labels.size(0)

        correct += (
            predicted == labels
        ).sum().item()

accuracy = (
    100 * correct / total
)

print(
    f"Accuracy: "
    f"{accuracy:.2f}%"
)
```

نمونه‌ای از خروجی:

```text
Accuracy: 72.35%
```

برای یک CNN ساده و تنها چند دوره آموزش، چنین دقتی کاملاً قابل قبول است.

## 🔍 مشاهده پیش‌بینی مدل

برای درک بهتر عملکرد شبکه می‌توان چند تصویر را نمایش داد و پیش‌بینی مدل را مشاهده کرد.

```python
classes = (
    "plane",
    "car",
    "bird",
    "cat",
    "deer",
    "dog",
    "frog",
    "horse",
    "ship",
    "truck"
)

images, labels = next(
    iter(test_loader)
)

outputs = model(images)

_, predicted = torch.max(
    outputs,
    1
)

print(
    "Prediction:",
    classes[predicted[0]]
)

print(
    "Real:",
    classes[labels[0]]
)
```

در این بخش می‌توان بررسی کرد که آیا مدل کلاس تصویر را به درستی تشخیص داده است یا خیر.
