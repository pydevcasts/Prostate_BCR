# فصل ۳ 🧠 نورون مصنوعی و شبکه‌های عصبی پایه

## 🎯 اهداف فصل

در فصل قبل، ابزارهای ریاضی موردنیاز برای یادگیری عمیق را بررسی کردیم. اکنون زمان آن رسیده است که اولین و مهم‌ترین جزء سازنده شبکه‌های عصبی را بشناسیم: **نورون مصنوعی** (Artificial Neuron).

در پایان این فصل خواهید توانست:

* مفهوم نورون مصنوعی را درک کنید.
* ارتباط میان نورون بیولوژیکی و نورون مصنوعی را بشناسید.
* ساختار پرسپترون (Perceptron) را تحلیل کنید.
* نقش وزن (Weight) و بایاس (Bias) را بفهمید.
* توابع فعال‌سازی (Activation Functions) را بشناسید.
* یک شبکه عصبی ساده را از صفر طراحی کنید.
* اولین مدل طبقه‌بندی خود را با PyTorch پیاده‌سازی نمایید.

---

# 🧬 الهام از مغز انسان

مغز انسان از میلیاردها سلول عصبی یا نورون تشکیل شده است. هر نورون اطلاعات را از نورون‌های دیگر دریافت می‌کند، آن‌ها را پردازش می‌کند و در صورت لزوم سیگنالی را به نورون‌های بعدی ارسال می‌کند.

به‌صورت ساده، هر نورون سه بخش اصلی دارد:

1. دندریت‌ها (Dendrites) برای دریافت سیگنال
2. جسم سلولی برای پردازش اطلاعات
3. آکسون (Axon) برای ارسال خروجی

📷 [تصویر اینجا قرار گیرد: ساختار نورون بیولوژیکی شامل دندریت، جسم سلولی و آکسون]

پژوهشگران علوم کامپیوتر از همین ایده برای طراحی نورون مصنوعی الهام گرفتند.

# ⚙️ نورون مصنوعی چیست؟

نورون مصنوعی کوچک‌ترین واحد محاسباتی در یک شبکه عصبی است.

این نورون چند ورودی دریافت می‌کند، روی آن‌ها محاسباتی انجام می‌دهد و یک خروجی تولید می‌کند.

ساختار کلی آن به شکل زیر است:

📷 [تصویر اینجا قرار گیرد: نورون مصنوعی شامل ورودی‌ها، وزن‌ها، جمع‌کننده، بایاس و تابع فعال‌سازی]

هر ورودی دارای یک وزن مخصوص به خود است.

فرمول پایه نورون:

[
z = w_1x_1 + w_2x_2 + w_3x_3 + ... + w_nx_n + b
]

که در آن:

* (x) ها ورودی‌ها هستند.
* (w) ها وزن‌ها هستند.
* (b) بایاس است.
* (z) مجموع وزن‌دار ورودی‌ها است.

سپس خروجی از طریق تابع فعال‌سازی محاسبه می‌شود:

[
a = f(z)
]

---

# 🧮 مثال عددی کامل

فرض کنید یک نورون سه ورودی دریافت می‌کند:

[
x_1=2
]

[
x_2=4
]

[
x_3=1
]

وزن‌ها:

[
w_1=0.5
]

[
w_2=0.2
]

[
w_3=0.8
]

و بایاس:

[
b=1
]

اکنون مقدار z را محاسبه می‌کنیم:

[
z=(0.5\times2)+(0.2\times4)+(0.8\times1)+1
]

[
z=1+0.8+0.8+1
]

[
z=3.6
]

اگر فعلاً تابع فعال‌سازی را برابر تابع همانی در نظر بگیریم:

[
a=z
]

در نتیجه:

[
a=3.6
]

# 🎯 وزن‌ها چه نقشی دارند؟

وزن‌ها مهم‌ترین پارامترهای قابل یادگیری شبکه عصبی هستند.

هر وزن میزان اهمیت یک ورودی را مشخص می‌کند.

برای مثال در یک سیستم پیش‌بینی قبولی دانشجو:

* ساعات مطالعه
* تعداد تمرین‌های حل‌شده
* حضور در کلاس

ممکن است ساعات مطالعه تأثیر بیشتری داشته باشد.

در این حالت وزن مربوط به آن ویژگی بزرگ‌تر خواهد بود.

در طول فرآیند آموزش، شبکه این وزن‌ها را به‌صورت خودکار تنظیم می‌کند.

---

# ⚖️ بایاس چیست؟

بایاس پارامتری است که به مدل اجازه می‌دهد انعطاف‌پذیری بیشتری داشته باشد.

اگر بایاس وجود نداشته باشد:

[
z=wx
]

در این حالت مدل همیشه مجبور است از نقطه صفر عبور کند.

اما با اضافه شدن بایاس:

[
z=wx+b
]

مدل می‌تواند مرز تصمیم‌گیری خود را جابه‌جا کند.

📷 [تصویر اینجا قرار گیرد: مقایسه نمودار خطی با و بدون بایاس]

# 🔥 تابع فعال‌سازی چیست؟

اگر فقط عملیات جمع و ضرب انجام دهیم، شبکه عصبی عملاً چیزی بیشتر از یک مدل خطی نخواهد بود.

توابع فعال‌سازی باعث ایجاد غیرخطی بودن (Non-Linearity) می‌شوند.

همین غیرخطی بودن راز اصلی قدرت شبکه‌های عصبی است.

---

# 📈 تابع پله‌ای (Step Function)

یکی از اولین توابع فعال‌سازی مورد استفاده:

[
f(x)=
\begin{cases}
1 & x \geq 0\
0 & x < 0
\end{cases}
]

این تابع برای تصمیم‌گیری دودویی طراحی شده بود.

📷 [تصویر اینجا قرار گیرد: نمودار تابع پله‌ای]

---

# 📈 تابع سیگموید (Sigmoid)

یکی از مشهورترین توابع فعال‌سازی:

[
\sigma(x)=\frac{1}{1+e^{-x}}
]

خروجی آن همیشه بین صفر و یک قرار می‌گیرد.

---

## مثال عددی

فرض کنید:

[
x=2
]

داریم:

[
\sigma(2)=\frac{1}{1+e^{-2}}
]

[
=\frac{1}{1+0.135}
]

[
=0.881
]

بنابراین:

[
\sigma(2)\approx0.88
]

📷 [تصویر اینجا قرار گیرد: نمودار تابع سیگموید]

---

# 📈 تابع تانژانت هیپربولیک (Tanh)

فرمول:

[
tanh(x)=
\frac{e^x-e^{-x}}
{e^x+e^{-x}}
]

خروجی آن بین 1- و 1 قرار می‌گیرد.

مزیت آن نسبت به سیگموید این است که حول صفر متقارن است.

📷 [تصویر اینجا قرار گیرد: مقایسه نمودار Sigmoid و Tanh]

---

# 🚀 تابع ReLU

امروزه پرکاربردترین تابع فعال‌سازی:

[
ReLU(x)=max(0,x)
]

---

## مثال

اگر:

[
x=5
]

باشد:

[
ReLU(5)=5
]

اگر:

[
x=-3
]

باشد:

[
ReLU(-3)=0
]

📷 [تصویر اینجا قرار گیرد: نمودار تابع ReLU]

---

# 📊 مقایسه توابع فعال‌سازی

| تابع    | بازه خروجی      | مزیت        |
| ------- | --------------- | ----------- |
| Step    | 0 تا 1          | ساده        |
| Sigmoid | 0 تا 1          | احتمال      |
| Tanh    | 1- تا 1         | متقارن      |
| ReLU    | صفر تا بی‌نهایت | سریع و مؤثر |

# 🏗️ شبکه عصبی چندلایه

یک نورون به‌تنهایی قدرت محدودی دارد.

اما اگر تعداد زیادی نورون را به هم متصل کنیم، شبکه عصبی شکل می‌گیرد.

یک شبکه عصبی معمولاً شامل سه بخش است:

### لایه ورودی

اطلاعات اولیه را دریافت می‌کند.

### لایه‌های پنهان

عملیات یادگیری در این بخش رخ می‌دهد.

### لایه خروجی

نتیجه نهایی را تولید می‌کند.

📷 [تصویر اینجا قرار گیرد: شبکه عصبی سه‌لایه شامل Input Layer، Hidden Layer و Output Layer]

دو ورودی داریم:

[
x_1=1

[
x_2=2

0.5

0.4

این دقیقاً همان چیزی است که در شبکه‌های بزرگ‌تر میلیون‌ها بار اتفاق می‌افتد.

# ⚙️ پروژه عملی فصل

در این پروژه یک شبکه عصبی ساده برای تشخیص کلاس داده‌ها با PyTorch می‌سازیم.

```python
import torch
import torch.nn as nn

class SimpleNetwork(nn.Module):

    def __init__(self):
        super().__init__()

        self.layer1 = nn.Linear(2, 8)
        self.relu = nn.ReLU()
        self.output = nn.Linear(8, 1)

    def forward(self, x):

        x = self.layer1(x)
        x = self.relu(x)
        x = self.output(x)

        return x

model = SimpleNetwork()

print(model)
```
