
## 🔹 صفحه ۲۷ — توابع آماری و تحلیلی روی Tensorها

📌 شامل: `mean`, `std`, `min`, `max`, `sum`, `argmax`, `argmin`, `clamp`

---

### 🎯 چرا توابع آماری مهم هستند؟

هنگام بررسی، پیش‌پردازش یا تحلیل داده‌ها یا خروجی مدل، نیاز داریم:

* میانگین و انحراف معیار ویژگی‌ها را محاسبه کنیم
* حداکثر یا حداقل مقدار را بیابیم
* شاخص (index) این مقادیر را شناسایی کنیم
* مقدارها را در بازه معین محدود کنیم

---

## 🔸 `mean()` — میانگین عناصر Tensor

```python
x = torch.tensor([1.0, 2.0, 3.0, 4.0])

print(x.mean())  # tensor(2.5)
```

برای محاسبه میانگین در یک بُعد خاص:

```python
x = torch.rand(2, 3)

print(x.mean(dim=0))  # میانگین ستون‌ها  
print(x.mean(dim=1))  # میانگین سطرها
```

---

## 🔸 `std()` — انحراف معیار

```python
x = torch.tensor([1.0, 2.0, 3.0, 4.0])

print(x.std())  # tensor(1.2909)
```

---

## 🔸 `sum()` — مجموع عناصر

```python
x = torch.tensor([1, 2, 3, 4, 5])

print(x.sum())  # tensor(15)
```

---

## 🔸 `min()` و `max()` — کمترین و بیشترین مقدار

```python
x = torch.tensor([5, 3, 8, 1, 6])

print(x.min())  # tensor(1)
print(x.max())  # tensor(8)
```

---

## 🔸 `argmin()` و `argmax()` — اندیس مقدار کمینه و بیشینه

```python
print(x.argmin())  # tensor(3)
print(x.argmax())  # tensor(2)
```

✅ برای یافتن مکان (ایندکس) مفید هستند، نه مقدار

---

## 🔸 `clamp()` — محدود کردن مقادیر در یک بازه

```python
x = torch.tensor([0.1, 0.5, 0.9, 1.2, -0.3])

y = torch.clamp(x, min=0.0, max=1.0)

print(y)  # tensor([0.1000, 0.5000, 0.9000, 1.0000, 0.0000])
```

✅ اگر مقداری خارج از بازه باشد، به نزدیک‌ترین حد مجاز محدود می‌شود.

---

## 🔸 محاسبه روی ابعاد خاص (مثال ۲ بعدی)

```python
x = torch.tensor([[1.0, 2.0], [3.0, 4.0]])

print(x.mean(dim=0))  # tensor([2.0, 3.0]) → میانگین ستون‌ها  
print(x.mean(dim=1))  # tensor([1.5, 3.5]) → میانگین سطرها
```

---

## 🔍 کاربردهای عملی این توابع

| تابع              | کاربرد                                               |
| ----------------- | ---------------------------------------------------- |
| `mean()`          | نرمال‌سازی داده یا بررسی سطح کلی                     |
| `std()`           | تشخیص پراکندگی داده                                  |
| `min()` / `max()` | تعیین مقادیر بحرانی                                  |
| `argmax()`        | انتخاب کلاس دارای بیشترین احتمال در طبقه‌بندی        |
| `clamp()`         | جلوگیری از انفجار یا انحراف مقادیر (مثلاً در تصاویر) |
