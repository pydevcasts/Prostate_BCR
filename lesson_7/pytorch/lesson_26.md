

## 🔹 صفحه ۲۶ — انتخاب و فیلتر کردن داده با شرط در PyTorch

📌 شامل: `torch.where`, `masked_select`, مقایسه شرطی، و `boolean indexing`

---

### 🎯 چرا این ابزارها مهم‌اند؟

در پردازش داده یا خروجی مدل‌ها، بسیار پیش می‌آید که بخواهیم فقط:

* مقادیری که از یک حد بیشترند را انتخاب کنیم
* داده‌هایی را جایگزین کنیم
* بر اساس شرط، فیلتر کنیم

✅ PyTorch امکانات بسیار قدرتمندی برای این کار فراهم کرده است.

---

## 🔸 مقایسه شرطی بین Tensorها

```python
x = torch.tensor([1, 2, 3, 4, 5])

mask = x > 3         # Tensor([False, False, False, True, True])
```

✅ خروجی یک Tensor از نوع `bool` است که می‌توان از آن برای انتخاب استفاده کرد.

---

## 🔸 استفاده از `masked_select`

```python
x = torch.tensor([1, 2, 3, 4, 5])

mask = x > 2
selected = torch.masked_select(x, mask)

print(selected)  # tensor([3, 4, 5])
```

---

## 🔸 انتخاب با Boolean Indexing (روش ساده‌تر)

```python
x = torch.tensor([1, 2, 3, 4, 5])

print(x[x > 2])  # tensor([3, 4, 5])
```

✅ این روش خواناتر و پرکاربردتر است.

---

## 🔸 جایگزینی با استفاده از `torch.where`

```python
x = torch.tensor([1, 2, 3, 4, 5])

# If x > 3 → use x, else → use 0
result = torch.where(x > 3, x, torch.tensor(0))

print(result)  # tensor([0, 0, 0, 4, 5])
```

| پارامتر                          | توضیح           |
| -------------------------------- | --------------- |
| شرط → `x > 3`                    | شرط برای انتخاب |
| مقدار اگر شرط برقرار باشد → `x`  |                 |
| مقدار اگر شرط برقرار نباشد → `0` |                 |

---

## 🔸 استفاده از `where` با دو Tensor مختلف

```python
a = torch.tensor([1, 2, 3])
b = torch.tensor([10, 20, 30])

cond = torch.tensor([True, False, True])

res = torch.where(cond, a, b)  # tensor([1, 20, 3])
```

---

## 🔍 عملیات ترکیبی شرطی

```python
x = torch.rand(10)

# انتخاب مقادیر بین 0.3 و 0.7
filtered = x[(x > 0.3) & (x < 0.7)]

print(filtered)
```

✅ استفاده از `&` برای "و" منطقی
✅ از `|` برای "یا" نیز می‌توان استفاده کرد

## 📘 تمرین پیشنهادی:

۱. یک Tensor تصادفی بسازید و مقادیر بزرگ‌تر از ۰.۵ را انتخاب کنید
۲. با `where` تمام مقادیر کمتر از ۰.۳ را با صفر جایگزین کنید
۳. از یک شرط ترکیبی استفاده کنید: فقط مقادیری بین ۰.۲ و ۰.۸ را نگه دارید
