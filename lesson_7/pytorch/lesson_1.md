### 🔰 PyTorch چیست و چرا Tensor مهم است؟

اگر بخواهیم یادگیری با PyTorch را مثل ساختن یک ساختمان تصور کنیم، **تنسورها (Tensors)** آجرهای اولیه این سازه هستند. هر چیزی که با داده سر و کار دارد—چه در یادگیری ماشین، چه در یادگیری عمیق—در نهایت به تنسور ختم می‌شود.

در واقع، **Tensors** آرایه‌هایی هستند که می‌توانند در یک، دو، سه یا چند بعد داده‌ها را نگهداری کنند. این آرایه‌ها شبیه `NumPy array` هستند، ولی با این تفاوت که:

* می‌توانند روی GPU پردازش شوند.
* دارای قابلیت رهگیری گرادیان برای یادگیری هستند.

---

### 📌 تعریف ساده:

> Tensor در PyTorch یک ساختار داده‌ای مشابه آرایه چندبعدی است که می‌تواند روی CPU یا GPU قرار گیرد و قابلیت محاسبات پیشرفته را دارد.

---

## ✅ ساخت Tensor با `torch.tensor()`

برای ساختن یک Tensor، ساده‌ترین روش استفاده از تابع `torch.tensor()` است. بیایید یک مثال ساده ببینیم.

```python
import torch

# یک آرایه‌ی دوبعدی را به Tensor تبدیل می‌کنیم
x = torch.tensor([[1, 2, 3],
                  [4, 5, 6]])

print(x)
```

### ✅ خروجی:

```
tensor([[1, 2, 3],
        [4, 5, 6]])
```

---

## 📘 توضیح خط به خط:

| کد                  | توضیح                                                 |
| ------------------- | ----------------------------------------------------- |
| `import torch`      | کتابخانه‌ی PyTorch را فراخوانی می‌کنیم.               |
| `torch.tensor(...)` | لیستی از لیست‌ها را به یک Tensor دوبعدی تبدیل می‌کند. |
| `print(x)`          | محتوای Tensor را در قالب خاص PyTorch چاپ می‌کند.      |

## 🎯 بررسی ویژگی‌های یک Tensor

شما می‌توانید ویژگی‌های مختلف Tensor را مشاهده کنید:

```python
print("Shape:", x.shape)
print("Data Type:", x.dtype)
print("Device:", x.device)
print("Dimension:", x.ndim)
```

### خروجی:

```
Shape: torch.Size([2, 3])
Data Type: torch.int64
Device: cpu
Dimension: 2
```

---

## 💡 نکته مهم:

اگر عددها را با نقطه بنویسید، PyTorch آن‌ها را به صورت `float32` ذخیره می‌کند:

```python
x = torch.tensor([[1.0, 2.0], [3.0, 4.0]])
print(x.dtype)  # float32
```

## 🔍 یک سوال مهم:

چرا PyTorch اینقدر روی Tensorها تاکید دارد؟

زیرا در الگوریتم‌های یادگیری ماشین و یادگیری عمیق، تمام عملیات روی داده‌های عددی انجام می‌شود و Tensorها بهترین ساختار برای نمایش و عملیات روی این داده‌ها هستند—خصوصاً وقتی داده بزرگ باشد و نیاز به GPU داشته باشیم.
