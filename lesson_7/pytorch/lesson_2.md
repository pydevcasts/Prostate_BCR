

# ✅ فصل اول: آشنایی با Tensor در PyTorch

## 🔹 صفحه ۲ — توابع تولید داده تصادفی: `rand()`, `randn()`, `randint()`

---

### 🎯 چرا توابع تصادفی مهم‌اند؟

در بسیاری از الگوریتم‌های یادگیری، نیاز به داده‌ی تصادفی داریم—برای مثال:

* مقداردهی اولیه‌ی وزن‌ها در شبکه‌های عصبی
* ساخت داده تست
* شبیه‌سازی

 ابزارهای قدرتمندی برای ساخت داده تصادفی دارد. سه تابع اصلی که بسیار پرکاربردند:

---

## 🔹 تابع `torch.rand()`

این تابع **اعدادی بین ۰ و ۱ با توزیع یکنواخت (Uniform)** تولید می‌کند.

```python
import torch

# Create a 2x3 tensor with random numbers from [0, 1)
x = torch.rand(2, 3)

print(x)
```

✅ این مقادیر همواره بین صفر و یک هستند ولی هر بار اجرای برنامه، اعداد متفاوتی تولید می‌شود.

---

## 🔹 تابع `torch.randn()`

بر خلاف `rand()`، تابع `randn()` از **توزیع نرمال (Gaussian)** برای تولید اعداد استفاده می‌کند.

ویژگی‌های آن:

* میانگین = ۰
* انحراف معیار = ۱
* داده‌ها می‌توانند منفی یا مثبت باشند.

```python
# Generate random numbers from a normal distribution (mean=0, std=1)
x = torch.randn(2, 4)

print(x)
```

✅ مناسب برای شبیه‌سازی داده‌های طبیعی یا ورودی‌های دارای نویز است.

---

## 🔹 تابع `torch.randint()`

این تابع **اعداد صحیح تصادفی بین یک بازه مشخص** تولید می‌کند.

```python
# Generate random integers from 10 (inclusive) to 20 (exclusive)
x = torch.randint(low=10, high=20, size=(3, 3))

print(x)
```

📌 پارامترها:

* `low`: کم‌ترین مقدار ممکن (شامل می‌شود)
* `high`: بیش‌ترین مقدار ممکن (شامل نمی‌شود)
* `size`: شکل Tensor خروجی

---

## 🔄 تفاوت اصلی بین این سه تابع:

| تابع        | نوع توزیع    | نوع داده       | دامنه خروجی                |
| ----------- | ------------ | -------------- | -------------------------- |
| `rand()`    | یکنواخت      | اعشاری         | \[0, 1)                    |
| `randn()`   | نرمال (گوسی) | اعشاری         | مقادیر مثبت و منفی حول صفر |
| `randint()` | یکنواخت      | صحیح (integer) | عدد صحیح بین دو عدد        |

---

۲. با `torch.randn()` یک Tensor 3×5 بسازید و مقدار max و min آن را نمایش دهید.
