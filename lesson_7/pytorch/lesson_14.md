### 📘 در این فصل چه یاد گرفتیم؟

ما در فصل اول پایه‌های کار با Tensor در PyTorch را پوشش دادیم — از ساخت Tensor گرفته تا تغییر شکل، عملیات ریاضی، آماری و متدهای کمکی بسیار پرکاربرد.

این فصل برای کسی که تازه با PyTorch آشنا شده، مثل یک نقشه راه عمل می‌کند. اکنون با یک نگاه خلاصه، همه متدهایی که یاد گرفتیم را مرور می‌کنیم.

---

## 🔹 جدول مرجع توابع پایه PyTorch (Cheat Sheet ساده)

| عملیات          | تابع                             | توضیح                         |
| --------------- | -------------------------------- | ----------------------------- |
| ساخت Tensor     | `torch.tensor(...)`              | تبدیل لیست یا آرایه به Tensor |
| تصادفی یکنواخت  | `torch.rand(...)`                | بین ۰ و ۱، توزیع یکنواخت      |
| تصادفی نرمال    | `torch.randn(...)`               | میانگین ۰، انحراف معیار ۱     |
| تصادفی عدد صحیح | `torch.randint(low, high, size)` | اعداد صحیح بین low و high     |

---

## 🔹 عملیات ریاضی

| تابع               | توضیح                  |
| ------------------ | ---------------------- |
| `+`, `-`, `*`, `/` | جمع، تفریق، ضرب، تقسیم |
| `torch.add(a, b)`  | جمع دو Tensor          |
| `torch.mul(a, b)`  | ضرب عنصر به عنصر       |
| `torch.pow(a, 2)`  | توان‌رسانی             |

---

## 🔹 آمار و تحلیل

| تابع                          | توضیح                      |
| ----------------------------- | -------------------------- |
| `.mean()`, `.std()`, `.sum()` | میانگین، انحراف معیار، جمع |
| `.min()`, `.max()`            | کمینه و بیشینه             |
| `.argmax()`, `.argmin()`      | ایندکس بیشینه/کمینه        |
| `.median()`, `.mode()`        | میانه و مد                 |

---

## 🔹 مقایسه و شرط

| تابع                      | توضیح                 |
| ------------------------- | --------------------- |
| `.gt()`, `.lt()`, `.eq()` | بزرگتر، کوچکتر، مساوی |
| `torch.where(cond, a, b)` | انتخاب شرطی           |
| `.clamp(min, max)`        | محدودسازی مقادیر      |

---

## 🔹 تغییر شکل و ابعاد

| تابع                     | توضیح                   |
| ------------------------ | ----------------------- |
| `.view()`, `.reshape()`  | تغییر شکل Tensor        |
| `.unsqueeze(dim)`        | افزودن بُعد با اندازه ۱ |
| `.squeeze(dim)`          | حذف بُعد با اندازه ۱    |
| `.transpose(dim1, dim2)` | جابجایی دو بُعد         |
| `.permute(...)`          | تغییر ترتیب چند بُعد    |

---

## 🔹 اتصال و تقسیم Tensor

| تابع                              | توضیح                  |
| --------------------------------- | ---------------------- |
| `torch.cat((a, b), dim=...)`      | اتصال بدون بُعد جدید   |
| `torch.stack((a, b), dim=...)`    | اتصال با بُعد جدید     |
| `torch.split(tensor, chunk_size)` | تقسیم با اندازه دلخواه |
| `torch.chunk(tensor, chunks)`     | تقسیم به n قسمت برابر  |

---

## 🔹 ویژگی‌ها و متدهای کمکی

| متد                             | توضیح              |
| ------------------------------- | ------------------ |
| `.shape`, `.size()`             | ابعاد Tensor       |
| `.ndim`, `.dim()`               | تعداد ابعاد        |
| `.numel()`                      | تعداد کل عناصر     |
| `.dtype`                        | نوع داده           |
| `.device`                       | مکان (cpu یا cuda) |
| `.float()`, `.int()`, `.bool()` | تغییر نوع داده     |
| `.item()`                       | گرفتن مقدار تکی    |
| `.tolist()`                     | تبدیل به لیست      |
| `.clone()`                      | کپی مستقل          |
| `.detach()`                     | جدا از گرادیان     |
| `.numpy()`                      | تبدیل به NumPy     |
| `torch.from_numpy()`            | تبدیل از NumPy     |
