
# 📘 فصل ۲: آموزش مدل ساده با کد و تحلیل واقعی

### ✅ **صفحه ۳ – گسترش به مدل‌های چندمتغیره و درک ساختار برداری**

---

## 🎯 مقدمه:

تا اینجا فقط از **یک متغیر ورودی (x)** برای پیش‌بینی مقدار خروجی (y) استفاده کردیم.
اما در دنیای واقعی، متغیر هدف (مثل قیمت خانه، درآمد یا فروش) به عوامل زیادی وابسته است.

برای مثال:

> قیمت یک خانه = تابعی از **متراژ** + **تعداد اتاق** + **سال ساخت** + **موقعیت مکانی**

این یعنی نیاز به مدلی داریم که با چندین ویژگی کار کند.
اینجاست که **رگرسیون خطی چندمتغیره (Multiple Linear Regression)** وارد بازی می‌شود.

---

## 🧠 ۱. ساختار ریاضی مدل چندمتغیره

فرم کلی:

$$
y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_n x_n + \varepsilon
$$

یا در فرم برداری:

$$
\mathbf{y} = \mathbf{X} \boldsymbol{\beta} + \boldsymbol{\varepsilon}
$$

| نماد                         | مفهوم                 |
| ---------------------------- | --------------------- |
| y                            | بردار مشاهدات متغیر وابسته (n×1)      |
| X                            | (متغیر مستقل)ماتریس ویژگی‌ها (n×p)  |
| β                            | بردار ضرایب (p×1)     |
| ε                            | بردار خطاها (n×1)     |

---

## 📐 ۲. محاسبه ضرایب در رگرسیون چندمتغیره (OLS)

برای محاسبه ضرایب $\boldsymbol{\beta}$ از فرمول زیر استفاده می‌شود:

$$
\boldsymbol{\beta} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}
$$

> ⚠️ **شرط مهم:** ماتریس $\mathbf{X}^T \mathbf{X}$ باید معکوس‌پذیر باشد. این بدان معناست که نباید هم‌خطی شدید (Multicollinearity) بین ویژگی‌ها وجود داشته باشد. اگر ویژگی‌ها همبستگی بسیار بالایی با یکدیگر داشته باشند، ماتریس $\mathbf{X}^T \mathbf{X}$ معکوس‌پذیر نخواهد بود و در نتیجه محاسبه ضرایب با مشکل مواجه می‌شود.

---

## 🏠 ۳. مثال واقعی – پیش‌بینی قیمت خانه با ۳ ویژگی

فرض کنید دیتای زیر را داریم:

| x1 (Area) | x2 (Rooms) | x3 (Age) | y (Price) |
| --------- | ---------- | -------- | --------- |
| 100       | 3          | 10       | 1.2       |
| 120       | 4          | 5        | 1.6       |
| 90        | 2          | 15       | 1.0       |
| 110       | 3          | 8        | 1.4       |

برای محاسبه ضرایب، ابتدا ماتریس‌ها را می‌سازیم:

```python
import numpy as np

# Features (add intercept column manually)
X = np.array([
    [1, 100, 3, 10],
    [1, 120, 4, 5],
    [1, 90, 2, 15],
    [1, 110, 3, 8]
])

# Target
y = np.array([1.2, 1.6, 1.0, 1.4])

# Calculate beta using normal equation
X_T = X.T
beta = np.linalg.inv(X_T @ X) @ X_T @ y

print("Coefficients:", beta)
```

> خروجی: بردار ضرایب شامل:
>
> * Intercept
> * Effect of area
> * Effect of rooms
> * Effect of age

## 🤖 ۴. استفاده از Scikit-learn برای مدل‌سازی راحت‌تر

در بازار کار، استفاده از ابزارهایی مثل Scikit-learn استاندارد است. بیایید همان داده بالا را با Scikit-learn مدل‌سازی کنیم:

```python
from sklearn.linear_model import LinearRegression

# Remove intercept from X and add separately
X_features = np.array([
    [100, 3, 10],
    [120, 4, 5],
    [90, 2, 15],
    [110, 3, 8]
])
# Target
y = np.array([1.2, 1.6, 1.0, 1.4])

model = LinearRegression()
model.fit(X_features, y)

print("Intercept:", model.intercept_) #β ضریب
print("Coefficients:", model.coef_) #تأثیر هر یک از متغیرهای مستقل بر متغیر وابسته هستند
```

## 📊 ۵. تحلیل ضرایب مدل

فرض کنیم خروجی کد بالا این باشد:

```text
Intercept: 0.2
Coefficients: [0.01, 0.3, -0.02]
```

**تفسیر:**

* برای هر 1 متر مربع افزایش مساحت → قیمت 0.01 افزایش می‌یابد
* اضافه‌شدن یک اتاق → افزایش 0.3 واحد قیمت
* افزایش یک سال سن → کاهش 0.02 واحد قیمت

این تحلیل ساده نشان می‌دهد **هر ویژگی چقدر در تصمیم نهایی تأثیرگذار است.**

## ⚠️ ۶. چه زمانی این مدل ناکارآمد می‌شود؟

| مشکل              | راهکار پیشنهادی                         |
| ----------------- | --------------------------------------- |
| Multicollinearity | حذف یا ترکیب ویژگی‌ها، استفاده از Ridge |
| داده پرت زیاد     | استفاده از مدل‌های Robust               |
| رابطه غیرخطی      | Polynomial Regression یا مدل‌های غیرخطی |
| نویز بالا در داده | Regularization (Lasso, Ridge)           |
