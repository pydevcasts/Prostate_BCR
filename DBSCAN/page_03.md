
## 📖 فصل سوم: مثال عددی گام‌به‌گام

برای اینکه مفاهیم ریاضی الگوریتم DBSCAN شامل **Core Point**، **Border Point** و **Noise Point** بهتر درک شوند، یک مثال عددی ساده بررسی می‌کنیم.

---

### 🔹 داده‌های ما

فرض کنید پنج نقطه دوبعدی داریم:

| نقطه | مختصات (x, y) |
| ---- | ------------- |
| A    | (0,0)         |
| B    | (0,1)         |
| C    | (1,0)         |
| D    | (1.8,0)       |
| E    | (5,5)         |

و پارامترهای الگوریتم:

* $\varepsilon = 1.5$
* $\text{minPts}=4$

---

### 🔹 مرحله ۱: محاسبه فاصله‌ها

از فرمول فاصله اقلیدسی استفاده می‌کنیم:

$$
dist(p,q)=\sqrt{(x_p-x_q)^2+(y_p-y_q)^2}
$$
محاسبه فاصله‌ها:

* $dist(A,B)=\sqrt{(0-0)^2+(0-1)^2}=1$ ✅

* $dist(A,C)=\sqrt{(0-1)^2+(0-0)^2}=1$ ✅

* $dist(A,D)=\sqrt{(0-1.8)^2+(0-0)^2}=1.8$ ❌

* $dist(A,E)=\sqrt{50}\approx7.07$ ❌

* $dist(B,C)=\sqrt{2}\approx1.41$ ✅

* $dist(B,D)=\sqrt{(0-1.8)^2+(1-0)^2}=\sqrt{4.24}\approx2.06$ ❌

* $dist(B,E)=\sqrt{41}\approx6.40$ ❌

* $dist(C,D)=\sqrt{(1-1.8)^2}=0.8$ ✅

* $dist(C,E)=\sqrt{41}\approx6.40$ ❌

* $dist(D,E)=\sqrt{(1.8-5)^2+(0-5)^2}\approx5.94$ ❌

---

### 🔹 مرحله ۲: تشکیل همسایگی ε

با در نظر گرفتن $\varepsilon=1.5$، مجموعه همسایگی هر نقطه به صورت زیر است:

* $N_{\varepsilon}(A)={A,B,C}$ → تعداد = 3

* $N_{\varepsilon}(B)={A,B,C}$ → تعداد = 3

* $N_{\varepsilon}(C)={A,B,C,D}$ → تعداد = 4

* $N_{\varepsilon}(D)={C,D}$ → تعداد = 2

* $N_{\varepsilon}(E)={E}$ → تعداد = 1

---

### 🔹 مرحله ۳: تعیین نوع نقاط

با توجه به اینکه $\text{minPts}=4$ است:

* **C**: **Core Point** (زیرا تعداد همسایه‌ها برابر 4 است.)

* **A**: **Border Point** (خودش Core نیست، اما در همسایگی نقطه Core یعنی C قرار دارد.)

* **B**: **Border Point** (در همسایگی C قرار دارد.)

* **D**: **Border Point** (در همسایگی C قرار دارد، اما تعداد همسایه‌های خودش کمتر از minPts است.)

* **E**: **Noise Point** (تنها خودش در همسایگی قرار دارد و به هیچ Core Point متصل نیست.)

---

### 🔹 نتیجه خوشه‌بندی

* خوشه ۱ = {A, B, C, D}

* نقطه **C** = Core Point

* نقاط **A، B و D** = Border Point

* نویز = {E}

---

### 🔹 تفسیر نتایج

در این مثال، نقطه **C** به دلیل داشتن حداقل **minPts** همسایه، به عنوان **Core Point** شناخته می‌شود و هسته اصلی خوشه را تشکیل می‌دهد. نقاط **A، B و D** اگرچه تعداد همسایه‌های آن‌ها برای Core شدن کافی نیست، اما چون در همسایگی نقطه Core قرار گرفته‌اند، به عنوان **Border Point** به همان خوشه اختصاص داده می‌شوند. در مقابل، نقطه **E** هیچ ارتباطی با نقاط دیگر ندارد و به همین دلیل توسط الگوریتم به عنوان **Noise Point** یا داده پرت شناسایی می‌شود.
