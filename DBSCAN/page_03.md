## 📖 فصل سوم: مثال عددی گام‌به‌گام

برای اینکه مفاهیم ریاضی DBSCAN (Core Point، Border Point، Noise) بهتر درک بشن، یک مثال عددی ساده بررسی می‌کنیم.

---

### 🔹 داده‌های ما

فرض کنید چهار نقطه دوبعدی داریم:

| نقطه | مختصات (x, y) |
| ---- | ------------- |
| A    | (0,0)         |
| B    | (0,1)         |
| C    | (1,0)         |
| D    | (5,5)         |

و پارامترهای الگوریتم:

* $\varepsilon = 1.5$
* $\text{minPts} = 2$

---

### 🔹 مرحله ۱: محاسبه فاصله‌ها

از فرمول فاصله اقلیدسی استفاده می‌کنیم:

$$
dist(p, q) = \sqrt{(x_p - x_q)^2 + (y_p - y_q)^2}
$$

محاسبه فاصله‌ها:

* $dist(A,B) = \sqrt{(0-0)^2 + (0-1)^2} = 1$ ✅

* $dist(A,C) = \sqrt{(0-1)^2 + (0-0)^2} = 1$ ✅

* $dist(A,D) = \sqrt{(0-5)^2 + (0-5)^2} = \sqrt{50} \approx 7.07$ ❌

* $dist(B,C) = \sqrt{(0-1)^2 + (1-0)^2} = \sqrt{2} \approx 1.41$ ✅

* $dist(B,D) = \sqrt{(0-5)^2 + (1-5)^2} = \sqrt{41} \approx 6.40$ ❌

* $dist(C,D) = \sqrt{(1-5)^2 + (0-5)^2} = \sqrt{41} \approx 6.40$ ❌

---

### 🔹 مرحله ۲: تشکیل همسایگی ε

با $\varepsilon = 1.5$:

* $N_\varepsilon(A) = \{ A, B, C \}$ → تعداد = 3
* $N_\varepsilon(B) = \{ A, B, C \}$ → تعداد = 3
* $N_\varepsilon(C) = \{ A, B, C \}$ → تعداد = 3
* $N_\varepsilon(D) = \{ D \}$ → تعداد = 1

---

### 🔹 مرحله ۳: تعیین نوع نقاط

* **A**: Core Point (چون 3 ≥ 2)
* **B**: Core Point (چون 3 ≥ 2)
* **C**: Core Point (چون 3 ≥ 2)
* **D**: Noise (چون فقط خودش تو همسایگیه → 1 < 2)

---

### 🔹 نتیجه خوشه‌بندی

* خوشه ۱ = {A, B, C}
* نویز = {D}

---

✅ این مثال نشون می‌ده DBSCAN چطور می‌تونه سه نقطه نزدیک رو توی یک خوشه بذاره و نقطه دورافتاده (D) رو به عنوان نویز تشخیص بده.
