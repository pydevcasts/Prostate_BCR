## آموزش الگوریتم‌های یادگیری ماشین

این پروژه به‌منظور ارائه‌ی یک راهنمای جامع و مرحله‌به‌مرحله برای الگوریتم‌های یادگیری ماشین طراحی شده است. هدف ما این است که منابع و راهنماهای مفیدی را برای یادگیری ایرانی‌زبان‌ها فراهم کنیم.

### محتویات

- توضیحات کامل هر الگوریتم
- مثال‌های عملی
- توضیحات گام به گام
- کدهای نمونه به زبان پایتون
