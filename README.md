 
This GitHub repository, "ML_Doc", is a comprehensive guide for learning machine learning algorithms, primarily aimed at Persian-speaking learners. The project aims to provide a step-by-step guide, detailed explanations, practical examples, and sample code in Python for various machine learning algorithms.

### Main Function Points
- Provide detailed explanations of different machine learning algorithms
- Include practical examples and sample code in Python
- Cater to Persian-speaking learners by offering resources in their native language
- Cover a wide range of topics, such as regression, classification, neural networks, and decision trees

### Technology Stack
- Python
- Jupyter Notebook
