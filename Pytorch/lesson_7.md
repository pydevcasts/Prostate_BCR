

## 🔹 صفحه ۷ — توابع فعال‌سازی و تبدیل نوع داده‌ها در PyTorch

📌 شامل: `relu()`, `sigmoid()`, `tanh()` و `.float()`, `.int()`, `.bool()`

---

### 🎯 چرا توابع فعال‌سازی مهم‌اند؟

توابع فعال‌سازی (Activation Functions) قلب مدل‌های یادگیری عمیق هستند. آن‌ها به مدل کمک می‌کنند **غیرخطی** شود و بتواند الگوهای پیچیده را یاد بگیرد.

در این صفحه، کاربرد این توابع را با داده‌های ساده و بدون شبکه عصبی تمرین می‌کنیم تا **رفتار عددی آن‌ها را بفهمیم**.

---

## 🔸 تابع `relu()` — Rectified Linear Unit

این تابع مقدارهای منفی را صفر می‌کند و مقدارهای مثبت را بدون تغییر نگه می‌دارد.

```python
import torch
import torch.nn.functional as F

x = torch.tensor([-3.0, -1.0, 0.0, 2.0, 5.0])

# Apply ReLU
output = F.relu(x)

print(output)
```

خروجی:

```
tensor([0., 0., 0., 2., 5.])
```

---

## 🔸 تابع `sigmoid()`

این تابع مقدارهای ورودی را به عددی بین ۰ و ۱ نگاشت می‌کند. مناسب برای مدل‌های دودویی.

```python
x = torch.tensor([-5.0, 0.0, 5.0])

output = torch.sigmoid(x)

print(output)
```

خروجی:

```
tensor([0.0067, 0.5000, 0.9933])
```

---

## 🔸 تابع `tanh()`

این تابع مقادیر را به بازه بین -1 و 1 محدود می‌کند. نسبت به sigmoid خروجی متقارن‌تری دارد.

```python
x = torch.tensor([-2.0, 0.0, 2.0])

output = torch.tanh(x)

print(output)
```

خروجی:

```
tensor([-0.9640,  0.0000,  0.9640])
```

---

## 🧪 مقایسه سریع:

| تابع      | بازه خروجی | کاربرد                              |
| --------- | ---------- | ----------------------------------- |
| `ReLU`    | \[0, ∞)    | ساده، سریع، رایج در شبکه‌ها         |
| `Sigmoid` | (0, 1)     | خروجی‌های دودویی                    |
| `Tanh`    | (-1, 1)    | مدل‌های متقارن یا داده‌های centered |

---

## 🔸 تبدیل نوع داده Tensorها

گاهی لازم است نوع داده را برای محاسبات یا هماهنگی تغییر دهیم. PyTorch این کار را با متدهایی ساده فراهم می‌کند:

```python
x = torch.tensor([1, 0, 1])

print(x.float())   # Convert to float32
print(x.bool())    # Convert to boolean
print(x.long())    # Convert to int64
```

---

## 🔸 بررسی نوع داده و ویژگی‌های Tensor

```python
print(x.dtype)     # Shows current data type
print(x.type())    # Full type as string
```

## 📘 تمرین پیشنهادی:

۱. یک Tensor شامل مقادیر منفی و مثبت بسازید و ReLU روی آن اعمال کنید.
۲. یک لیست از اعداد تصادفی ایجاد کنید و Sigmoid و Tanh روی آن‌ها تست کنید.
۳. یک Tensor از ۰ و ۱ بسازید و آن را به boolean و سپس به float تبدیل کنید.
