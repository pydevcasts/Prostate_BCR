
## 🔹 صفحه ۳ — عملیات ریاضی پایه روی Tensorها در PyTorch

---

### 🎯 چرا عملیات ریاضی مهم هستند؟

در اکثر مدل‌های یادگیری ماشین، مقداردهی اولیه، تغییر داده‌ها، و به‌روزرسانی پارامترها بر پایه عملیات ریاضی انجام می‌شود. در PyTorch، این عملیات می‌توانند روی **تنسورها** به سادگی و با کارایی بالا انجام شوند.

---

## ✳️ روش‌های اجرای عملیات ریاضی در PyTorch

شما می‌توانید از:

* عملگرهای Python (مانند `+`, `-`, `*`, `/`)
* توابع داخلی PyTorch (مانند `torch.add`, `torch.mul` و غیره)

استفاده کنید.

---

## 🔸 جمع دو Tensor — `+` یا `torch.add()`

```python
import torch

a = torch.tensor([1, 2, 3])
b = torch.tensor([4, 5, 6])

# Method 1: Using +
print(a + b)

# Method 2: Using torch.add
print(torch.add(a, b))
```

✅ هر دو روش نتیجه مشابه می‌دهند:

```
tensor([5, 7, 9])
```

---

## 🔸 تفریق — `-` یا `torch.sub()`

```python
print(a - b)              # Method 1
print(torch.sub(a, b))    # Method 2
```

خروجی:

```
tensor([-3, -3, -3])
```

---

## 🔸 ضرب عنصر به عنصر — `*` یا `torch.mul()`

```python
print(a * b)
print(torch.mul(a, b))
```

خروجی:

```
tensor([ 4, 10, 18])
```

---

## 🔸 تقسیم عنصر به عنصر — `/` یا `torch.div()`

```python
print(a / b)
print(torch.div(a, b))
```

خروجی:

```
tensor([0.2500, 0.4000, 0.5000])
```

---

## 🔸 توان (توان رساندن) — `**` یا `torch.pow()`

```python
print(a ** 2)             # Each element squared
print(torch.pow(a, 2))
```

خروجی:

```
tensor([1, 4, 9])
```

---

## 🔍 نکته مهم در Broadcasting:

اگر اندازه دو Tensor متفاوت ولی قابل هم‌ترازی باشد، PyTorch به‌صورت خودکار آن‌ها را با **Broadcasting** یکسان می‌کند:

```python
a = torch.tensor([[1, 2, 3], [4, 5, 6]])
b = torch.tensor([10, 20, 30])

print(a + b)
```

خروجی:

```
tensor([[11, 22, 33],
        [14, 25, 36]])
```

✅ بردار b به‌طور خودکار به اندازه a گسترش می‌یابد.
