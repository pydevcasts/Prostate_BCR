## 🔹 صفحه ۱۲ — متدهای کمکی مهم در PyTorch

📌 شامل: `.item()`, `.tolist()`, `.clone()`, `.detach()`

---

### 🎯 چرا این متدها مهم‌اند؟

در کار با داده‌ها، گاهی لازم است:

* مقدار عددی یک Tensor را به‌صورت `float` یا `int` ساده استخراج کنیم
* کل Tensor را به لیست پایتونی تبدیل کنیم
* از Tensor نسخه‌ی مستقل برای جلوگیری از تغییرات ناخواسته بسازیم
* یک Tensor را از **جریان محاسبه گرادیان** جدا کنیم

---

## 🔸 `.item()` — تبدیل Tensor با یک مقدار به عدد ساده

```python
import torch

x = torch.tensor([7.5])

# Extract value as a float
val = x.item()

print(val)
print(type(val))
```

خروجی:

```
7.5
<class 'float'>
```

✅ فقط روی Tensorهایی با **یک مقدار تکی** قابل استفاده است.

---

## 🔸 `.tolist()` — تبدیل Tensor به لیست پایتونی

```python
x = torch.tensor([[1, 2], [3, 4]])

lst = x.tolist()

print(lst)
```

خروجی:

```
[[1, 2], [3, 4]]
```

✅ مناسب برای تبدیل داده برای استفاده در کتابخانه‌هایی مثل pandas یا matplotlib

---

## 🔸 `.clone()` — ساخت کپی کامل از Tensor

```python
x = torch.tensor([10, 20, 30])
y = x.clone()

x[0] = 99

print(x)  # tensor([99, 20, 30])
print(y)  # tensor([10, 20, 30])
```

✅ با استفاده از `.clone()` یک نسخه مستقل از Tensor ایجاد می‌شود.

---

## 🔸 `.detach()` — جدا کردن Tensor از جریان گرادیان (Autograd)

در مدل‌های یادگیری عمیق، گاهی لازم است یک Tensor را از مسیر محاسبه گرادیان جدا کنیم تا در Backpropagation درگیر نشود.

```python
x = torch.tensor([1.0, 2.0, 3.0], requires_grad=True)
y = x * 2

# Detach y from autograd
z = y.detach()

print(z)
```

✅  دیگر `z` در مسیر گرادیان نیست و تغییرات آن اثری در محاسبات گرادیان نخواهد داشت.

---

## 🔍 جمع‌بندی سریع:

| متد         | کاربرد                              | نکته                         |
| ----------- | ----------------------------------- | ---------------------------- |
| `.item()`   | گرفتن مقدار عددی از Tensor تک‌عنصری | فقط برای Tensor با یک مقدار  |
| `.tolist()` | تبدیل Tensor به لیست پایتونی        | برای تبدیل به فرمت‌های معمول |
| `.clone()`  | ایجاد نسخه مستقل                    | بدون وابستگی به حافظه قبلی   |
| `.detach()` | جدا شدن از مسیر Autograd            | استفاده در آموزش مدل‌ها      |

---

## 📘 تمرین پیشنهادی:

۱. یک Tensor با یک مقدار بسازید و با `.item()` آن را به عدد ساده تبدیل کنید.
۲. یک Tensor دوبعدی ساخته و با `.tolist()` آن را به لیست تبدیل کنید.
۳. یک Tensor بسازید، با `.clone()` کپی بگیرید، عنصر یکی را تغییر دهید و تفاوت را ببینید.
۴. یک Tensor با `requires_grad=True` بسازید و سپس از `.detach()` برای جدا کردن استفاده کنید.
