
## 🔹 صفحه ۱۶ — توابع فعال‌سازی و ساختار مدل با `nn.Sequential`

---

### 🎯 چرا باید از توابع فعال‌سازی استفاده کنیم؟

در مدل‌های یادگیری عمیق، اگر فقط لایه‌های `Linear` استفاده شوند، **مدل شما صرفاً یک تابع خطی خواهد بود** که قدرت یادگیری الگوهای پیچیده را ندارد.

✅ توابع فعال‌سازی (Activation Functions) باعث ایجاد **غیرخطی بودن در مدل** می‌شوند و قابلیت مدل را برای یادگیری بهتر به‌شدت افزایش می‌دهند.

---

## 🔸 استفاده از `nn.ReLU()`

در صفحه قبلی، از `torch.relu(x)` استفاده کردیم. اما روش رسمی‌تر در تعریف مدل این است که از نسخه ماژولی آن یعنی `nn.ReLU()` استفاده کنیم.

```python
import torch.nn as nn

class ModelWithReLU(nn.Module):
    def __init__(self):
        super().__init__()
        self.layer1 = nn.Linear(10, 5)
        self.relu = nn.ReLU()
        self.layer2 = nn.Linear(5, 1)

    def forward(self, x):
        x = self.layer1(x)
        x = self.relu(x)
        x = self.layer2(x)
        return x
```

---

## 🔸 سایر توابع فعال‌سازی در `torch.nn`

| تابع                | کاربرد                                         | بازه خروجی        |
| ------------------- | ---------------------------------------------- | ----------------- |
| `nn.ReLU()`         | رایج‌ترین و سریع‌ترین                          | \[0, ∞)           |
| `nn.Sigmoid()`      | مدل‌های دودویی                                 | (0, 1)            |
| `nn.Tanh()`         | داده‌های centered                              | (-1, 1)           |
| `nn.LeakyReLU()`    | ReLU بهبود‌یافته (مقدار منفی کوچک نگه می‌دارد) | (-∞, ∞)           |
| `nn.Softmax(dim=?)` | خروجی طبقه‌بندی چندکلاسه                       | (0, 1) با مجموع ۱ |

## 🔸 ساختاردهی تمیزتر با `nn.Sequential`

برای مدل‌هایی که مسیر مستقیم و ساده دارند (بدون شاخه یا شرط)، می‌توان از `nn.Sequential` استفاده کرد.

```python
model = nn.Sequential(
    nn.Linear(10, 5),
    nn.ReLU(),
    nn.Linear(5, 1)
)
```

✅ حالا شما بدون نیاز به تعریف کلاس جداگانه، یک مدل کامل دارید.

---

## 🔸 اجرای مدل و مشاهده خروجی

```python
x = torch.rand(3, 10)  # Batch of 3 samples with 10 features
out = model(x)

print(out.shape)
```

خروجی:

```
torch.Size([3, 1])
```

## 🔍 مقایسه: کلاس سفارشی vs nn.Sequential

| ویژگی                         | `nn.Module` با کلاس | `nn.Sequential`         |
| ----------------------------- | ------------------- | ----------------------- |
| انعطاف بالا                   | ✅ بله               | ❌ محدود به forward ساده |
| مناسب مدل‌های پیچیده          | ✅                   | ❌                       |
| خوانایی سریع                  | متوسط               | بسیار بالا              |
| پشتیبانی از شرط‌ها و چند مسیر | ✅ بله               | ❌ خیر                   |
