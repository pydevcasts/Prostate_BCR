## 🔹 صفحه ۲۸ — لایه‌های کانولوشن `nn.Conv2d` و کاهش ابعاد با `nn.MaxPool2d`

📌 مناسب برای تصاویر، بینایی کامپیوتر و تشخیص الگوهای فضایی

---

### 🎯 چرا از CNN استفاده می‌شود؟

در مسائل تصویری یا ورودی‌های دوبعدی (مانند تصویر، داده پزشکی، نقشه‌ها و…) استفاده از لایه‌های معمولی `Linear` مناسب نیست، چون:

* وابستگی به **موقعیت مکانی پیکسل‌ها** نادیده گرفته می‌شود
* تعداد پارامترها بسیار زیاد می‌شود
* ساختار فضایی (مثل خطوط یا گوشه‌ها) تشخیص داده نمی‌شود

✅ در مقابل، **لایه‌های کانولوشن (Conv2d)** این محدودیت‌ها را برطرف می‌کنند.

---

## 🔸 معرفی `nn.Conv2d`

```python
import torch.nn as nn

conv = nn.Conv2d(in_channels=1, out_channels=8, kernel_size=3, stride=1, padding=1)
```

| پارامتر        | توضیح                                                               |
| -------------- | ------------------------------------------------------------------- |
| `in_channels`  | تعداد کانال‌های ورودی (مثلاً ۱ برای تصاویر سیاه‌وسفید، ۳ برای رنگی) |
| `out_channels` | تعداد فیلترها (ویژگی‌هایی که مدل یاد می‌گیرد)                       |
| `kernel_size`  | اندازه فیلتر (مثلاً ۳x۳)                                            |
| `stride`       | گام حرکت فیلتر روی تصویر                                            |
| `padding`      | اضافه کردن صفر دور تصویر برای حفظ ابعاد                             |

---

## 🔸 نمونه ورودی و خروجی

```python
import torch

x = torch.rand(1, 1, 28, 28)  # batch=1, channel=1, height=28, width=28
out = conv(x)

print(out.shape)  # torch.Size([1, 8, 28, 28])
```

✅ اگر `stride=1` و `padding=1` باشد، ابعاد ثابت می‌ماند.

---

## 🔸 معرفی `nn.MaxPool2d`

برای کاهش ابعاد و استخراج ویژگی‌های مهم استفاده می‌شود:

```python
pool = nn.MaxPool2d(kernel_size=2, stride=2)

x = torch.rand(1, 8, 28, 28)
out = pool(x)

print(out.shape)  # torch.Size([1, 8, 14, 14])
```

✅ هر بار، اندازه‌ی تصویر نصف می‌شود
✅ عملیات max در هر ناحیه کوچک اعمال می‌شود

---

## 🔸 استفاده ترکیبی: Conv + ReLU + Pool

```python
model = nn.Sequential(
    nn.Conv2d(1, 8, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(2)
)
```

ورودی: `[1, 1, 28, 28]` → خروجی: `[1, 8, 14, 14]`

---

## 🔍 مثال عملی

```python
x = torch.rand(4, 1, 28, 28)  # batch of 4 grayscale images

conv_layer = nn.Conv2d(1, 16, kernel_size=5, padding=2)
pool_layer = nn.MaxPool2d(2)

x = conv_layer(x)
x = torch.relu(x)
x = pool_layer(x)

print(x.shape)  # torch.Size([4, 16, 14, 14])
```
