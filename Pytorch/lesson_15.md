### 🎯 چرا `nn.Module` مهم است؟

کتابخانه‌ی `torch.nn` پایه‌ی ساخت مدل‌های یادگیری عمیق در PyTorch است.
در این فصل یاد می‌گیریم که چگونه با استفاده از **کلاس `nn.Module`** یک **مدل قابل آموزش** بسازیم.

این ساختار باعث می‌شود:

* تمام **لایه‌ها و پارامترها** در یک جا تعریف شوند
* عملیات پیش‌رو (forward) را به‌سادگی تعریف کنیم
* از توابع آماده‌ی PyTorch برای بهینه‌سازی، Loss و... بهره ببریم

---

## 🔸 وارد کردن ماژول‌ها و آماده‌سازی

```python
import torch
import torch.nn as nn
```

---

## 🔸 تعریف یک مدل ساده با ارث‌بری از `nn.Module`

در PyTorch، ساخت مدل یعنی ایجاد یک کلاس که از `nn.Module` ارث می‌برد و شامل:

1. تابع `__init__` برای تعریف لایه‌ها
2. تابع `forward()` برای تعریف عملیات عبور داده از لایه‌ها

---

### ✅ مثال: مدل ساده با دو لایه Linear

```python
class MyModel(nn.Module):
    def __init__(self):
        super(MyModel, self).__init__()
        self.layer1 = nn.Linear(10, 5)
        self.layer2 = nn.Linear(5, 1)

    def forward(self, x):
        x = self.layer1(x)
        x = torch.relu(x)
        x = self.layer2(x)
        return x
```

---

### 📘 خط به خط:

| خط کد                      | توضیح                                    |
| -------------------------- | ---------------------------------------- |
| `class MyModel(nn.Module)` | تعریف کلاس مدل با ارث‌بری                |
| `super(...)`               | فراخوانی کلاس پدر (`nn.Module`)          |
| `nn.Linear(10, 5)`         | لایه‌ی خطی با ورودی ۱۰ و خروجی ۵         |
| `forward()`                | مسیر عبور داده از لایه‌ها را مشخص می‌کند |
| `torch.relu()`             | تابع فعال‌سازی ReLU بین لایه‌ها          |

---

## 🔸 ساخت یک شیء از مدل و اجرای آن روی داده

```python
model = MyModel()

# Create dummy input with shape [batch_size, features] = [2, 10]
x = torch.rand(2, 10)

# Pass input through model
output = model(x)

print(output.shape)
```

خروجی:

```
torch.Size([2, 1])
```

✅ یعنی دو ورودی → دو خروجی تک‌مقداری (مطابق لایه‌ی نهایی مدل)

## 🔸 چرا از کلاس استفاده می‌کنیم؟

مزایای ساختار کلاس `nn.Module`:

* کد تمیزتر و ماژولار
* قابلیت ذخیره و بارگذاری آسان
* امکان استفاده در مدل‌های پیچیده‌تر (CNN, RNN, ...)
* پشتیبانی از توابع داخلی PyTorch مثل `.to()`, `.eval()`, `.train()`
