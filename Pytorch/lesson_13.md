
## 🔹 صفحه ۱۳ — مدیریت ابعاد با `.squeeze()` و `.unsqueeze()`

---

### 🎯 چرا `.squeeze()` و `.unsqueeze()` مهم هستند؟

در PyTorch، گاهی داده‌ها ابعادی دارند که از نظر ریاضی **ضروری نیستند** (مثل `[1, 3, 1, 5]`)، ولی برای هماهنگی با شکل ورودی مدل یا هنگام استفاده از توابع خاص، باید:

* یک بُعد را **اضافه کنیم** (`unsqueeze`)
* یا یک بُعد **اضافی و غیرضروری را حذف کنیم** (`squeeze`)

این دو متد دقیقاً برای این هدف طراحی شده‌اند.

---

## 🔸 اضافه کردن بُعد جدید — `.unsqueeze(dim)`

این تابع یک بُعد از اندازه ۱ را **در مکان دلخواه** اضافه می‌کند.

```python
import torch

x = torch.tensor([1.0, 2.0, 3.0])   # Shape: [3]

x1 = x.unsqueeze(0)  # Add dimension at position 0 → shape [1, 3]
x2 = x.unsqueeze(1)  # Add dimension at position 1 → shape [3, 1]

print(x1.shape)
print(x2.shape)
```

خروجی:

```
torch.Size([1, 3])
torch.Size([3, 1])
```

---

## 🔸 حذف ابعاد با اندازه ۱ — `.squeeze()`

این تابع **تمام ابعاد با اندازه ۱** را حذف می‌کند. همچنین می‌توان به آن `dim` داد تا فقط از یک مکان خاص حذف کند.

```python
x = torch.zeros(1, 3, 1, 5)  # Shape: [1, 3, 1, 5]

y = x.squeeze()              # Remove all size-1 dims → shape [3, 5]
z = x.squeeze(dim=2)         # Remove only dim=2 if it's size 1

print(y.shape)
print(z.shape)
```

---

## 🔸 مثال ترکیبی

```python
x = torch.tensor([[1.0, 2.0, 3.0]])  # Shape: [1, 3]

# Add one dimension
x2 = x.unsqueeze(2)                 # Shape: [1, 3, 1]

# Remove the same dimension
x3 = x2.squeeze(2)                  # Back to [1, 3]

print(x3.shape)
```

---

## 🔍 چه زمانی این متدها ضروری هستند؟

| کاربرد                                                   | توضیح                                                     |
| -------------------------------------------------------- | --------------------------------------------------------- |
| مدل‌هایی که فقط ورودی `[batch_size, features]` می‌پذیرند | گاهی لازم است `.unsqueeze(0)` اضافه کنیم                  |
| کاهش خروجی مدل برای محاسبه Loss                          | گاهی با `.squeeze()` خروجی را تک‌بعدی می‌کنیم             |
| تطبیق داده با شکل یکسان                                  | هنگام اتصال یا اعمال توابع مثل `cat()`, `matmul()` و غیره |

## 📘 تمرین پیشنهادی:

۱. یک Tensor با شکل `[3]` بسازید و آن را به `[1, 3]` و سپس `[3, 1]` تبدیل کنید.
۲. یک Tensor با ابعاد `[1, 4, 1, 6]` بسازید و با `.squeeze()` آن را به شکل ساده‌تر درآورید.
۳. یک Tensor با شکل `[2, 1, 5]` ایجاد کرده و فقط بُعد وسط (با اندازه ۱) را حذف کنید.
