## 🧠 ۳. تمرین ترکیبی — اجرای هم‌زمان چند روش

می‌خوایم با یه دیتاست واقعی (Digits) چند روش کاهش بُعد رو با هم اجرا کنیم و نتایج رو مقایسه کنیم 🔍

```python
from sklearn.datasets import load_digits
from sklearn.decomposition import PCA
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis
from sklearn.manifold import TSNE
import umap
import matplotlib.pyplot as plt

# داده‌ها
digits = load_digits()
X = digits.data
y = digits.target

# اجرای PCA
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X)

# اجرای LDA
lda = LinearDiscriminantAnalysis(n_components=2)
X_lda = lda.fit_transform(X, y)

# اجرای t-SNE
tsne = TSNE(n_components=2, random_state=42)
X_tsne = tsne.fit_transform(X)

# اجرای UMAP
reducer = umap.UMAP(n_components=2, random_state=42)
X_umap = reducer.fit_transform(X)

# رسم نتایج
fig, axes = plt.subplots(2, 2, figsize=(12,10))
axes[0,0].scatter(X_pca[:,0], X_pca[:,1], c=y, cmap='tab10', s=10)
axes[0,0].set_title('PCA')

axes[0,1].scatter(X_lda[:,0], X_lda[:,1], c=y, cmap='tab10', s=10)
axes[0,1].set_title('LDA')

axes[1,0].scatter(X_tsne[:,0], X_tsne[:,1], c=y, cmap='tab10', s=10)
axes[1,0].set_title('t-SNE')

axes[1,1].scatter(X_umap[:,0], X_umap[:,1], c=y, cmap='tab10', s=10)
axes[1,1].set_title('UMAP')

plt.suptitle("مقایسه‌ی روش‌های مختلف کاهش ابعاد")
plt.show()
```

📊 **نتیجه:**

* PCA ساختار کلی رو نشون می‌ده.
* LDA مرز بین کلاس‌ها رو واضح‌تر می‌کنه.
* t-SNE و UMAP خوشه‌های طبیعی داده‌ها رو به‌صورت بصری زیبا نمایش می‌دن 🌈

## 📘 ۴. نکات حرفه‌ای برای استفاده از روش‌های کاهش بُعد
