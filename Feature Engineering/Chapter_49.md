## 📘 ۱. مرور و مقایسه‌ی روش‌های Encoding

| روش                  | توضیح کوتاه                             | مزیت‌ها                    | محدودیت‌ها                         | زمان استفاده                                |
| :------------------- | :-------------------------------------- | :------------------------- | :--------------------------------- | :------------------------------------------ |
| **Label Encoding**   | هر دسته به عددی یکتا نگاشت می‌شود       | سریع، ساده                 | ایجاد ارتباط ترتیبی دروغین         | داده‌های **ترتیبی (Ordinal)** مثل رتبه‌بندی |
| **One-Hot Encoding** | هر دسته به چند ستون باینری تبدیل می‌شود | بدون ترتیب، قابل تفسیر     | افزایش ابعاد داده                  | داده‌های **غیربترتیبی** با دسته‌های کم      |
| **Target Encoding**  | میانگین مقدار هدف برای هر دسته          | حفظ ارتباط با خروجی، فشرده | خطر Overfitting، نیازمند هموارسازی | مدل‌های آماری یا درختی با داده زیاد         |
| **Hash Encoding**    | نگاشت مقادیر با تابع هش                 | سریع و مقیاس‌پذیر          | امکان Collision، غیرقابل تفسیر     | داده‌های **بزرگ یا با دسته‌های زیاد**       |

---

## 💡 ۲. انتخاب بهترین روش بر اساس نوع داده

| وضعیت داده                     | بهترین روش               |
| :----------------------------- | :----------------------- |
| تعداد دسته‌ها کمتر از ۱۰       | One-Hot Encoding         |
| داده دارای ترتیب واقعی         | Label Encoding           |
| داده حجیم با صدها دسته         | Hash Encoding            |
| ارتباط قوی بین دسته و Target   | Target Encoding          |
| مدل مبتنی بر درخت (Tree-Based) | Target یا Label Encoding |
| مدل خطی (Linear/SVM)           | One-Hot Encoding         |

---

## ⚠️ ۳. اشتباهات رایج در Encoding

🚫 استفاده از Label Encoding برای داده‌های غیرترتیبی
🚫 انجام Encoding روی کل داده (نه فقط Train) که باعث **نشت اطلاعات (Data Leakage)** می‌شود
🚫 استفاده از One-Hot برای داده‌های حجیم → افزایش بیش از حد ابعاد
🚫 نادیده گرفتن Smoothing در Target Encoding

---

## 🔧 ۴. نکات طلایی و ترفندهای حرفه‌ای

✨ همیشه نوع مدل رو در انتخاب Encoding لحاظ کن.
✨ اگر تعداد دسته‌ها خیلی زیاد بود، Hash Encoding انتخاب خوبی‌ه.
✨ برای داده‌های حساس به توزیع Target، از Target Encoding با smoothing استفاده کن.
✨ همیشه از `fit` روی داده‌ی Train و `transform` روی Test استفاده کن.
✨ در پروژه‌های واقعی، **mapping** روش انتخابی رو ذخیره کن تا در آینده همون‌طور تکرار بشه.

## 🎨 تصویر پیشنهادی

> نموداری چهارتایی با چهار بلوک رنگی که هرکدام نشان‌دهنده‌ی یکی از روش‌های Encoding است:
>
> * Label: عددهای ساده
> * One-Hot: ماتریس صفر و یک
> * Target: رنگ‌های گرادیانی (بین ۰ تا ۱)
> * Hash: اعداد تصادفی رنگی

---

### 💬 گفت‌وگوی استاد و دانشجو 🎓

👩‍🎓 استاد، پس کِی باید One-Hot رو انتخاب کنم؟
👨‍🏫 وقتی دسته‌ها کم‌ان و ترتیب ندارن. مثلاً رنگ، کشور، یا جنسیت.
👩‍🎓 و Target Encoding؟
👨‍🏫 اون‌موقع که می‌خوای رابطه‌ی مستقیم دسته با هدف رو حفظ کنی، مخصوصاً توی مدل‌های درختی.
👩‍🎓 و اگه داده‌م خیلی بزرگ باشه؟
👨‍🏫 اون‌جا دیگه وقتشه Hash Encoding وارد بشه ⚡
