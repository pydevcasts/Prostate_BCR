### 🧮 راه‌حل: Scaling و Normalization

| مفهوم                                | توضیح کوتاه                                                        |
| :----------------------------------- | :----------------------------------------------------------------- |
| ⚖️ **Scaling (مقیاس‌سازی)**          | همه‌ی ویژگی‌ها رو در یک بازه‌ی عددی مشخص (مثلاً ۰ تا ۱) قرار می‌ده |
| 🧘‍♂️ **Normalization (نرمال‌سازی)** | ویژگی‌ها رو طوری تنظیم می‌کنه که مجموع یا طول بردار برابر ۱ بشه    |

---

### 🔢 تفاوت ساده با مثال

| نوع           | مثال عددی                                                 | نتیجه                |
| :------------ | :-------------------------------------------------------- | :------------------- |
| Scaling       | اگر مقدار ۵۰ از بازه ۰ تا ۱۰۰ باشه → بعد از Scaling = ۰.۵ | تنظیم بازه           |
| Normalization | اگر داده‌ها [3,4] باشن → بعد از نرمال‌سازی = [0.6, 0.8]   | تنظیم طول بردار به ۱ |

---

### 💻 کد نمونه: StandardScaler

```python
from sklearn.preprocessing import StandardScaler
import pandas as pd

data = pd.DataFrame({
    'Age': [20, 30, 40, 50, 60],
    'Income': [20000, 35000, 50000, 80000, 100000]
})

scaler = StandardScaler()
scaled = scaler.fit_transform(data)
print(scaled)
```

📊 خروجی نمونه:

```
[[-1.26, -1.23],
 [-0.63, -0.82],
 [ 0.00, -0.40],
 [ 0.63,  0.82],
 [ 1.26,  1.63]]
```

یعنی هر ستون به شکلی تغییر کرده که میانگینش صفر و انحراف معیارش یک شده ⚙️
