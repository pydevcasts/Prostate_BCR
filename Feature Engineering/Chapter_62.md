## 🔵 ۱. مفهوم Ordinal Encoding 

 یعنی **دادن یک ترتیب واقعی و منطقی به دسته‌ها**
بر خلاف Label Encoding که تصادفی دسته‌ها را به عدد تبدیل می‌کند.

 برای دسته‌هایی است که **چیدمان طبیعی دارند**:

```
Low < Medium < High  
Poor < Fair < Good < Excellent  
S < M < L < XL  
```

این‌ها کاملاً ترتیب‌دار هستند و مدل باید این ترتیب را بداند.

---

## 🔵 ۲. چرا Ordinal Encoding بسیار مهم است؟

زیرا اگر دادهٔ ترتیبی را One-Hot کنی:

❌ مدل متوجه اندازه و سطح نمی‌شود
❌ تفاوت "S" با "XL" را نمی‌فهمد
❌ زیرساخت ترتیب از بین می‌رود

اما با Ordinal:

✔️ مدل می‌فهمد XL از M بزرگ‌تر است
✔️ روابط ریاضی حفظ می‌شود
✔️ برای مدل‌های خطی و درختی فوق‌العاده کاربردی است

---

## 🔥 ۳. مثال عددی (خیلی مهم)

داریم:

| Size |
| ---- |
| S    |
| M    |
| L    |
| S    |
| XL   |

اگر One-Hot کنیم:

```
S   → 1 0 0 0
M   → 0 1 0 0
L   → 0 0 1 0
XL  → 0 0 0 1
```

ترتیب مثل قبل از بین می‌رود.
مدل نمی‌فهمد XL از L بزرگ‌تر است.

اما Ordinal Encoding:

```
S  → 0
M  → 1
L  → 2
XL → 3
```

این بهترین و صحیح‌ترین حالت است.

---

## 🟣 ۴. بهترین روش ساخت Ordinal Encoding

اگر ترتیب مشخص است → مستقیم تعریف کن.

اگر ترتیب نامشخص است → از این روش استفاده کن:

✔️ میانگین "Target" را برای هر دسته حساب کن
✔️ دسته‌ها را مرتب کن
✔️ عدد بده

مثلاً در یک دیتاست واقعی:

| Quality | Avg Price |
| ------- | --------- |
| Low     | 100$      |
| Medium  | 150$      |
| High    | 220$      |

نتیجه:

```
Low → 0  
Medium → 1  
High → 2  
```

این روش به آن می‌گویند:
🔥 **Target-Based Ordinal Encoding**
و در مدل‌سازی واقعی فوق‌العاده قدرتمند است.

---

## 💻 ۵. کد پایتون — پیاده‌سازی Ordinal Encoding

```python
import pandas as pd

data = pd.DataFrame({
    "size": ["S", "M", "XL", "L", "S"]
})

# تعریف ترتیب صحیح
order = ["S", "M", "L", "XL"]

# تبدیل ترتیبی
data["size_ord"] = data["size"].astype("category").cat.set_categories(order).cat.codes

print(data)
```

## ⚠️ ۶. نکات مهم در پروژه‌های واقعی

### ✔️ نکته ۱

در مدل‌های درختی مثل XGBoost، LightGBM
Ordinal بهترین عملکرد را دارد.

### ✔️ نکته ۲

اگر ترتیب ندانیم ولی به‌زور Ordinal بدهیم:
❌ مدل دچار جهت‌گیری مصنوعی می‌شود
❌ رفتار مدل غیرقابل پیش‌بینی می‌شود

### ✔️ نکته ۳

در ستون‌های با ترتیب معکوس (مثلاً «کم تا زیاد» اما داده بالعکس ثبت شده)
حتماً ترتیب را اصلاح کن.
