### 💡 تعریف ساده Feature Construction

> یعنی ساخت ویژگی‌های جدید از ویژگی‌های موجود
> تا داده‌ها بهتر بتونن **الگوهای پنهان** رو به مدل نشون بدن 👁️‍🗨️

به زبان ساده‌تر، داری به مدل کمک می‌کنی «چیزهایی رو بفهمه» که خودش به‌تنهایی متوجهش نمی‌شد.

---

### 📘 تفاوت Feature Selection و Feature Construction

| ویژگی     | Feature Selection                  | Feature Construction         |
| :-------- | :--------------------------------- | :--------------------------- |
| هدف       | حذف ویژگی‌های غیرمفید              | ایجاد ویژگی‌های جدید و مفید  |
| نوع تغییر | کاهش داده                          | افزایش قدرت داده             |
| مثال      | حذف ستون‌هایی که همبستگی بالا دارن | ساخت ویژگی "BMI = وزن / قد²" |
| تأثیر     | کاهش پیچیدگی                       | افزایش قدرت مدل              |

---

### 💬 مثال ساده از ساخت ویژگی

فرض کن دیتاستی داری با ستون‌های زیر:

| Height (cm) | Weight (kg) |
| :---------- | :---------- |
| 170         | 70          |
| 180         | 90          |

مدل ممکنه از روی این دو تا ستون نتونه رابطه سلامتی فرد رو بفهمه.
ولی اگه یه ویژگی جدید بسازی به اسم **BMI (شاخص توده بدنی)**:

$$
BMI = \frac{Weight}{(Height/100)^2}
$$

به مدل کمک می‌کنی بهتر سلامتی یا چاقی فرد رو پیش‌بینی کنه 🧠✅

---

### 💻 مثال پایتون

```python
import pandas as pd

data = pd.DataFrame({
    'Height_cm': [170, 180, 160],
    'Weight_kg': [70, 85, 60]
})

# ایجاد ویژگی جدید BMI
data['BMI'] = data['Weight_kg'] / ((data['Height_cm']/100) ** 2)

print(data)
```

📊 **خروجی:**

```
   Height_cm  Weight_kg        BMI
0        170         70  24.22
1        180         85  26.23
2        160         60  23.43
```

✅ حالا مدل به‌جای دو ستون ساده، یه ویژگی جدید داره که مفهوم بیشتری منتقل می‌کنه.

### 💭 چرا ساخت ویژگی مهمه؟

🔹 چون مدل‌های یادگیری ماشین خودشون به‌صورت مستقیم نمی‌تونن مفهوم‌های انتزاعی رو درک کنن.
🔹 ساخت ویژگی‌های جدید باعث می‌شه داده‌ها **معنادارتر** بشن.
🔹 معمولاً **در مسابقات داده‌کاوی (مثل Kaggle)** برنده‌ها با مهندسی ویژگی حرفه‌ای برنده می‌شن نه با الگوریتم جدید! 🏆

### 🧠 مثال واقعی از دنیای کسب‌وکار

فرض کن داده‌های فروش داری:

| تاریخ      | قیمت | تعداد فروش |
| :--------- | :--- | :--------- |
| 2025-11-01 | 200  | 5          |
| 2025-11-02 | 200  | 9          |

ممکنه ویژگی جدیدی بسازی به اسم:

* **Revenue = Price × Quantity**
* یا **Day_of_Week = day_name(تاریخ)**
* یا حتی **Is_Weekend (آیا روز تعطیله؟)**

📈 این ویژگی‌ها به مدل یاد می‌دن چه روزهایی فروش بیشتره و چرا.

### 🧩 دسته‌بندی کلی ساخت ویژگی‌ها

| نوع داده            | نوع ویژگی جدید        | مثال                      |
| :------------------ | :-------------------- | :------------------------ |
| عددی (Numeric)      | ترکیب ریاضی           | BMI، سرعت، نرخ رشد        |
| زمانی (Time Series) | فاصله زمانی، روز هفته | ساعت، ماه، تاخیر زمانی    |
| متنی (Text)         | تعداد کلمات، طول جمله | تعداد تگ‌ها، فراوانی واژه |
| مکانی (Geo)         | فاصله جغرافیایی       | فاصله از مرکز شهر، ناحیه  |
