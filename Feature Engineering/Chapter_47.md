## 🧠 ۱. مفهوم Target Encoding

در **Target Encoding** هر دسته (Category) با **میانگین مقدار هدف (Target)** جایگزین می‌شه.
به زبان ساده یعنی اگر خروجی مدل عددیه (مثلاً احتمال خرید، امتیاز یا درآمد)،
می‌تونیم مقدار هر دسته رو برابر با **میانگین Target مربوط به اون دسته** بذاریم.

---

### 📘 مثال عددی

فرض کن داده‌ای داریم برای پیش‌بینی خرید (Buy = 1 یا 0):

| کشور   | خرید (Buy) |
| :----- | :--------: |
| ایران  |      1     |
| ژاپن   |      0     |
| ایران  |      1     |
| آمریکا |      0     |
| ژاپن   |      1     |

حالا میانگین خرید برای هر کشور:

| کشور   |      میانگین خرید     |
| :----- | :-------------------: |
| ایران  | (1 + 1) / 2 = **1.0** |
| ژاپن   | (0 + 1) / 2 = **0.5** |
| آمریکا |   (0) / 1 = **0.0**   |

نتیجه‌ی **Target Encoding** 👇

| کشور   | خرید | کشور_Encoded |
| :----- | :--: | :----------: |
| ایران  |   1  |      1.0     |
| ژاپن   |   0  |      0.5     |
| ایران  |   1  |      1.0     |
| آمریکا |   0  |      0.0     |
| ژاپن   |   1  |      0.5     |

---

## 💻 ۲. پیاده‌سازی در پایتون

```python
import pandas as pd

data = pd.DataFrame({
    'Country': ['Iran', 'Japan', 'Iran', 'USA', 'Japan'],
    'Buy': [1, 0, 1, 0, 1]
})

means = data.groupby('Country')['Buy'].mean()
data['Country_encoded'] = data['Country'].map(means)

print(data)
```

📊 **خروجی:**

```
  Country  Buy  Country_encoded
0    Iran    1              1.0
1   Japan    0              0.5
2    Iran    1              1.0
3     USA    0              0.0
4   Japan    1              0.5
```

## ⚙️ ۴. جلوگیری از Overfitting در Target Encoding

اگر دسته‌ای فقط چند نمونه داشته باشه، میانگین اون ممکنه مدل رو گمراه کنه.
برای جلوگیری، از **Smoothing (هموارسازی)** استفاده می‌کنیم:

### 📐 فرمول ساده‌ی هموارسازی:

[
Encoded = \frac{mean_{cat} \times n + global_mean \times k}{n + k}
]

🔹 `mean_cat`: میانگین مقدار هدف برای آن دسته
🔹 `global_mean`: میانگین کل داده‌ها
🔹 `n`: تعداد نمونه در آن دسته
🔹 `k`: عدد تنظیم‌کننده‌ی قدرت هموارسازی

---

### 💻 پیاده‌سازی ساده‌ی Smoothing

```python
global_mean = data['Buy'].mean()
counts = data['Country'].value_counts()
means = data.groupby('Country')['Buy'].mean()

k = 2
smooth = (means * counts + global_mean * k) / (counts + k)
data['Country_encoded'] = data['Country'].map(smooth)

print(data)
```

📊 این روش باعث می‌شه دسته‌هایی که داده‌ی کمی دارن، به میانگین کلی نزدیک‌تر بشن.
