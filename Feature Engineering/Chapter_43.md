## 💣 ۱. مشکل داده‌های پرت (Outliers)

گاهی فقط چند مقدار عجیب (مثلاً درآمد یک میلیاردر در بین افراد عادی) می‌تونن میانگین کل داده رو منحرف کنن 😅

📊 مثال:

| مقدار اصلی |  توضیح |
| :--------: | :----: |
|     20     |  نرمال |
|     22     |  نرمال |
|     23     |  نرمال |
|     25     |  نرمال |
|     500    | پرت 😱 |

اگر از **StandardScaler** استفاده کنی، اون مقدار ۵۰۰ باعث می‌شه همه‌ی داده‌ها کشیده بشن و بخش اعظم‌شون نزدیک صفر بشن، در نتیجه مدل گمراه می‌شه.

---

## 🧩 ۲.  تعریف RobustScaler — مقاوم در برابر Outlier

### 💡 مفهوم:

در این روش، به‌جای استفاده از میانگین و انحراف معیار، از **میانه (Median)** و **IQR (Interquartile Range)** استفاده می‌شه.

📘 **فرمول:**
$$[
x' = \frac{x - \text{Median}}{IQR}
]$$
که در اون:
$$[
IQR = Q3 - Q1
]$$
(Q3 صدک ۷۵٪ و Q1 صدک ۲۵٪ است.)

---

### 💻 مثال عددی

| مقدار اصلی | Median | IQR | مقدار مقیاس‌شده |
| :--------: | :----: | :-: | :-------------: |
|     20     |   23   |  3  |      -1.00      |
|     22     |   23   |  3  |      -0.33      |
|     23     |   23   |  3  |       0.00      |
|     25     |   23   |  3  |       0.66      |
|     500    |   23   |  3  |    159.00 😎    |

📊 حالا داده‌های نرمال بین حدود -1 تا +1 هستن، ولی داده پرت دیگه باعث کشیدگی شدید داده‌ها نمی‌شه.

---

### 💻 کد پایتون – RobustScaler

```python
import pandas as pd
from sklearn.preprocessing import RobustScaler

data = pd.DataFrame({
    'Income': [20, 22, 23, 25, 500],
    'Age': [25, 30, 22, 28, 26]
})

scaler = RobustScaler()
scaled_data = scaler.fit_transform(data)

df_scaled = pd.DataFrame(scaled_data, columns=data.columns)
print(df_scaled)
```

📈 **خروجی تقریبی:**

```
   Income      Age
0 -0.80  -0.33
1 -0.33   0.33
2  0.00  -1.00
3  0.66   1.00
4 159.00  0.00
```

✅ داده‌های پرت خیلی تأثیر کمتری روی مقیاس‌سازی گذاشتن.

## ⚙️ ۳.تعریف  MaxAbsScaler — مناسب داده‌های مثبت و منفی

### 💡 مفهوم:

این روش داده‌ها رو به‌صورت **متقارن در بازه [-1, +1]** نگه می‌داره.
فقط با تقسیم مقدار هر ویژگی بر **بیشترین مقدار قدر مطلق (max(|x|))** اون ویژگی انجام می‌شه.

📘 **فرمول:**
$$[
x' = \frac{x}{\max(|x|)}
]$$

---

### 💻 مثال عددی

| مقدار اصلی | بیشترین قدر مطلق | مقدار مقیاس‌شده |
| :--------: | :--------------: | :-------------: |
|     -50    |        100       |       -0.5      |
|      0     |        100       |       0.0       |
|    +100    |        100       |       +1.0      |

📊 این روش وقتی مفیده که داده‌ها هم مقادیر مثبت دارن و هم منفی (مثلاً ولتاژ یا نرخ تغییر).

---

### 💻 کد پایتون – MaxAbsScaler

```python
from sklearn.preprocessing import MaxAbsScaler
import pandas as pd

data = pd.DataFrame({
    'Signal': [-50, -20, 0, 20, 100],
    'Voltage': [-5, 0, 10, 20, 25]
})

scaler = MaxAbsScaler()
scaled = scaler.fit_transform(data)

df_scaled = pd.DataFrame(scaled, columns=data.columns)
print(df_scaled)
```

📈 **خروجی:**

```
   Signal  Voltage
0  -0.5    -0.2
1  -0.2     0.0
2   0.0     0.4
3   0.2     0.8
4   1.0     1.0
```

✅ این روش داده‌ها رو بین -1 و +1 نگه می‌داره، بدون تغییر شکل یا انتقال میانگین.

| :------------- | :-----------------: | :------------: | :------------------: |
| StandardScaler |        ❌ بله        | میانگین=۰، σ=۱ |    داده‌های نرمال    |

| MaxAbsScaler   |     ⚪ نیمه مقاوم    |     [-1,+1]    | داده‌های مثبت و منفی |
