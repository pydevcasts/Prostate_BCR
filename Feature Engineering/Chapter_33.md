### 💡 تعریف ساده LDA

> **LDA** یعنی پیدا کردن محورهایی که **بهترین تفکیک بین کلاس‌ها** رو ایجاد کنن.

برخلاف PCA که دنبال بیشترین **واریانس کلی داده‌ها** بود،
LDA دنبال **حداکثر جدایی بین دسته‌ها (کلاس‌ها)** هست.

---

### 📊 تفاوت PCA و LDA

| ویژگی            | PCA                      | LDA                      |
| :--------------- | :----------------------- | :----------------------- |
| نوع یادگیری      | بدون ناظر (Unsupervised) | با ناظر (Supervised)     |
| هدف              | حفظ بیشترین واریانس داده | جداسازی بهتر بین کلاس‌ها |
| خروجی            | مؤلفه‌های اصلی           | محورهای تفکیکی           |
| داده‌ی مورد نیاز | فقط ویژگی‌ها             | ویژگی + برچسب کلاس       |

---

### 🧠 مثال شهودی

فرض کن داده‌هایی داری از دو کلاس:
کلاس A (قرمز 🔴) و کلاس B (آبی 🔵).
اگر PCA بزنی، داده‌هارو طوری می‌چرخونه که بیشترین پخش‌بودگی رو ببینی.
اما LDA داده‌هارو طوری می‌چرخونه که **بهترین جدایی بین قرمزها و آبی‌ها** حاصل بشه.

---

### 🧮 مراحل اجرای LDA

1️⃣ محاسبه‌ی **میانگین هر کلاس** (Class Mean)
2️⃣ محاسبه‌ی **پراکندگی درون‌کلاسی (Within-Class Scatter)**
3️⃣ محاسبه‌ی **پراکندگی بین‌کلاسی (Between-Class Scatter)**
4️⃣ پیدا کردن محورهایی که نسبت بین‌کلاسی / درون‌کلاسی رو بیشینه کنن.
5️⃣ فرافکنی داده‌ها روی این محورهای جدید 🎯

---

### 💻 مثال پایتون عملی

```python
from sklearn.datasets import load_iris
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis
import pandas as pd

# بارگذاری داده‌ها
iris = load_iris()
X = iris.data
y = iris.target

# اجرای LDA برای کاهش ابعاد به 2 بُعد
lda = LinearDiscriminantAnalysis(n_components=2)
X_lda = lda.fit_transform(X, y)

# نمایش داده‌های کاهش‌یافته
print("شکل داده‌ها قبل از LDA:", X.shape)
print("شکل داده‌ها بعد از LDA:", X_lda.shape)
```

📊 **خروجی:**

```
شکل داده‌ها قبل از LDA: (150, 4)
شکل داده‌ها بعد از LDA: (150, 2)
```

✅ یعنی از ۴ ویژگی به ۲ ویژگی رسیدیم و در عین حال جدایی کلاس‌ها حفظ شده.

### 🧠 تفاوت کلیدی LDA و PCA در هدف

| مورد مقایسه   | PCA                   | LDA                                  |
| :------------ | :-------------------- | :----------------------------------- |
| هدف اصلی      | بیشترین پراکندگی داده | بیشترین جدایی بین کلاس‌ها            |
| ناظر (Labels) | ندارد                 | دارد ✅                               |
| نوع محور جدید | بر اساس واریانس       | بر اساس نسبت بین‌کلاسی به درون‌کلاسی |
| مناسب برای    | کاهش بُعد عمومی       | پیش‌پردازش قبل از طبقه‌بندی          |

### 💬 گفت‌وگوی استاد و دانشجو

👩‍💻 استاد، یعنی LDA بهتر از PCA هست؟
👨‍🏫 بستگی داره.
اگه برچسب کلاس داری (مثلاً نوع گل یا نوع مشتری)، LDA عالیه 🌹
ولی اگه فقط داده‌ی خام داری بدون برچسب، باید از PCA استفاده کنی.
👩‍💻 یعنی PCA برای درک داده و LDA برای تفکیک داده؟
👨‍🏫 دقیقاً 💡
