### 💡 مقدمه فصل دوم

تا اینجا فهمیدیم مهندسی ویژگی یعنی چی و چطور قراره داده‌هامون رو تبدیل کنیم.
اما قبل از ساخت ویژگی‌های جدید، باید یه کار اساسی‌تر انجام بدیم:

> داده‌هامون رو بشناسیم و آماده‌شون کنیم 🎯

چون اگه داده‌هات ناقص، اشتباه یا نامرتب باشن، هرچی ویژگی بسازی هم درست جواب نمی‌ده.
پس توی این فصل قراره یاد بگیری:

* انواع مختلف داده‌ها چیا هستن
* چطور داده‌های گمشده، پرت و متنی رو مدیریت کنی
* و چطور یه دیتاست خام رو برای مدل آماده کنی

### 📘 انواع داده‌ها در یادگیری ماشین

ما معمولاً با چهار نوع داده سروکار داریم 👇

| نوع داده                  | مثال                         | توضیح کوتاه                     |
| :------------------------ | :--------------------------- | :------------------------------ |
| 🔢 **عددی (Numerical)**   | درآمد، سن، وزن               | شامل اعداد پیوسته یا گسسته      |
| 🔤 **متنی (Categorical)** | جنسیت، کشور، شغل             | شامل برچسب‌ها و دسته‌ها         |
| 🕓 **زمانی (Temporal)**   | تاریخ تولد، تاریخ خرید       | شامل زمان، تاریخ یا فاصله زمانی |
| 🌍 **مکانی (Spatial)**    | طول جغرافیایی، عرض جغرافیایی | شامل موقعیت مکانی یا جغرافیایی  |

---

### ⚙️ زیرمجموعه‌های داده عددی:

🔹 **پیوسته (Continuous):** عدد می‌تونه هر مقدار ممیزدار باشه (مثل وزن، قد، دما)

🔹 **گسسته (Discrete):** فقط مقدارهای شمارشی داره (مثل تعداد خریدها، تعداد فرزندان)

---

### 📊 زیرمجموعه‌های داده متنی:

🔹 **اسمی (Nominal):** فقط دسته‌ها رو مشخص می‌کنه (مثل رنگ: قرمز، آبی، سبز)

🔹 **ترتیبی (Ordinal):** علاوه‌بر دسته، ترتیب هم داره (مثل سطح تحصیلات: دیپلم < کارشناسی < ارشد)

---

### 🧩 مثال واقعی ترکیبی از انواع داده‌ها:

| مشتری | سن | جنسیت | شهر    | تاریخ خرید | مبلغ خرید | موقعیت مکانی (X,Y) |
| :---- | :- | :---- | :----- | :--------- | :-------- | :----------------- |
| علی   | 25 | مرد   | تهران  | 2025-11-05 | 4,500,000 | (35.7, 51.4)       |
| سارا  | 32 | زن    | اصفهان | 2025-10-28 | 6,800,000 | (32.6, 51.7)       |

در این جدول داریم:
✅ داده عددی (سن، مبلغ خرید)
✅ داده متنی (جنسیت، شهر)
✅ داده زمانی (تاریخ خرید)
✅ داده مکانی (مختصات جغرافیایی)

### 💻 کد پایتون برای بررسی انواع داده‌ها

```python
import pandas as pd

data = pd.DataFrame({
    'age': [25, 32],
    'gender': ['male', 'female'],
    'city': ['Tehran', 'Isfahan'],
    'purchase_date': ['2025-11-05', '2025-10-28'],
    'amount': [4500000, 6800000]
})

# 🧠 بررسی نوع داده‌ها
print(data.dtypes)
```

📋 خروجی:

```
age               int64
gender           object
city             object
purchase_date    object
amount            int64
dtype: object
```

📌 نکته: ستون‌های `object` معمولاً متنی هستن و باید بعداً به عددی تبدیل بشن تا مدل بفهمه‌شون.

### 💡 نکته مهم:

> همیشه قبل از هرکاری نوع داده‌ها رو بررسی کن.
> چون انتخاب روش پردازش و مهندسی ویژگی، کاملاً بستگی به نوع داده داره.

مثلاً برای داده عددی می‌تونی نرمال‌سازی انجام بدی،
اما برای داده متنی باید از **کدگذاری (Encoding)** استفاده کنی.

### 🎨 تصویر پیشنهادی:

> یک نمودار با چهار آیکون کنار هم:
> 🔢 اعداد → ویژگی عددی
> 🔤 متن → ویژگی متنی
> 🕓 ساعت → ویژگی زمانی
> 🌍 نقشه → ویژگی مکانی

---

### 🎯 تمرین سریع:

فرض کن یه دیتاست داری با ستون‌های زیر:
`جنسیت، سن، درآمد، کشور، تاریخ خرید`
تشخیص بده هرکدوم جزو چه نوع داده‌ای هستن 👇

(مثلاً: جنسیت → متنی، سن → عددی، تاریخ خرید → زمانی و ...)
