### 🎯 هدف این صفحه

در این صفحه یاد می‌گیری چطور بدون ساخت مدل، فقط با بررسی آماری داده‌ها،
ویژگی‌های مهم رو انتخاب کنی — روشی سریع، ساده، و بسیار محبوب برای شروع تحلیل داده‌ها ⚡

---

### 💡 مفهوم روش‌های Filter

روش‌های **Filter** بر پایه‌ی روابط آماری بین ویژگی‌ها و متغیر هدف هستن.
در این روش:

* هر ویژگی **به‌صورت مستقل** بررسی می‌شه.
* با استفاده از **همبستگی (Correlation)**، **آزمون‌های آماری** یا **اطلاعات متقابل (Mutual Information)** مشخص می‌کنیم کدوم ویژگی مفیدتره.
* مدل یادگیری ماشین در این مرحله **نقشی نداره** 🎯

---

### ⚙️ مزایا و معایب

| مزیت                              | عیب                                             |
| :-------------------------------- | :---------------------------------------------- |
| 🚀 بسیار سریع و سبک               | ❌ در نظر نمی‌گیرد که ویژگی‌ها با هم تعامل دارند |
| 🧮 مستقل از مدل                   | ⚠️ ممکنه ویژگی‌های ترکیبی مهم حذف بشن           |
| ✅ مناسب برای دیتاست‌های خیلی بزرگ | 💡 فقط معیارهای آماری بررسی می‌شن               |

---

### 🔍 روش‌های محبوب Filter

| روش                             | نوع داده        | توضیح                               |
| :------------------------------ | :-------------- | :---------------------------------- |
| 📈 **Correlation (همبستگی)**    | عددی            | سنجش ارتباط خطی بین ویژگی و هدف     |
| 🔢 **Chi-Square Test (کای-دو)** | طبقه‌ای         | بررسی وابستگی بین ویژگی و هدف       |
| 🧠 **Mutual Information**       | عددی یا طبقه‌ای | بررسی اطلاعات مشترک بین ویژگی و هدف |

---

### 💻 مثال ۱: همبستگی (Correlation)

در این روش از ضریب پیرسون (r) استفاده می‌کنیم تا رابطه‌ی خطی بین ویژگی‌ها و هدف را بسنجیم.

```python
import pandas as pd

data = pd.DataFrame({
    'age': [20, 25, 30, 35, 40],
    'income': [2000, 3000, 4000, 5000, 6000],
    'spending': [1500, 2000, 3000, 3500, 4000]
})

# محاسبه همبستگی بین ویژگی‌ها
corr_matrix = data.corr()
print(corr_matrix)
```

📊 خروجی:

| ویژگی    |  age | income | spending |
| :------- | :--: | :----: | :------: |
| age      | 1.00 |  0.98  |   0.95   |
| income   | 0.98 |  1.00  |   0.97   |
| spending | 0.95 |  0.97  |   1.00   |

💡 مشاهده می‌کنی که همبستگی بالای بین `income` و `spending` ممکنه باعث تکرار اطلاعات بشه،
پس فقط یکی از آن‌ها را نگه می‌داریم.

---

### 💻 مثال ۲: آزمون کای-دو (Chi-Square Test)

برای داده‌های طبقه‌ای از آزمون χ² استفاده می‌کنیم:

```python
from sklearn.feature_selection import chi2
from sklearn.preprocessing import LabelEncoder
import pandas as pd

data = pd.DataFrame({
    'color': ['red', 'blue', 'green', 'red', 'blue'],
    'bought': [1, 0, 0, 1, 1]
})

# تبدیل به عدد
enc = LabelEncoder()
X = enc.fit_transform(data['color']).reshape(-1, 1)
y = data['bought']

chi_scores, p_values = chi2(X, y)
print("Chi-square:", chi_scores, "P-values:", p_values)
```

📊 خروجی:

```
Chi-square: [0.83333333] P-values: [0.36131043]
```

💡 چون مقدار p بزرگ‌تر از ۰.۰۵ است → رنگ با خرید رابطه‌ی آماری قوی ندارد ❌

---

### 💻 مثال ۳: اطلاعات متقابل (Mutual Information)

این روش برای داده‌های عددی و غیرخطی مناسب است:

```python
from sklearn.feature_selection import mutual_info_classif
import numpy as np

X = data[['age', 'income']]
y = np.array([0, 0, 1, 1, 1])

info = mutual_info_classif(X, y)
for i, col in enumerate(X.columns):
    print(col, ":", info[i])
```

📊 خروجی:

```
age : 0.02
income : 0.11
```

💡 ویژگی `income` اطلاعات بیشتری درباره‌ی هدف در اختیار مدل می‌گذارد،
پس انتخابش منطقی‌تر است ✅
