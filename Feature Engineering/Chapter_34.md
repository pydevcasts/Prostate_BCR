### 🌈 ۱. t-SNE (t-Distributed Stochastic Neighbor Embedding)

#### 🧠 ایده اصلی

 داده‌هایی که در فضای پر بُعد به هم نزدیک هستن رو در فضای دو یا سه بُعد هم **نزدیک** نگه می‌داره.
یعنی **ساختار محلی (Local Structure)** داده‌ها رو حفظ می‌کنه 👌

---

#### 💻 مثال پایتون

```python
from sklearn.datasets import load_digits
from sklearn.manifold import TSNE
import matplotlib.pyplot as plt

# بارگذاری داده‌ها (تصاویر ارقام 0 تا 9)
digits = load_digits()
X = digits.data
y = digits.target

# اجرای t-SNE برای کاهش به 2 بعد
tsne = TSNE(n_components=2, random_state=42, perplexity=30)
X_tsne = tsne.fit_transform(X)

# ترسیم داده‌ها
plt.figure(figsize=(8,6))
plt.scatter(X_tsne[:,0], X_tsne[:,1], c=y, cmap='tab10', s=15)
plt.title("t-SNE Projection of Digits Dataset")
plt.xlabel("Dimension 1")
plt.ylabel("Dimension 2")
plt.show()
```

📊 **توضیح:**
اعداد مشابه (مثل تمام صفرها یا تمام هفت‌ها) نزدیک هم قرار می‌گیرن.
این یعنی t-SNE خوشه‌های پنهان داده‌ها رو کشف کرده 🧩

---

### ⚙️ نکات مهم در t-SNE

| پارامتر         | معنی            | توضیح                             |
| :-------------- | :-------------- | :-------------------------------- |
| `perplexity`    | تعداد همسایه‌ها | معمولاً بین 5 تا 50 انتخاب می‌شود |
| `learning_rate` | سرعت یادگیری    | کنترل سرعت تغییر مختصات           |
| `n_iter`        | تعداد تکرارها   | هرچه بیشتر، نتایج پایدارتر        |

⚠️ توجه: t-SNE فقط برای **نمایش و تجسم داده‌ها** مناسبه،
نه برای پیش‌پردازش مدل‌های یادگیری ماشین!

### 🌌 ۲. UMAP (Uniform Manifold Approximation and Projection)

#### 💡 ایده اصلی

بر اساس نظریه‌ی مانیفولدها و توپولوژی ساخته شده 😍
هدفش حفظ **ساختار کلی (Global Structure)** داده‌هاست، نه فقط محلی.

✅ سریع‌تر از t-SNE
✅ بهتر برای داده‌های حجیم
✅ قابل‌استفاده حتی برای مدل‌سازی

---

#### 💻 مثال پایتون

```python
import umap
import matplotlib.pyplot as plt
from sklearn.datasets import load_iris

iris = load_iris()
X = iris.data
y = iris.target

# اجرای UMAP برای کاهش به دو بُعد
reducer = umap.UMAP(n_components=2, random_state=42)
X_umap = reducer.fit_transform(X)

# رسم خروجی
plt.figure(figsize=(8,6))
plt.scatter(X_umap[:,0], X_umap[:,1], c=y, cmap='viridis', s=40)
plt.title("UMAP Projection of Iris Dataset")
plt.xlabel("UMAP 1")
plt.ylabel("UMAP 2")
plt.show()
```

📈 **توضیح:**
در این نمودار، سه کلاس گل Iris به‌وضوح از هم جدا شدن.
UMAP هم ساختار کلی داده رو حفظ کرده و هم جزئیات رو ✨

---

### 🧠 مقایسه t-SNE و UMAP

| ویژگی         | t-SNE        | UMAP                  |
| :------------ | :----------- | :-------------------- |
| سرعت اجرا     | کندتر ⏳      | سریع‌تر ⚡             |
| حفظ ساختار    | محلی (Local) | کلی (Global)          |
| پایداری خروجی | کمتر         | بیشتر ✅               |
| کاربرد        | تجسم داده    | تجسم + پیش‌پردازش مدل |
