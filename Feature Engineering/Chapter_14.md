### 🔹 مفهوم کلی Embedded Methods

در این روش‌ها، دیگه لازم نیست جدا از مدل انتخاب ویژگی انجام بدیم.
خود مدل هنگام آموزش یاد می‌گیره که کدوم ویژگی‌ها بیشتر به نتیجه کمک می‌کنن 💡

یعنی همزمان **مدل آموزش داده می‌شه** و **وزن اهمیت ویژگی‌ها** هم محاسبه می‌شن.
هر ویژگی که وزن کوچکی داشته باشه، کنار گذاشته می‌شه ✂️

---

### ⚙️ مزایا و معایب

| مزیت                 | توضیح                                             |
| :------------------- | :------------------------------------------------ |
| ✅ سرعت خوب           | چون همزمان با آموزش مدل انجام می‌شود              |
| ✅ دقت بالا           | ویژگی‌ها بر اساس یادگیری واقعی مدل انتخاب می‌شوند |
| ⚠️ وابسته به مدل     | فقط با مدل‌های خاص قابل انجام است                 |
| ⚠️ سخت‌تر برای تفسیر | نسبت به Filter کمی پیچیده‌تر است                  |

---

### 📘 معروف‌ترین روش‌های Embedded

| نام روش                                     | نوع مدل | توضیح ساده                                       |
| :------------------------------------------ | :------ | :----------------------------------------------- |
| 🔹 **Lasso Regression (L1 Regularization)** | خطی     | ویژگی‌هایی با وزن کم را به صفر تبدیل می‌کند      |
| 🔸 **Decision Tree / Random Forest**        | درختی   | اهمیت ویژگی‌ها را بر اساس کاهش خطا محاسبه می‌کند |
| 🔹 **Gradient Boosting**                    | ترکیبی  | ترکیبی از مدل‌های درختی با وزن‌دهی خودکار        |

---

### 💡 مثال ۱: Lasso Regression (انتخاب خودکار ویژگی‌ها با حذف وزن صفر)

Lasso یکی از جذاب‌ترین مدل‌هاست چون خودش به‌صورت خودکار برخی ویژگی‌ها رو حذف می‌کنه!

```python
import pandas as pd
from sklearn.linear_model import Lasso
from sklearn.preprocessing import StandardScaler

# داده نمونه
data = pd.DataFrame({
    'area': [50, 70, 90, 110, 130],
    'rooms': [2, 3, 4, 4, 5],
    'distance_metro': [10, 8, 6, 4, 2],
    'old_years': [10, 9, 8, 8, 7],
    'price': [200, 250, 300, 350, 400]
})

X = data[['area', 'rooms', 'distance_metro', 'old_years']]
y = data['price']

# نرمال‌سازی داده‌ها
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# مدل Lasso
lasso = Lasso(alpha=0.1)
lasso.fit(X_scaled, y)

# نمایش ضرایب (اهمیت ویژگی‌ها)
for feature, coef in zip(X.columns, lasso.coef_):
    print(f"{feature}: {coef:.3f}")
```

📊 خروجی نمونه:

```
area: 120.456  
rooms: 25.842  
distance_metro: -35.200  
old_years: 0.000
```

✅ ویژگی `old_years` حذف شد (وزنش صفر شده)
چون مدل تشخیص داده تأثیری در پیش‌بینی ندارد 👌

---

### 💡 مثال ۲: درخت تصمیم (Decision Tree)

مدل‌های درختی مثل RandomForest می‌توانند اهمیت هر ویژگی را بر اساس تأثیرش روی پیش‌بینی بسنجند 🌳

```python
from sklearn.tree import DecisionTreeRegressor

model = DecisionTreeRegressor(random_state=42)
model.fit(X, y)

importance = pd.DataFrame({
    'Feature': X.columns,
    'Importance': model.feature_importances_
}).sort_values(by='Importance', ascending=False)

print(importance)
```

📊 خروجی:

| Feature        | Importance |
| :------------- | :--------: |
| area           |    0.55    |
| distance_metro |    0.35    |
| rooms          |    0.10    |
| old_years      |    0.00    |

✅ بنابراین "متراژ" و "فاصله از مترو" مهم‌ترین ویژگی‌ها هستند.

---

### 🧠 نکته‌ی حرفه‌ای

> مدل‌های درختی (مثل RandomForest یا XGBoost) برای داده‌های واقعی انتخاب خوبی هستن،
> چون خودشون ویژگی‌های کم‌اهمیت رو بی‌اثر می‌کنن بدون نیاز به پیش‌پردازش جدا.

همچنین Lasso برای داده‌های عددی و خطی بهترین انتخابه.
اگر داده ترکیبی داری، ترکیب این دو روش عالیه ✨

---

### 🎨 تصویر پیشنهادی

> یک درخت با شاخه‌های مختلف (ویژگی‌ها) که ضخامت هر شاخه میزان اهمیتش را نشان می‌دهد 🌳
> شاخه‌های ضخیم‌تر یعنی ویژگی مهم‌تر.
