# 🧠 ۱. Feature Construction چیست؟

ساخت ویژگی یعنی **ایجاد ویژگی‌های جدید** از دل ویژگی‌های موجود، به‌طوری که:

* اطلاعات پنهان بهتر نمایان شوند
* رابطه‌های پیچیده ساده‌تر شوند
* مدل بهتر الگوها را یاد بگیرد

📘 *در واقع ویژگی‌های جدید مثل زاویهٔ جدید نگاه به داده هستند.*
گاهی با یک ویژگی جدید، مشکلی که سخت بوده ناگهان آسان می‌شود.

---

# 🧩 ۲. چرا باید ویژگی جدید ساخت؟

ساخت ویژگی وقتی ضروری می‌شود که:

✨ رابطه‌های غیرخطی وجود دارند
✨ دادهٔ خام ناقص است
✨ ترکیب چند ویژگی بهتر از تک‌تک آن‌هاست
✨ ویژگی فعلی اطلاعات را کامل منتقل نمی‌کند

---

# 📊 ۳. نمونهٔ کاربردی واقعی

فرض کن دیتاست قیمت خانه داری:

| متراژ | تعداد اتاق | قیمت |
| ----- | ---------- | ---- |
| 120   | 2          | 4.1  |
| 200   | 4          | 7.3  |

دو ویژگی *متراژ* و *اتاق* کافی نیستند…
اما اگر یک ویژگی جدید بسازی:

```
Price_per_room = قیمت / تعداد اتاق
```

این ناگهان الگو را بهبود می‌دهد!
چون رابطهٔ *قیمت به ازای هر اتاق* برای مدل بسیار گویاست.

---

# 🧠 ۴. انواع ساخت ویژگی‌ها

به‌طور کلی ویژگی‌های جدید در چند گروه مهم ساخته می‌شوند:

---

## **۱) ویژگی‌های ریاضی (Mathematical Features)**

مثال‌ها:

* جمع (`A + B`)
* تفریق (`A - B`)
* نسبت (`A / B`)
* ضرب (`A * B`)
* میانگین (`(A + B)/2`)
* لگاریتم (`log(A)`)

📘 *این ویژگی‌ها برای داده‌های عددی بسیار مؤثرند.*

---

## **۲) ویژگی‌های تعاملی (Interaction Features)**

مثال:
اگر دو ویژگی وقتی کنار هم هستند معنی جدیدی می‌دهند:

```
Age * Income
کسی که سن کم + درآمد بالا دارد بسیار متفاوت از کسی است که سن بالا + درآمد پایین دارد
```

---

## **۳) ویژگی‌های منطقی / باینری**

مثال:

```
Is_Adult = Age >= 18
Is_Large_House = Rooms > 3
```

این ویژگی‌ها روابط پیچیده را ساده می‌کنند.

---

## **۴) ویژگی‌های دسته‌ای جدید (Combined Categories)**

مثال:

```
Country + City → Region
فروش در “ایران-تبریز” = رفتار متفاوت نسبت به “ایران-بندرعباس”
```

---

## **۵) ویژگی‌های آماری محلی**

در داده‌های زمانی و مکانی بسیار کاربردی‌اند:

* میانگین ۷ روز اخیر
* حداکثر ۳۰ روز
* روند تغییرات (Trend)
* نوسان (Volatility)

---

# 💻 ۵. مثال پایتون — ساخت ویژگی‌های جدید

⚠️ *اسم هر خط فارسی شروع می‌شود تا چپ‌چین نشود.*

```python
# ساخت چند ویژگی جدید
import pandas as pd

data = pd.DataFrame({
    "age": [20, 30, 40],
    "income": [3.5, 5.0, 6.8],
    "rooms": [2, 3, 4]
})

# ویژگی تعاملی
data["age_income_interaction"] = data["age"] * data["income"]

# ویژگی نسبت
data["income_per_room"] = data["income"] / data["rooms"]

# ویژگی منطقی
data["is_adult"] = data["age"] >= 18

print(data)
```
