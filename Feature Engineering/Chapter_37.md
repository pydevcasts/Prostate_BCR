## 🔹 ۱. ساخت ویژگی‌های عددی جدید

در داده‌های عددی معمولاً با روابط ریاضی ساده می‌شه ویژگی‌های جدید ساخت که **رابطه‌های پنهان بین متغیرها** رو آشکار کنه 🧠

| نوع عملیات | مثال                  | توضیح                 |
| :--------- | :-------------------- | :-------------------- |
| جمع        | `Income + Bonus`      | مجموع درآمد           |
| تفریق      | `Max_Temp - Min_Temp` | دامنه دما             |
| ضرب        | `Price × Quantity`    | کل مبلغ فروش          |
| تقسیم      | `Revenue / Customers` | میانگین فروش هر مشتری |

---

### 💻 مثال عملی پایتون

```python
import pandas as pd

# داده‌ی نمونه
data = pd.DataFrame({
    'price': [100, 150, 200],
    'quantity': [5, 3, 8],
    'discount': [0.1, 0.15, 0.05]
})

# ایجاد ویژگی‌های جدید عددی
data['revenue'] = data['price'] * data['quantity']
data['final_price'] = data['revenue'] * (1 - data['discount'])
data['discount_value'] = data['revenue'] * data['discount']

print(data)
```

📊 **خروجی:**

```
   price  quantity  discount  revenue  final_price  discount_value
0    100         5      0.10      500        450.0            50.0
1    150         3      0.15      450        382.5            67.5
2    200         8      0.05     1600       1520.0            80.0
```

✅ با سه ویژگی جدید (`revenue`, `final_price`, `discount_value`) مدل ما بهتر می‌فهمه که تخفیف چه تأثیری روی سود نهایی داشته.

## 🔹 ۲. تبدیل لگاریتمی (Log Transformation)

خیلی از داده‌ها پراکندگی زیاد دارن (مثلاً درآمد افراد یا قیمت خونه‌ها).
برای کاهش این پراکندگی از **تبدیل لگاریتمی** استفاده می‌کنیم 📉

[
X' = \log(X + 1)
]

(عدد ۱ اضافه می‌شه تا از log(0) جلوگیری بشه)

---

### 💻 مثال پایتون

```python
import numpy as np

data['log_revenue'] = np.log1p(data['revenue'])
print(data[['revenue', 'log_revenue']])
```

📊 **خروجی:**

```
   revenue  log_revenue
0      500     6.217
1      450     6.111
2     1600     7.378
```

✅ حالا تفاوت مقادیر خیلی زیاد (مثل 1600 و 450) کمتر شده و مدل راحت‌تر می‌تونه روی اون یاد بگیره.

---

## 🔹 ۳. تبدیل‌های توان و ریشه (Power & Root Transformations)

گاهی داده‌ها به‌صورت غیرخطی تغییر می‌کنن؛ مثلاً وقتی رشد نمایی داریم.
در این حالت، از تبدیل‌هایی مثل **ریشه دوم** یا **توان دوم** استفاده می‌کنیم 🔢

```python
data['sqrt_revenue'] = np.sqrt(data['revenue'])
data['square_discount'] = data['discount'] ** 2
print(data[['revenue', 'sqrt_revenue', 'discount', 'square_discount']])
```

📊 **خروجی:**

```
   revenue  sqrt_revenue  discount  square_discount
0      500     22.3607      0.10           0.0100
1      450     21.2132      0.15           0.0225
2     1600     40.0000      0.05           0.0025
```

✅ این ویژگی‌های جدید گاهی الگوهایی رو آشکار می‌کنن که در مقدار خام پنهان بودن.

## 🔹 ۴. نرمال‌سازی (Normalization) و مقیاس‌دهی (Scaling)

چون مقیاس عددها (مثلاً تومان در برابر درصد) متفاوت است، مدل‌ها ممکنه سردرگم بشن 😵‍💫
برای همین از **نرمال‌سازی** یا **استانداردسازی** استفاده می‌کنیم.

### 📘 دو روش متداول:

| روش            | توضیح                       | فرمول                                          |
| :------------- | :-------------------------- | :--------------------------------------------- |
| MinMaxScaler   | مقادیر بین ۰ تا ۱           | ( X' = \frac{X - X_{min}}{X_{max} - X_{min}} ) |
| StandardScaler | میانگین صفر، انحراف معیار ۱ | ( X' = \frac{X - μ}{σ} )                       |

---

### 💻 مثال پایتون

```python
from sklearn.preprocessing import MinMaxScaler, StandardScaler

scaler_minmax = MinMaxScaler()
scaler_std = StandardScaler()

data['revenue_minmax'] = scaler_minmax.fit_transform(data[['revenue']])
data['revenue_std'] = scaler_std.fit_transform(data[['revenue']])

print(data[['revenue', 'revenue_minmax', 'revenue_std']])
```

📊 **خروجی:**

```
   revenue  revenue_minmax  revenue_std
0      500        0.0357     -0.563
1      450        0.0000     -0.633
2     1600        1.0000      1.196
```

✅ حالا همه‌ی مقادیر تو یه بازه‌ی کنترل‌شده هستن،
و مدل‌ت راحت‌تر می‌تونه الگوهای واقعی رو تشخیص بده.
