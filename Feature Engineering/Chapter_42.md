## 📏 ۱. StandardScaler

### 💡 مفهوم:

در این روش، داده‌ها طوری تغییر مقیاس داده می‌شن که **میانگین‌شون صفر و انحراف معیارشون یک بشه**.
به این می‌گن **Z-score Normalization**.

📘 **فرمول:**
$$[
z = \frac{x - \mu}{\sigma}
]$$
که در اون:

* ($\mu$) = میانگین ویژگی
* ( $\sigma$ ) = انحراف معیار ویژگی

---

### 💻 مثال عددی

| مقدار اصلی (x) | میانگین (µ) | انحراف معیار (σ) | مقدار مقیاس‌شده (z) |
| :------------: | :---------: | :--------------: | :-----------------: |
|       10       |      20     |         5        |          -2         |
|       20       |      20     |         5        |          0          |
|       30       |      20     |         5        |          +2         |

📊 حالا داده‌ها حول صفر قرار گرفتن، و فاصله از میانگین با واحد انحراف معیار اندازه‌گیری می‌شه.

---

### 💻 کد پایتون – StandardScaler

```python
import pandas as pd
from sklearn.preprocessing import StandardScaler

data = pd.DataFrame({
    'Height': [150, 160, 170, 180, 190],
    'Weight': [50, 60, 70, 80, 90]
})

scaler = StandardScaler()
scaled_data = scaler.fit_transform(data)

df_scaled = pd.DataFrame(scaled_data, columns=data.columns)
print(df_scaled)
```

📊 **خروجی:**

```
     Height    Weight
0 -1.414214 -1.414214
1 -0.707107 -0.707107
2  0.000000  0.000000
3  0.707107  0.707107
4  1.414214  1.414214
```

✅ میانگین داده‌ها ≈ ۰ و انحراف معیار ≈ ۱
مدل حالا راحت‌تر وزن‌ها رو یاد می‌گیره و سریع‌تر همگرا می‌شه.

---

### ⚡ کاربردهای مناسب StandardScaler

| نوع مدل             | نیاز به StandardScaler؟ | دلیل                                    |
| :------------------ | :---------------------- | :-------------------------------------- |
| Logistic Regression | ✅                       | وزن‌ها نسبت به میانگین داده تنظیم می‌شن |
| SVM                 | ✅                       | فاصله‌محور محور تصمیم حساسه             |
| PCA                 | ✅                       | واریانس بر اساس مقیاس محاسبه می‌شه      |
| Neural Network      | ✅                       | گرادیان‌ها بهتر همگرا می‌شن             |
| Decision Tree       | ❌                       | مستقل از مقیاس داده است                 |

## 📉 ۲. MinMaxScaler

### 💡 مفهوم:

در این روش، داده‌ها به **بازه‌ای ثابت (معمولاً [0, 1])** تبدیل می‌شن.
بهش می‌گن **Normalization** یا **Rescaling**.

📘 **فرمول:**
$$[
x' = \frac{x - x_{min}}{x_{max} - x_{min}}
]$$
که در اون:

* ( $x_{min}$ ) = کمترین مقدار ویژگی
* ( $x_{max}$ ) = بیشترین مقدار ویژگی

---

### 💻 مثال عددی

| مقدار اصلی | x_min | x_max | مقدار مقیاس‌شده |
| :--------: | :---: | :---: | :-------------: |
|     10     |   10  |   40  |       0.00      |
|     20     |   10  |   40  |       0.33      |
|     40     |   10  |   40  |       1.00      |

📈 داده‌ها الان بین ۰ و ۱ فشرده شدن و همه در یک محدوده‌ی واحد قرار دارن.

---

### 💻 کد پایتون – MinMaxScaler

```python
from sklearn.preprocessing import MinMaxScaler
import pandas as pd

data = pd.DataFrame({
    'Height': [150, 160, 170, 180, 190],
    'Weight': [50, 60, 70, 80, 90]
})

scaler = MinMaxScaler()
scaled_data = scaler.fit_transform(data)

df_scaled = pd.DataFrame(scaled_data, columns=data.columns)
print(df_scaled)
```

📊 **خروجی:**

```
   Height  Weight
0     0.0     0.0
1     0.25    0.25
2     0.50    0.50
3     0.75    0.75
4     1.00    1.00
```

✅ هر دو ویژگی الان در بازه [0,1] هستن، مناسب برای شبکه‌های عصبی و الگوریتم‌های مبتنی بر گرادیان.

---

## ⚙️ ۳. تفاوت عملکرد در مدل‌های مختلف

| مدل                          | StandardScaler | MinMaxScaler | توضیح                                          |
| :--------------------------- | :------------- | :----------- | :--------------------------------------------- |
| Linear / Logistic Regression | ✅              | ⚪            | حفظ میانگین صفر برای وزن‌دهی دقیق              |
| SVM                          | ✅              | ⚪            | مبتنی بر فاصله؛ مقیاس صفر میانگین مناسب‌تره    |
| Neural Networks              | ⚪              | ✅            | شبکه‌ها با داده‌های [0,1] پایدارتر یاد می‌گیرن |
| PCA                          | ✅              | ⚪            | حفظ واریانس‌ها اهمیت داره                      |
| K-Means                      | ✅              | ✅            | هردو مفید؛ بسته به نوع داده                    |

---

## ⚖️ ۴. انتخاب بین دو روش

| شرایط داده                                         | روش پیشنهادی                                 |
| :------------------------------------------------- | :------------------------------------------- |
| داده‌ها نرمال (دارای میانگین و انحراف معیار طبیعی) | StandardScaler                               |
| داده‌ها در بازه محدود (مثلاً درصد یا نرخ)          | MinMaxScaler                                 |
| داده‌ها برای شبکه عصبی یا NN                       | MinMaxScaler                                 |
| داده‌ها دارای مقادیر پرت (outlier) هستند           | RobustScaler (در صفحه بعد توضیح داده می‌شود) |

---

### 🎨 تصویر پیشنهادی

> نموداری شامل دو محور از داده‌های خام،
> یکی با StandardScaler که داده‌ها حول صفر پراکنده شده‌اند،
> و دیگری با MinMaxScaler که داده‌ها به بازه‌ی [0,1] منتقل شده‌اند.
