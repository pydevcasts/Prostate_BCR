### 💡 تعریف نرمال‌سازی

> نرمال‌سازی یعنی تنظیم مقیاس داده‌ها طوری که **طول بردار ویژگی‌ها برابر با ۱** بشه.
> این یعنی هر سطر از داده‌ها (هر نمونه) روی یک **دایره‌ی واحد** قرار می‌گیره 🎯

به زبان ساده‌تر: نرمال‌سازی باعث می‌شه هر داده فقط جهتش حفظ بشه، نه اندازه‌اش.

---

### 🧮 فرمول نرمال‌سازی (L2 Normalization)

[
X_{normalized} = \frac{X}{\sqrt{X_1^2 + X_2^2 + ... + X_n^2}}
]

📘 یعنی هر سطر داده (نه هر ستون) نرمال می‌شه.

---

### 💻 مثال ساده در پایتون

```python
from sklearn.preprocessing import Normalizer
import pandas as pd

data = pd.DataFrame({
    'x1': [3, 1, 0],
    'x2': [4, 0, 2]
})

normalizer = Normalizer(norm='l2')
normalized = normalizer.fit_transform(data)
print(normalized)
```

📊 خروجی:

```
[[0.6, 0.8],
 [1.0, 0.0],
 [0.0, 1.0]]
```

💡 یعنی در ردیف اول، چون طول بردار (3,4) برابر 5 بود، هر مقدار تقسیم بر 5 شده و طول کل به ۱ رسیده ✅

---

### 🧠 فرق نرمال‌سازی با Scaling

| ویژگی  | Scaling                               | Normalization                                     |
| :----- | :------------------------------------ | :------------------------------------------------ |
| دامنه  | بر اساس ستون‌ها                       | بر اساس ردیف‌ها                                   |
| فرمول  | وابسته به میانگین و انحراف معیار      | وابسته به طول بردار                               |
| تأثیر  | مقیاس ویژگی‌ها رو تغییر می‌ده         | جهت داده‌ها رو حفظ می‌کنه                         |
| کاربرد | الگوریتم‌های مبتنی بر فاصله و گرادیان | الگوریتم‌های برداری مثل KNN، SVM، Neural Networks |

---

### 🔢 انواع نرمال‌سازی

| نوع                      | توضیح                                | فرمول                   |     |      |
| :----------------------- | :----------------------------------- | :---------------------- | --- | ---- |
| 🧮 **L1 Normalization**  | مجموع قدرمطلق‌ها برابر ۱ می‌شود      | (\sum                   | x_i | = 1) |
| ⚙️ **L2 Normalization**  | مجموع مربعات برابر ۱ می‌شود          | (\sqrt{\sum x_i^2} = 1) |     |      |
| 💫 **Max Normalization** | مقادیر بر حداکثر مقدار تقسیم می‌شوند | (x_i / max(x))          |     |      |

---

### 💻 مثال عددی مقایسه‌ای

```python
from sklearn.preprocessing import Normalizer

data = [[3, 4], [1, 0], [0, 2]]

for norm in ['l1', 'l2', 'max']:
    normalizer = Normalizer(norm=norm)
    result = normalizer.fit_transform(data)
    print(f"{norm} normalization:\n", result, "\n")
```

📊 خروجی خلاصه:

```
l1 → [[0.43, 0.57], [1.0, 0.0], [0.0, 1.0]]
l2 → [[0.6, 0.8], [1.0, 0.0], [0.0, 1.0]]
max → [[0.75, 1.0], [1.0, 0.0], [0.0, 1.0]]
```

### 🧩 تمرین
