# 🧠 ۱. ساخت ویژگی‌های جدید (Feature Interaction) چیست؟

یعنی **ساخت ویژگی‌های جدید با ترکیب دو یا چند ویژگی**
به‌طوری که اطلاعات جدیدی ایجاد شود که قبلاً در هیچ ویژگی تکی وجود نداشت.

📘 *یک جملهٔ طلایی:*

> «مدل همیشه نمی‌تواند روابط پیچیده بین ویژگی‌ها را خودش یاد بگیرد—
> ما باید این تعامل‌ها را بسازیم و در اختیارش بگذاریم.»

---

# 🌀 ۲. مثال بسیار ساده (اما مهم!)

فرض کن دو ویژگی داری:

* سن → `Age`
* درآمد → `Income`

حالا این دو مورد را جداگانه نگاه می‌کنی:

* سن ۲۰ → عادی
* درآمد ۳ میلیون → عادی

ولی ضرب این دو:

```
Age * Income = 20 * 3 = 60
```

این عدد *میزان توان مالی فرد* را بسیار بهتر از تک‌تک ویژگی‌ها نشان می‌دهد.

---

# 📊 ۳. انواع تعامل‌های مهم

## ۱) تعامل ضربی (Multiplicative Interaction)

🔹 مهم‌ترین نوع تعامل
🔹 مدل‌های خطی بسیار از آن سود می‌برند
مثال‌ها:

```
Age * Income
Size * Height
Temperature * Humidity
```

---

## ۲) تعامل جمعی (Additive Interaction)

مثال:

```
A + B
Revenue + Profit
```

---

## ۳) تعامل تفاوتی (Difference Interaction)

```
Price - Cost
Income - Expenses
```

---

## ۴) تعامل منطقی (Logical Interaction)

```
Is_Adult = (Age >= 18)
High_Risk = (Age < 25) & (Speed > 120)
```

---

## ۵) تعامل دسته‌ای (Categorical Interaction)

برای ویژگی‌های متنی:

```
Country + "_" + City
Gender + "_" + Job
```

برای مدل بسیار مفید است چون دسته‌ها ترکیب می‌شوند.

---

# 🔢 ۴. مثال عددی قابل‌فهم

فرض کن داده‌ای داری:

| Age | Income | Car_Price |
| --- | ------ | --------- |
| 22  | 3.1    | 220       |
| 45  | 8.2    | 410       |

اگر فقط Age را نگاه کنی → الگو خیلی واضح نیست
اگر Income را نگاه کنی → باز هم نه

اما اگر یک ویژگی بسازی:

```
Financial_Power = Age * Income
```

نتیجه:

| Age | Income | Financial_Power | Car_Price |
| --- | ------ | ---------- | --------- |
| 22  | 3.1    | 68.2       | 220       |
| 45  | 8.2    | 369        | 410       |

ناگهان رابطه **تقریباً خطی** می‌شود ⚡
همین باعث بهبود دقت مدل می‌شود.

---

# 💻 ۵. ساخت تعامل‌ها در پایتون

```python

import pandas as pd

data = pd.DataFrame({
    "age": [22, 45, 31],
    "income": [3.1, 8.2, 5.4],
    "rooms": [2, 4, 3]
})

# تعامل ضربی
data["age_income"] = data["age"] * data["income"]

# تعامل جمعی
data["income_plus_rooms"] = data["income"] + data["rooms"]

# تعامل منطقی
data["is_young_rich"] = (data["age"] < 30) & (data["income"] > 4)

print(data)
```

# 🌍 ۶. کاربردهای واقعی Feature Interaction

🔹 **بانک‌ها**
برای تشخیص ریسک و اعتبار اقتصادی مشتری

🔹 **فروشگاه‌های آنلاین**
تعامل *محصول + فصل* (مثلاً "کفش ورزشی در تابستان")

🔹 **سلامت**
تعامل سن × فشارخون
تشخیص بیماری‌ها بهتر می‌شود

🔹 **بازاریابی**
تعامل جنسیت + سن
برای شخصی‌سازی تبلیغات
