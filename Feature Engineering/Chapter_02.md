### 🔍 تفاوت ویژگی (Feature) و متغیر (Variable)

ببین، خیلیا این دو تا واژه رو یکی می‌دونن، ولی تفاوت ظریفی بینشونه:

* **متغیر (Variable)** یعنی داده‌ی خامی که توی دیتاست داریم (مثل «سن» یا «درآمد»).
* **ویژگی (Feature)** یعنی داده‌ای که ما **بعد از پردازش یا تغییر شکل دادن** از همون متغیر می‌سازیم.

🧩 مثال ساده:

> متغیر: «تاریخ تولد»
> ویژگی: «سن فعلی» که از تاریخ تولد محاسبه کردیم.

یعنی یه ویژگی، همیشه یه متغیرِ معنی‌دار و به‌دردبخوره که از دل داده‌ی خام استخراج شده 😎

---

### 🧠 ویژگی خوب چه ویژگی‌هایی داره؟

یه ویژگی خوب معمولاً باید این ۵ تا خصوصیت رو داشته باشه:

1. 🎯 **مرتبط باشه** → واقعاً روی خروجی مدل تأثیر داشته باشه
2. 🔍 **منحصر‌به‌فرد نباشه** → هر ردیف مقدار خاص خودش رو نداشته باشه (مثل شماره ملی که هیچ الگویی نداره)
3. 🔄 **تغییرپذیر باشه** → با تغییر داده‌ها تغییر کنه
4. ⚖️ **مقیاس مناسب داشته باشه** → خیلی بزرگ یا خیلی کوچک نباشه
5. 💬 **قابل تفسیر باشه** → وقتی دیدی، بدونی چی داره نشون می‌ده

---

### 📊 مثال عددی برای درک تفاوت

فرض کن یه دیتاست ساده از خریداران داری:

| نام  | تاریخ تولد | مبلغ خرید | آخرین خرید |
| :--- | :--------- | :-------- | :--------- |
| علی  | 1998-07-15 | 320000    | 2024-11-10 |
| سارا | 1985-01-12 | 920000    | 2024-11-05 |
| رضا  | 2002-05-03 | 180000    | 2024-10-22 |

ما می‌تونیم از این داده‌ها ویژگی‌های جدید بسازیم:

* **سن مشتری** → از تاریخ تولد
* **فاصله آخرین خرید تا امروز**
* **میانگین مبلغ خرید ماهانه**

همین تبدیل‌ها یعنی مهندسی ویژگی 💪

### 💻 نمونه کد پایتون برای ساخت چند ویژگی ساده:

```python
import pandas as pd
from datetime import datetime

# 🧾 داده خام
data = pd.DataFrame({
    'name': ['Ali', 'Sara', 'Reza'],
    'birth_date': ['1998-07-15', '1985-01-12', '2002-05-03'],
    'purchase_amount': [320000, 920000, 180000],
    'last_purchase': ['2024-11-10', '2024-11-05', '2024-10-22']
})

# ⏱ تبدیل به نوع تاریخ
data['birth_date'] = pd.to_datetime(data['birth_date'])
data['last_purchase'] = pd.to_datetime(data['last_purchase'])

# 📆 ساخت ویژگی سن
today = datetime(2025, 11, 11)
data['age'] = (today - data['birth_date']).dt.days // 365

# 🕓 ساخت ویژگی فاصله از آخرین خرید
data['days_since_last_purchase'] = (today - data['last_purchase']).dt.days

print(data[['name', 'age', 'days_since_last_purchase']])
```

📋 خروجی نمونه:

| name | age | days_since_last_purchase |
| :--: | :-: | :----------------------: |
|  Ali |  27 |             1            |
| Sara |  40 |             6            |
| Reza |  23 |            20            |

### 🧩 نکته مفهومی

🔸 ببین چقدر ساده از داده‌های خام (تاریخ تولد، آخرین خرید)
ویژگی‌هایی ساختیم که الان برای مدل معنی‌دارن.
مدل حالا می‌تونه بفهمه مثلاً مشتری‌های جوون‌تر معمولاً خریدهای بیشتری دارن یا نه.

🔹 مهندسی ویژگی فقط یه عملیات ریاضی نیست،
یه جور **درک عمیق از داده‌ها و رفتار انسان‌ها** هم هست.
