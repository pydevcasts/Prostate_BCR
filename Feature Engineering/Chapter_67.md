# 🔵 ۱. Feature Interaction یعنی چه؟

Feature Interaction یعنی:

**ترکیب دو یا چند ویژگی با هم برای ساخت یک ویژگی جدید که رابطه مشترک را نشان دهد.**

مثال بسیار ساده:

```
سن × درآمد
```

این ویژگی نشان می‌دهد:

* افراد مسن با درآمد بالا چه رفتاری دارند؟
* افراد جوان با درآمد کم چه ریسکی دارند؟

این ترکیب‌ها، *معنای جدید* تولید می‌کنند.

---

# 🟣 ۲. چرا Feature Interaction مهم است؟

### ⭐ دلیل ۱ — مدل‌های خطی هیچ تعاملی را به‌صورت خودکار پیدا نمی‌کنند

یعنی اگر دو ویژگی با هم یک الگوی قوی ایجاد کنند
مدل **نمی‌تواند آن را ببیند**
مگر خودمان آن را بسازیم.

### ⭐ دلیل ۲ — تعامل‌ها الگوهای پنهان را آشکار می‌کنند

مثلاً:

* درآمد به تنهایی → الگوی ضعیف
* سن به تنهایی → الگوی ضعیف
* درآمد × سن → الگوی قوی و قابل‌تشخیص

### ⭐ دلیل ۳ — تعامل‌ها پیچیدگی را برای مدل کم می‌کنند

به مدل کمک می‌کنند الگو را ساده‌تر یاد بگیرد.

---

# 🔥 ۳. انواع تعامل ویژگی‌ها

### 🟩 ۱. تعامل ضربی (Multiplicative) — مهم‌ترین نوع

```
df['interaction'] = df['income'] * df['age']
```

برای مدل‌های Logistic و Linear این ویژگی *طلایی* است.

---

### 🟦 ۲. تعامل تقسیم (Division Interaction)

گاهی رابطه نسبت‌گونه دارد:

```
df['ratio_interaction'] = df['feature1'] / df['feature2']
```

اگر feature2 کوچک شود، اثر feature1 شدیداً افزایش پیدا می‌کند.

---

### 🟧 ۳. تعامل جمع (Addition Interaction)

```
df['sum_interaction'] = df['speed'] + df['acceleration']
```

مواقعی کاربرد دارد که رفتار حاصل جمع معنی‌دار باشد.

---

### 🟪 ۴. تعامل تفاضلی (Difference Interaction)

```
df['difference'] = df['temperature_day'] - df['temperature_night']
```

برای پیدا کردن روندها بسیار مفید است.

---

### 🟫 ۵. تعامل‌های چندسطحی (High-order Interactions)

مثال:

```
age × income × credit_score
```

یا حتی:

```
(age × income) / debt
```

این تعامل‌ها الگوهای بسیار پیچیده را ساده می‌کنند.

---

# 📌 مثال عددی کاربردی

فرض کن داده زیر را داریم:

| سن | درآمد | بدهی |
| -- | ----- | ---- |
| 22 | 5M    | 12M  |
| 45 | 20M   | 8M   |
| 33 | 8M    | 4M   |

تعامل‌های قوی:

1️⃣ درآمد × سن

```
22×5 = 110
45×20 = 900
33×8 = 264
```

2️⃣ درآمد / بدهی

```
0.41
2.5
2.0
```

3️⃣ سن × (درآمد / بدهی)

```
22×0.41 = 9.02
45×2.5  = 112.5
33×2.0  = 66
```

این مقادیر ناگهان الگوی ریسک مالی را واضح می‌کنند 🔥

# 🧪 نمونه کد پایتون (راست‌چین نشود)

```
import pandas as pd

df['age_income'] = df['age'] * df['income']
df['income_debt_ratio'] = df['income'] / (df['debt'] + 1)
df['complex_interaction'] = df['age'] * df['income_debt_ratio']
```

# 🔵 ۴. بهترین مدل‌ها برای استفاده از تعامل‌ها

| مدل                 | تعامل‌ها را خودکار می‌گیرد؟ | نیاز به Feature Interaction دستی |
| ------------------- | --------------------------- | -------------------------------- |
| Logistic Regression | ❌ خیر                       | ✔️ خیلی زیاد                     |
| Linear Regression   | ❌ خیر                       | ✔️ خیلی زیاد                     |
| SVM خطی             | ❌ خیر                       | ✔️ زیاد                          |
| XGBoost / RF        | ✔️ تا حدی                   | متوسط                            |
| Neural Networks     | ✔️ بله                      | کم                               |

**نتیجه:**
تعامل‌های دستی مخصوصاً برای مدل‌های خطی معجزه می‌کنند.
