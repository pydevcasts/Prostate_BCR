### ⚖️ چرا باید داده‌ها را نرمال‌سازی کنیم؟

بعضی ویژگی‌ها مقیاس‌های بسیار متفاوتی دارن.
مثلاً:

| ویژگی         |   مقدار   |
| :------------ | :-------: |
| قد (cm)       |    180    |
| درآمد (تومان) | 9,000,000 |
| سن (سال)      |     25    |

اگر بدون نرمال‌سازی به مدل بدی، الگوریتم فکر می‌کنه درآمد مهم‌تره، چون عددش بزرگ‌تره 😅
درحالی‌که ممکنه «قد» یا «سن» تأثیر بیشتری روی پیش‌بینی داشته باشن.

پس باید همه‌ی ویژگی‌ها در یک محدوده‌ی قابل‌مقایسه قرار بگیرن — مثل تبدیل همه به بازه‌ی ۰ تا ۱ 🔢

---

### 🧮 روش‌های اصلی مقیاس‌بندی

| روش                              | توضیح                                       | مناسب برای              |
| :------------------------------- | :------------------------------------------ | :---------------------- |
| ⚙️ **Min-Max Scaling**           | تبدیل مقدارها به بازه‌ی ۰ تا ۱              | داده‌های بدون پرت       |
| 📈 **Standardization (Z-Score)** | تبدیل داده‌ها به میانگین ۰ و انحراف معیار ۱ | داده‌های با توزیع نرمال |
| 🧠 **Robust Scaling**            | کاهش اثر داده‌های پرت با استفاده از میانه   | داده‌های دارای Outlier  |

---

### 💡 ۱. نرمال‌سازی Min-Max Scaling

فرمول:
$$
x_{scaled} = \frac{x - x_{min}}{x_{max} - x_{min}}
$$

📘 مثال:

```python
import pandas as pd
from sklearn.preprocessing import MinMaxScaler

data = pd.DataFrame({'income': [3000000, 8000000, 15000000]})
scaler = MinMaxScaler()
data['income_scaled'] = scaler.fit_transform(data[['income']])
print(data)
```

📊 خروجی:

|   income   | income_scaled |
| :--------: | :-----------: |
|  3,000,000 |      0.0      |
|  8,000,000 |      0.38     |
| 15,000,000 |      1.0      |

✅ حالا همه در بازه‌ی بین ۰ و ۱ قرار گرفتن.

---

### 💡 ۲.استاندارد سازی Standardization (Z-Score)

فرمول:
$$
z = \frac{x - \mu}{\sigma}
$$
یعنی فاصله هر داده از میانگین تقسیم بر انحراف معیار.

```python
from sklearn.preprocessing import StandardScaler

data = pd.DataFrame({'height': [160, 170, 180, 190]})
scaler = StandardScaler()
data['height_zscore'] = scaler.fit_transform(data[['height']])
print(data)
```

📊 خروجی تقریبی:

| height | height_zscore |
| :----: | :-----------: |
|   160  |     -1.34     |
|   170  |     -0.45     |
|   180  |      0.45     |
|   190  |      1.34     |

📌 حالا میانگین = ۰ و پراکندگی = ۱

---

### 💡 ۳. مقیاس‌بندی مقاوم Robust Scaling

استفاده از میانه به‌جای میانگین برای مقابله با Outlierها:

```python
from sklearn.preprocessing import RobustScaler

data = pd.DataFrame({'price': [100, 150, 200, 10000]})
scaler = RobustScaler()
data['price_scaled'] = scaler.fit_transform(data[['price']])
print(data)
```

📊 خروجی:

| price | price_scaled |
| :---: | :----------: |
|  100  |     -0.5     |
|  150  |     -0.25    |
|  200  |      0.0     |
| 10000 |      7.5     |

📌 داده‌ی پرت (10000) تأثیر زیادی روی بقیه مقادیر نداره.

---

### 💬 نکته‌ی حرفه‌ای:

> همیشه قبل از انتخاب روش مقیاس‌بندی، توزیع داده‌هات رو بررسی کن.
> اگه داده‌هات پرت زیاد دارن، از Robust استفاده کن؛
> اگه داده‌هات نرمال هستن، از StandardScaler؛
> و اگه فقط می‌خوای مقدارها بین ۰ تا ۱ باشن، از Min-Max.
