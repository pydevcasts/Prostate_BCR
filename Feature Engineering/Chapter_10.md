### 🎯 هدف این بخش

تا الان یاد گرفتی:

* داده‌هات چه نوعی هستن (عددی، متنی، زمانی، مکانی)
* چطور اون‌ها رو تمیز کنی
* چطور متن‌ها رو عددی کنی
* و چطور مقادیر رو هم‌مقیاس (نرمال) بسازی

الان وقتشه که داده‌های آماده رو بین **آموزش (Train)** و **تست (Test)** تقسیم کنیم تا مدل بتونه یاد بگیره و بعد عملکردش رو بسنجیم 💪

---

### ⚖️ چرا باید داده‌ها را تقسیم کنیم؟

اگر همه‌ی داده‌ها رو فقط برای آموزش استفاده کنیم،
مدل فقط همون داده‌ها رو یاد می‌گیره و روی داده‌های جدید ضعیف عمل می‌کنه —
به این می‌گن **Overfitting** 😵

اما وقتی داده‌ها رو دو قسمت کنیم:

* بخش آموزش برای یادگیری
* بخش تست برای ارزیابی عملکرد مدل

اون‌وقت می‌تونیم بفهمیم مدل واقعاً چقدر خوب یاد گرفته 🎓

---

### 💻 کد پایتون برای تقسیم داده‌ها

```python
import pandas as pd
from sklearn.model_selection import train_test_split

# داده‌ی نمونه
data = pd.DataFrame({
    'age': [25, 30, 35, 40, 45, 50],
    'income': [5, 10, 15, 20, 25, 30],
    'purchases': [2, 4, 6, 8, 10, 12]
})

X = data[['age', 'income']]
y = data['purchases']

# ✂️ تقسیم داده به آموزش و تست (۷۰٪ آموزش، ۳۰٪ تست)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

print("Train Shape:", X_train.shape)
print("Test Shape:", X_test.shape)
```

📊 خروجی:

```
Train Shape: (4, 2)
Test Shape: (2, 2)
```

📌 حالا ۴ نمونه برای آموزش و ۲ نمونه برای تست داریم.

### 🧠 نکته‌ی طلایی

> همیشه بعد از آماده‌سازی داده‌ها (پاک‌سازی، عددی‌سازی، نرمال‌سازی)،
> اون‌ها رو به آموزش و تست تقسیم کن.

هر تغییری که روی داده‌ها اعمال می‌کنی، فقط باید **روی داده‌ی آموزش fit بشه**
و بعد همون تغییرات روی داده‌ی تست **اعمال (transform)** بشه، نه دوباره fit!

🔍 مثال:

```python
scaler.fit(X_train)        # فقط روی داده آموزش
X_train_scaled = scaler.transform(X_train)
X_test_scaled  = scaler.transform(X_test)  # فقط transform
```

---

### 💬 نکته‌ی حرفه‌ای برای مدل‌های بزرگ

اگر داده زیاد داری، می‌تونی بخشی رو هم برای **اعتبارسنجی (Validation)** جدا کنی:

> آموزش (Train) → ۷۰٪
> اعتبارسنجی (Validation) → ۱۵٪
> تست (Test) → ۱۵٪

مدل با داده آموزش یاد می‌گیره،
با داده Validation تنظیم می‌شه،
و با داده Test ارزیابی نهایی می‌شه 🔁
