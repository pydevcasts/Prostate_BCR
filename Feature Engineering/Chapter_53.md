## 🧠 ۱. مفهوم Embedded Methods

در این روش‌ها، **مدل یادگیری خودکار در حین آموزش** تصمیم می‌گیرد کدام ویژگی‌ها مهم هستند.

یعنی انتخاب ویژگی دیگر یک مرحله‌ی جدا نیست — بخشی از **فرآیند آموزش مدل** است 🎯

## 💡 ۳. LASSO Regression (انتخاب خودکار ویژگی‌ها با جریمه‌ی L1)

در رگرسیون LASSO، هدف این است که ضرایب ویژگی‌ها را کوچک کند،
و ویژگی‌هایی که تأثیری ندارند را **کاملاً صفر** کند.

📘 معادله‌ی هدف LASSO:

[
Loss = MSE + λ \sum |w_i|
]

λ (lambda) → پارامتر تنظیم‌کننده (هرچه بزرگ‌تر باشد، ویژگی‌های بیشتری صفر می‌شوند)

---

### 💻 کد نمونه پایتون

```python
from sklearn.linear_model import Lasso
from sklearn.datasets import load_boston
import pandas as pd

X, y = load_boston(return_X_y=True)
lasso = Lasso(alpha=0.1)
lasso.fit(X, y)

importance = pd.Series(lasso.coef_)
print(importance.sort_values(ascending=False))
```

📊 خروجی: ضرایب ویژگی‌ها
هر ویژگی با ضریب صفر → حذف می‌شود.

## 🌳 ۴. Decision Tree & Random Forest

در مدل‌های درختی، انتخاب ویژگی بر اساس **کاهش در خطای پیش‌بینی (Impurity Reduction)** است.
ویژگی‌هایی که در شاخه‌های بالاتر درخت ظاهر می‌شوند، اهمیت بیشتری دارند.

### 💻 کد نمونه

```python
from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import load_breast_cancer
import pandas as pd

X, y = load_breast_cancer(return_X_y=True)
model = RandomForestClassifier()
model.fit(X, y)

importance = pd.Series(model.feature_importances_)
print(importance.sort_values(ascending=False)[:5])
```

📈 ویژگی‌هایی که مقدار `feature_importances_` بیشتری دارند، مهم‌ترند.

## ⚖️ ۵. مقایسه Embedded با سایر روش‌ها

| ویژگی       | Filter        | Wrapper       | Embedded              |
| :---------- | :------------ | :------------ | :-------------------- |
| نیاز به مدل | ❌ ندارد       | ✅ دارد        | ✅ دارد                |
| سرعت        | 🔹 سریع       | 🔸 کند        | ⚡ متوسط               |
| دقت         | ⚙️ متوسط      | 🎯 بالا       | 🚀 بسیار بالا         |
| پیچیدگی     | ساده          | زیاد          | متوسط                 |
| مناسب برای  | داده‌های ساده | داده‌های کوچک | داده‌های واقعی و بزرگ |

## 🎨 ۶. تصویر پیشنهادی

> نموداری از یک درخت تصمیم با شاخه‌های رنگی؛
> در بالای درخت ویژگی‌های مهم‌تر با رنگ آبی تیره و پایین‌ترها با رنگ خاکستری.
> در کنار آن نمودار میله‌ای از مقدار اهمیت ویژگی‌ها از بزرگ به کوچک.
