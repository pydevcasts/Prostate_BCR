# 🔵 ۱. Polynomial Features (ویژگی‌های چندجمله‌ای)

یکی از قدرتمندترین روش‌ها برای نمایش رابطهٔ غیرخطی بین ویژگی‌ها.

اگر داده شامل:

```
سن
درآمد
```

باشد، مدل به صورت خطی نمی‌فهمد که با بالا رفتن سن، درآمد ابتدا زیاد می‌شود و بعد کم می‌شود.

اما با ویژگی‌های زیر، الگو آشکار می‌شود:

* سن²
* سن×درآمد
* درآمد²

---

## 📌 مثال عددی

فرض کن:

| سن | درآمد (میلیون) |
| -- | -------------- |
| 25 | 6              |
| 35 | 12             |
| 55 | 9              |

اگر ویژگی سن² را بسازیم:

| سن | سن²  | درآمد |
| -- | ---- | ----- |
| 25 | 625  | 6     |
| 35 | 1225 | 12    |
| 55 | 3025 | 9     |

الگو واضح‌تر می‌شود ⬆️

---

## 📌 نمونه کد پایتون (بدون شروع خط انگلیسی)

```
from sklearn.preprocessing import PolynomialFeatures
import pandas as pd

data = pd.DataFrame({
    'age': [25, 35, 55],
    'income': [6, 12, 9]
})

poly = PolynomialFeatures(degree=2, include_bias=False)
poly_features = poly.fit_transform(data)

pd.DataFrame(poly_features, columns=poly.get_feature_names_out(['age','income']))
```

# 🟣 ۲. Ratio Features (ویژگی‌های نسبت و تقسیم)

نسبت‌ها یکی از مهم‌ترین و کاربردی‌ترین ویژگی‌های ساخته‌شده در اکثر مدل‌های تجاری هستند.

نمونه‌های مهم:

* درآمد / سن
* بدهی / درآمد
* قیمت / وزن
* فروش امروز / فروش هفته قبل
* نرخ رشد = مقدار جدید / مقدار قدیمی

## 📌 مثال عددی

```
income = 10
age = 25

risk = income / age = 0.4
```

این مقدار، اطلاعات بسیار دقیق‌تری از risk به ما می‌دهد.

---

## 📌 نمونه کد پایتون

```
df['risk'] = df['income'] / df['age']
```

# 🟩 ۳. Aggregation Features (ویژگی‌های تجمیعی)

این ویژگی‌ها اغلب در:

* فروشگاه‌ها
* تراکنش مالی
* داده‌های زمانی
* دیتاهای کاربر-محصول

استفاده می‌شود.

نمونه‌ها:

* میانگین خریدهای مشتری
* بیشترین مبلغ خرید
* مجموع فروش ۳۰ روز اخیر
* تعداد لاگین‌ها طی هفته گذشته

---

## 📌 مثال عددی

خریدهای یک کاربر:

```
[120, 90, 300, 70]
```

ویژگی‌های جدید:

```
max_purchase = 300
min_purchase = 70
mean_purchase = 145
total_purchase = 580
```

---

## 📌 نمونه کد پایتون

```
df_grouped = df.groupby('user_id')['purchase'].agg(
    ['mean','max','min','sum','std']
).reset_index()
```

# 🔥 ۴. اختلاف‌ها، ضرب‌ها، لاگ و ریشه‌ها

### ✔ اختلاف‌ها

```
df['diff_price'] = df['new_price'] - df['old_price']
```

### ✔ ضرب‌ها

```
df['power'] = df['voltage'] * df['current']
```

### ✔ لگاریتیم

برای داده‌های با توزیع سنگین بسیار مفید است

```
df['log_income'] = np.log(df['income'] + 1)
```

### ✔ ریشه

```
df['sqrt_area'] = np.sqrt(df['area'])
```
