## 📘 ۱. چرا باید داده‌های متنی را به عددی تبدیل کنیم؟

مدل‌های یادگیری ماشین مثل **SVM، Logistic Regression، Neural Networks** فقط با اعداد کار می‌کنن.
اما داده‌های واقعی معمولاً شامل مقادیر متنی هستن:
مثل:

* جنسیت (Male / Female)
* کشور (Iran / USA / Japan)
* رنگ (Red / Blue / Green)
* نوع محصول (A / B / C)

📊 مدل ریاضی نمی‌تونه مستقیماً از رشته‌ی `"Red"` در محاسباتش استفاده کنه، پس باید به عدد تبدیلش کنیم.

---

### 🧩 مثال ساده

| رنگ  | برچسب عددی |
| :--- | :--------: |
| قرمز |      0     |
| آبی  |      1     |
| سبز  |      2     |

اما اینجا یه مشکل وجود داره... 😅
مدل ممکنه فکر کنه **۲ > ۱ > ۰** یعنی «سبز» از «آبی» بزرگ‌تره!
درحالی‌که فقط نام دسته‌ها عوض شده و هیچ ترتیب منطقی وجود نداره.
به همین دلیل روش‌های مختلفی از Encoding ایجاد شده تا از این اشتباه جلوگیری کنن.

---

## 🔢 ۲. Label Encoding

### 💡 مفهوم:

در Label Encoding، هر دسته (Category) به یک عدد منحصر‌به‌فرد اختصاص داده می‌شه.

📘 مثال:

| جنسیت  | مقدار عددی |
| :----- | :--------: |
| Male   |      0     |
| Female |      1     |

---

### 💻 کد پایتون – LabelEncoder

```python
import pandas as pd
from sklearn.preprocessing import LabelEncoder

data = pd.DataFrame({
    'Gender': ['Male', 'Female', 'Female', 'Male', 'Male']
})

encoder = LabelEncoder()
data['Gender_encoded'] = encoder.fit_transform(data['Gender'])

print(data)
```

📊 **خروجی:**

```
   Gender  Gender_encoded
0    Male               1
1  Female               0
2  Female               0
3    Male               1
4    Male               1
```

---

### ⚙️ نکات مهم Label Encoding

✅ ساده و سریع است
✅ مناسب برای ویژگی‌هایی با **ترتیب واقعی** (مثل رتبه‌ها: کم، متوسط، زیاد)
❌ اما در داده‌های **غیرترتیبی** (مثل رنگ، کشور) ممکن است باعث اشتباه مدل شود

---

### 🧠 مثال از اشتباه Label Encoding

فرض کن داریم:

| کشور  |  کد |
| :---- | :-: |
| Iran  |  0  |
| Japan |  1  |
| USA   |  2  |

مدل ممکنه تصور کنه آمریکا (۲) از ژاپن (۱) "بزرگ‌تر" است! 😅
برای جلوگیری از این اشتباه، از روش **One-Hot Encoding** استفاده می‌کنیم (در صفحه بعد).

---

### 🎨 تصویر پیشنهادی

> تصویری از یک جدول که در ستون اول کشورها و در ستون دوم مقادیر عددی (Label Encoding) نمایش داده شده،
> با پیکان قرمز که نشان می‌دهد ترتیب اعداد ممکن است مدل را گمراه کند.

---

### 💬 گفت‌وگوی استاد و دانشجو 🎓

👩‍🎓 استاد، پس Label Encoding همیشه اشتباهه؟
👨‍🏫 نه، فقط زمانی که دسته‌ها ترتیب ندارن.
👩‍🎓 یعنی مثلاً برای «سایز لباس» که Small < Medium < Large داریم، درسته؟
👨‍🏫 دقیقاً 👏 اون‌جا چون ترتیب واقعی داریم، Label Encoding عالیه.

### 🧩 تمرین
