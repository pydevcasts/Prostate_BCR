## 🕰️ ۱. اهمیت ویژگی‌های زمانی

در داده‌هایی مثل فروش، ترافیک سایت، آب‌وهوا یا رفتار کاربران، **زمان نقش کلیدی داره.**
ویژگی‌های زمانی به مدل کمک می‌کنن بفهمه:

* در چه زمانی رفتار تغییر می‌کنه؟
* آیا الگوی فصلی یا روزانه وجود داره؟
* فاصله بین رخدادها چقدره؟

📅 مثلاً فروش ممکنه در آخر هفته زیاد بشه یا دمای هوا در تابستان بالا بره.

---

## 📘 ۲. استخراج اجزای زمان (DateTime Components)

با کمک پکیج **pandas** می‌تونیم تاریخ‌ها رو به اجزای مختلف تقسیم کنیم:

| ویژگی جدید   | توضیح          | مثال       |
| :----------- | :------------- | :--------- |
| `year`       | سال            | 2025       |
| `month`      | ماه            | 11         |
| `day`        | روز ماه        | 11         |
| `weekday`    | روز هفته       | دوشنبه     |
| `hour`       | ساعت           | 14         |
| `is_weekend` | آیا تعطیل است؟ | True/False |

---

### 💻 مثال پایتون

```python
import pandas as pd

data = pd.DataFrame({
    'date': pd.date_range(start='2025-11-01', periods=5, freq='D')
})

data['year'] = data['date'].dt.year
data['month'] = data['date'].dt.month
data['day'] = data['date'].dt.day
data['weekday'] = data['date'].dt.day_name()
data['is_weekend'] = data['weekday'].isin(['Friday', 'Saturday'])

print(data)
```

📊 **خروجی:**

```
        date  year  month  day   weekday  is_weekend
0 2025-11-01  2025     11    1   Saturday       True
1 2025-11-02  2025     11    2     Sunday      False
2 2025-11-03  2025     11    3     Monday      False
3 2025-11-04  2025     11    4    Tuesday      False
4 2025-11-05  2025     11    5  Wednesday      False
```

✅ حالا مدل می‌تونه بفهمه مثلاً آیا فروش در روزهای تعطیل بالا می‌ره یا نه.

## 🔁 ۳. ویژگی‌های چرخه‌ای (Cyclical Features)

ویژگی‌هایی مثل **ماه یا ساعت** چرخه‌ای هستن ⏳
مثلاً ساعت ۲۳ شب و ساعت ۱ بامداد به هم نزدیک‌ترن،
اما اگه عددی در نظر بگیریم (۲۳ و ۱)، مدل فکر می‌کنه خیلی از هم دورن! 😅

برای حل این مشکل، از **تابع سینوسی و کسینوسی** استفاده می‌کنیم:

[
x_{sin} = \sin\left(\frac{2π \times value}{max_value}\right)
]
[
x_{cos} = \cos\left(\frac{2π \times value}{max_value}\right)
]

---

### 💻 مثال پایتون

```python
import numpy as np

data['hour'] = [0, 6, 12, 18, 23]
data['hour_sin'] = np.sin(2 * np.pi * data['hour'] / 24)
data['hour_cos'] = np.cos(2 * np.pi * data['hour'] / 24)

print(data[['hour', 'hour_sin', 'hour_cos']])
```

📊 **خروجی:**

```
   hour  hour_sin  hour_cos
0     0  0.000000  1.000000
1     6  1.000000  0.000000
2    12  0.000000 -1.000000
3    18 -1.000000  0.000000
4    23 -0.258819  0.965925
```

✅ با این تبدیل، مدل متوجه می‌شه که ۲۳ و ۱ نزدیک‌ان چون سین و کسین مشابه دارن.

## ⏳ ۴. محاسبه فاصله زمانی بین رخدادها

گاهی ویژگی مهم اینه که **چقدر فاصله زمانی بین دو اتفاق وجود داره.**
مثلاً:

* چند روز از آخرین خرید گذشته؟
* فاصله بین دو تراکنش چقدره؟

---

### 💻 مثال پایتون

```python
data = pd.DataFrame({
    'customer_id': [1, 1, 1, 2, 2],
    'purchase_date': pd.to_datetime([
        '2025-10-01', '2025-10-05', '2025-10-20',
        '2025-10-03', '2025-10-10'
    ])
})

data = data.sort_values(by=['customer_id', 'purchase_date'])
data['days_since_last'] = data.groupby('customer_id')['purchase_date'].diff().dt.days

print(data)
```

📊 **خروجی:**

```
   customer_id purchase_date  days_since_last
0            1    2025-10-01              NaN
1            1    2025-10-05              4.0
2            1    2025-10-20             15.0
3            2    2025-10-03              NaN
4            2    2025-10-10              7.0
```

✅ حالا مدل می‌فهمه مشتری شماره ۱ معمولاً هر چند روز یک‌بار خرید می‌کنه.

## 📅 ۵. ترکیب ویژگی‌های زمانی با دیگر داده‌ها

گاهی با ترکیب تاریخ با قیمت یا فروش،
می‌تونی ویژگی‌هایی مثل این بسازی:

| ویژگی جدید              | فرمول                                 | معنا                |
| :---------------------- | :------------------------------------ | :------------------ |
| `Revenue_per_Day`       | Revenue / Day                         | میانگین فروش روزانه |
| `Growth_Rate`           | (Value_t – Value_(t-1)) / Value_(t-1) | نرخ رشد             |
| `Days_Since_Last_Event` | تفاوت بین تاریخ فعلی و قبلی           | فاصله رخدادها       |
