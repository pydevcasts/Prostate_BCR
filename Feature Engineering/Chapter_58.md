## ⏳ ۱. چرا ویژگی‌های زمانی مهم هستند؟

در داده‌های زمانی رفتارها *وابسته به گذشته* هستند.
مثال‌ها:

* فروش دیروز روی فروش امروز اثر دارد
* ترافیک ساعت ۸ صبح همیشه مشابه است
* مصرف برق شب‌ها بیشتر است

پس باید ویژگی‌هایی استخراج کنیم که مدل *زمان* را بفهمد.

---

## 📅 ۲. استخراج ویژگی از تاریخ (Date Decomposition)

فرض کن یک ستون تاریخ داری:

```
2024-01-14 10:25:00
```

از این تاریخ می‌توانیم ده‌ها ویژگی بسازیم:

| ویژگی                  | نمونه | کاربرد           |
| ---------------------- | ----- | ---------------- |
| سال (Year)             | 2024  | روند بلندمدت     |
| ماه (Month)            | 1     | فصل فروش         |
| روز هفته (Day of Week) | 6     | تشخیص تعطیلات    |
| روز ماه (Day)          | 14    | رفتارهای دوره‌ای |
| ساعت (Hour)            | 10    | ساعات پربازدید   |
| آخر هفته بودن          | 0/1   | زمان تعطیلی      |
| فصل سال                | 1–4   | فصل‌های آب‌وهوا  |

## 🌀 ۳. ویژگی‌های چرخه‌ای (Cyclic Features)

مشکل بزرگ دادهٔ زمانی:

**روزهای هفته چرخه‌ای هستند اما مدل این را نمی‌فهمد.**

مثلاً:

```
شنبه = 0
جمعه = 6
```

اما «شنبه» به «جمعه» نزدیک است (فقط یک روز فاصله دارد!)
ولی مدل فکر می‌کند 0 و 6 خیلی دورند.

راه‌حل: تبدیل چرخه‌ای با سینوس و کسینوس:

```
sin( 2π * value / max )
cos( 2π * value / max )
```

مثال برای روز هفته:

| روز | sin   | cos           |
| --- | ----- | ------------- |
| 0   | 0.0   | 1.0           |
| 3   | 0.866 | -0.5          |
| 6   | 0.0   | 1.0 ← نزدیک 0 |

به همین دلیل مدل چرخه را می‌فهمد.

## 🔁 ۴. ویژگی‌های Lag (ویژگی‌های گذشته)

یکی از اساسی‌ترین مفاهیم.

Lag یعنی مقدار گذشته را به عنوان ویژگی وارد مدل کنیم:

| روز | فروش | Lag1 (فروش دیروز) |
| --- | ---- | ----------------- |
| 1   | 10   | NaN               |
| 2   | 12   | 10                |
| 3   | 15   | 12                |

Lag رایج:

* Lag1
* Lag7 (هفت روز پیش)
* Lag30 (یک ماه پیش)

بدون Lag مدل اصلاً رفتارهای گذشته را نمی‌فهمد.

---

## 📉 ۵. ویژگی‌های Rolling (میانگین متحرک)

میانگین متحرک برای یافتن روندهای کوتاه‌مدت عالی است.

مثال Rolling 3-day:

| روز | فروش | MA3                 |
| --- | ---- | ------------------- |
| 3   | 15   | (10+12+15)/3 = 12.3 |

انواع مهم:

* Rolling Mean
* Rolling Median
* Rolling Std
* Rolling Max / Min

---

## 📈 ۶. ویژگی Trend (روند بلندمدت)

 این ویژگی نشان می‌دهد مقدار دارد صعودی می‌شود یا نزولی.

مثال:

```
trend = (value_today – value_7_days_ago) / 7
```

# 🧮 ۷. کد پایتون — استخراج انواع ویژگی‌های زمانی


```python

import pandas as pd
import numpy as np

# دیتای نمونه
data = pd.DataFrame({
    "date": pd.date_range(start="2024-01-01", periods=10, freq="D"),
    "sales": [10, 12, 11, 14, 13, 18, 20, 17, 21, 23]
})

# تبدیل تاریخ
data["year"] = data["date"].dt.year
data["month"] = data["date"].dt.month
data["day"] = data["date"].dt.day
data["weekday"] = data["date"].dt.weekday
data["hour"] = data["date"].dt.hour

# ویژگی چرخه‌ای
data["weekday_sin"] = np.sin(2 * np.pi * data["weekday"] / 7)
data["weekday_cos"] = np.cos(2 * np.pi * data["weekday"] / 7)

# lag
data["lag1"] = data["sales"].shift(1)
data["lag7"] = data["sales"].shift(7)

# rolling
data["rolling_mean_3"] = data["sales"].rolling(3).mean()
data["rolling_std_3"] = data["sales"].rolling(3).std()

print(data)
```
