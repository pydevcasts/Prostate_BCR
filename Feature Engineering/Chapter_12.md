### 🔹 مفهوم کلی Filter Methods

🧮 روش‌های فیلتر، اولین و ساده‌ترین راه برای انتخاب ویژگی هستن.
در این روش‌ها مدل یادگیری ساخته نمی‌شه؛ فقط با کمک معیارهای آماری بررسی می‌کنیم هر ویژگی چقدر با متغیر هدف (Label) ارتباط داره.

📊 هر ویژگی امتیازی (Score) می‌گیره و بعد ویژگی‌هایی با امتیاز پایین حذف می‌شن ✂️

---

### ⚙️ مزایا و معایب

| مزیت                          | توضیح                                     |
| :---------------------------- | :---------------------------------------- |
| ⚡ بسیار سریع                  | نیازی به آموزش مدل نیست                   |
| 📈 مناسب برای دیتاست‌های بزرگ | چون فقط محاسبه‌ی آماری انجام می‌ده        |
| 🧠 ساده برای تفسیر            | نتایج عددی و قابل فهم                     |
| ⚠️ اما محدودیت دارد           | چون رابطه بین ویژگی‌ها را در نظر نمی‌گیرد |

---

### 📘 روش‌های پرکاربرد در گروه Filter

| نام روش                             |        نوع داده       | توضیح ساده                                |
| :---------------------------------- | :-------------------: | :---------------------------------------- |
| 🔸 **Correlation (همبستگی)**        |          عددی         | بررسی رابطه خطی بین ویژگی و هدف           |
| 🔹 **Chi-Square Test**              | طبقه‌ای (Categorical) | آزمون آماری برای بررسی وابستگی دو متغیر   |
| 🔸 **ANOVA (Analysis of Variance)** |     عددی + دسته‌ای    | بررسی تفاوت میانگین گروه‌ها               |
| 🔹 **Mutual Information**           |      عددی یا متنی     | بررسی میزان اطلاعات مشترک بین ویژگی و هدف |

---

### 📊 مثال ۱: همبستگی (Correlation)

فرض کن می‌خواهی قیمت خانه را پیش‌بینی کنی و ویژگی‌هایی داری مثل:
`متراژ، تعداد اتاق، فاصله از مترو، رنگ دیوار`

می‌توانی با محاسبه‌ی همبستگی (Correlation) بفهمی کدام ویژگی تأثیر بیشتری دارد 👇

```python
import pandas as pd

data = pd.DataFrame({
    'price': [200, 250, 300, 350, 400],
    'area': [50, 70, 90, 110, 130],
    'rooms': [2, 3, 4, 4, 5],
    'distance_metro': [10, 8, 6, 4, 2]
})

# محاسبه همبستگی با قیمت
corr = data.corr(numeric_only=True)['price'].sort_values(ascending=False)
print(corr)
```

📊 خروجی:

| ویژگی          | ضریب همبستگی با قیمت |
| :------------- | :------------------: |
| area           |         0.99         |
| rooms          |         0.92         |
| distance_metro |         -0.97        |

✅ پس می‌فهمیم متراژ و فاصله از مترو مهم‌ترین عوامل‌اند، ولی رنگ دیوار اصلاً مهم نیست 😄

### 📊 مثال ۲: آزمون Chi-Square

برای داده‌های طبقه‌ای مثل "جنسیت" و "خرید/نخرید" از آزمون Chi-Square استفاده می‌کنیم:

```python
from sklearn.feature_selection import chi2
from sklearn.preprocessing import LabelEncoder
from sklearn.feature_selection import SelectKBest
import pandas as pd

data = pd.DataFrame({
    'gender': ['M', 'F', 'F', 'M', 'M', 'F'],
    'age_group': ['young', 'old', 'young', 'middle', 'old', 'young'],
    'buy': [1, 0, 1, 0, 0, 1]
})

# تبدیل داده‌های متنی به عددی
enc = LabelEncoder()
data = data.apply(enc.fit_transform)

X = data[['gender', 'age_group']]
y = data['buy']

# محاسبه آزمون کای-دو
chi_scores = chi2(X, y)
for feature, score in zip(X.columns, chi_scores[0]):
    print(f"{feature}: {score:.2f}")
```

📈 خروجی تقریبی:

```
gender: 0.10  
age_group: 4.53
```

✅ نتیجه: ویژگی **سن** (age_group) تأثیر بیشتری روی خرید دارد.

---

### 🧠 نکته‌ی حرفه‌ای

> روش‌های فیلتر برای شروع عالی‌اند،
> ولی همیشه نتیجه‌ی نهایی را با مدل واقعی بررسی کن.
> چون ممکن است دو ویژگی با هم ترکیب شوند و تأثیر بیشتری بگذارند (که Filter آن را نمی‌بیند).

### 🧩 تمرین

یک دیتاست فرضی بساز با سه ستون:
`سن، درآمد، تصمیم خرید (۱ یا ۰)`
از آزمون Chi-Square استفاده کن تا بفهمی کدام ویژگی مهم‌تر است.
