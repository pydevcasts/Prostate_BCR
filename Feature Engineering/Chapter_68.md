## 🔵 ۱. ویژگی‌های آماری (Statistical Features)

این ویژگی‌ها برای داده‌هایی مثل:

* سنجش‌های حسگر
* سری‌های زمانی
* رفتار کاربران
* صدای خام
* شتاب‌سنج گوشی و خودرو

بسیار مهم‌اند.

### مهم‌ترین ویژگی‌های آماری:

* میانگین (Mean)
* میانه (Median)
* انحراف معیار (Std)
* واریانس
* بیشینه و کمینه
* Range = (max - min)
* Skewness (چولگی توزیع)
* Kurtosis (کشیدگی توزیع)

---

## 📌 مثال عددی

فرض کن دادهٔ حسگر:

```
[2, 5, 8, 3, 10]
```

محاسبات:

```
mean = 5.6
std  = 3.0
max  = 10
min  = 2
range = 8
```

این ویژگی‌ها الگوی رفتار حسگر را به مدل منتقل می‌کند.

---

## 📌 نمونه کد پایتون

```
df['mean_val'] = df['signal'].rolling(window=10).mean()
df['std_val']  = df['signal'].rolling(window=10).std()
df['max_val']  = df['signal'].rolling(window=10).max()
df['min_val']  = df['signal'].rolling(window=10).min()
```

## 🟣 ۲. ویژگی‌های Rolling Window (برای سری زمانی)

ویژگی‌های "پنجره‌ای" قدرت سری زمانی را چند برابر می کنند.

### مثال‌ها:

* میانگین ۷ روز اخیر فروش
* میانگین 3 رکورد حسگر قبلی
* اختلاف امروز با بیشینهٔ 30 روز اخیر
* شتاب لحظه‌ای = اختلاف سرعت‌های پشت سر هم

---

### 📌 مثال عددی

فروش ۵ روز اخیر:

```
[10, 12, 9, 20, 25]
```

میانگین ۳ روزه:

```
روز 3 → (10+12+9)/3 = 10.3  
روز 4 → (12+9+20)/3 = 13.7  
روز 5 → (9+20+25)/3 = 18
```

---

### 📌 نمونه کد پایتون

```
df['rolling_mean_7'] = df['sales'].rolling(window=7).mean()
df['rolling_std_7']  = df['sales'].rolling(window=7).std()
df['rolling_max_30'] = df['sales'].rolling(window=30).max()
```

## 🔥 ۳. ویژگی‌های سیگنالی (Signal Features)

برای داده‌های صوتی، حسگری، ECG، IMU و شتاب‌سنج بسیار مهم‌اند.

### مهم‌ترین ویژگی‌ها:

✔ انرژی سیگنال
✔ تعداد قله‌ها (Peaks)
✔ قدرت فرکانسی سیگنال (FFT)
✔ RMS (ریشه میانگین مربع)
✔ Zero Crossing Rate (تعداد عبور از صفر)
✔ Spectral Power

---

### 📌 انرژی سیگنال

```
energy = sum(x²)
```

مثال:

```
signal = [2, -3, 1]
energy = 4 + 9 + 1 = 14
```

---

### 📌 نمونه کد پایتون (FFT)

```
import numpy as np

df['fft_energy'] = np.abs(np.fft.fft(df['signal']))**2
```

## 🟩 ۴. ویژگی‌های مبتنی بر Domain Knowledge

اینجاست که مهارت واقعی یک Data Scientist مشخص می‌شود.

### مثال‌های واقعی:

### 💰 صنعت مالی

* نسبت بدهی به درآمد
* میانگین تراکنش‌های ۳۰ روز اخیر
* ریسک اعتباری = بدهی / (درآمد × سن)

### 🛒 فروشگاه‌ها

* نرخ تبدیل مشتری
* میانگین خرید هر کاربر
* زمان بین دو خرید (Inter-Purchase Time)

### 🚗 خودرو

* مصرف سوخت = کیلومتر / لیتر
* شتاب = اختلاف سرعت / زمان
* قدرت موتور = گشتاور × rpm

### 🌡 داده حسگر

* تعداد قله‌های غیرعادی
* اختلاف میانگین شب و روز
* نرخ تغییرات (Rate of Change)

این ویژگی‌ها دقیق‌ترین پیش‌بینی‌ها را می‌سازند.

---

## 🎨 تصویر پیشنهادی این صفحه

یک سیگنال (مثلاً موج ECG)

* نمودار پنجرهٔ ۲۰ نقطه‌ای که میانگین را نشان می‌دهد
* نمودار FFT برای تحلیل فرکانس

---

## 🧠 تمرین پیشنهادی

یکی از موارد زیر را انتخاب کن و یک ویژگی بساز:

1. **سری زمانی فروش:**
   مجموع ۱۴ روز اخیر + میانگین ۷ روز اخیر + اختلاف امروز و دیروز

2. **سیگنال حسگر:**
   انرژی سیگنال + تعداد قله‌ها + RMS

3. **دادهٔ مالی:**
   بدهی / درآمد + میانگین تراکنش ماه اخیر

4. **دادهٔ مکانیکی:**
   قدرت = گشتاور × rpm
