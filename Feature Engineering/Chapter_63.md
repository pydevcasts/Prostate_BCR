## 🔵 ۱. چیست؟ Target Encoding 

یعنی **برای هر دسته، میانگین مقدار Target را حساب می‌کنیم و جایگزین خود دسته می‌کنیم.**

مثال:

| City   | Salary |
| ------ | ------ |
| Tehran | 50     |
| Tabriz | 30     |
| Tehran | 60     |
| Shiraz | 40     |

محاسبهٔ میانگین:

* Tehran → 55
* Tabriz → 30
* Shiraz → 40

پس ستون City تبدیل می‌شود به:

| City   | T_Enc |
| ------ | ----- |
| Tehran | 55    |
| Tabriz | 30    |
| Tehran | 55    |
| Shiraz | 40    |

🔍 **این دقیقاً یعنی استفاده از الگوی رفتار هدف برای Encoding.**

---

## 🔥 ۲. چرا Target Encoding فوق‌العاده قدرتمند است؟

زیرا اطلاعات را کاهش نمی‌دهد
و مدل **روابط واقعی بین گروه‌ها و هدف** را یاد می‌گیرد.

✔️ مناسب برای داده‌های بزرگ
✔️ مناسب برای داده‌های با دسته‌های زیاد
✔️ بهترین روش برای مدل‌های خطی و درختی
✔️ کاملاً سازگار با XGBoost

طبقه‌بندی‌هایی مثل:

* شهر، محصول، کشور
* شناسه فروشنده
* شناسه مشتری
* دسته‌بندی‌های بسیار زیاد → ۵۰۰۰+ دسته

با One-Hot نابود می‌شوند، ولی با Target Encoding عالی کار می‌کنند.

---

## ⚠️ ۳. خطر بزرگ Target Encoding

**بزرگ‌ترین مشکل:**
اگر روی کل داده میانگین را حساب کنید → مدل تقلب می‌کند.

این اتفاق به نام:
🔥 **Data Leakage**
شناخته می‌شود و مدل ظاهراً عالی عمل می‌کند
اما در عمل کاملاً می‌بازد.

---

## 🟣 ۴. راه‌حل جلوگیری از Data Leakage

سه روش استاندارد وجود دارد:

---

### ✔️ روش ۱ — K-Fold Target Encoding (بهترین روش)

برای هر Fold، میانگین Target را فقط روی Train همان Fold حساب می‌کنی
و به دادهٔ Validation دست نمی‌زنی.

این روش در Kaggle استاندارد اصلی است.

---

### ✔️ روش ۲ — Noise اضافه کردن

به مقدار هر دسته کمی نویز Gaussian اضافه می‌شود:

```
encoded_value = mean + N(0, sigma)
```

این باعث می‌شود مدل روی میانگین‌ها Overfit نکند.

---

### ✔️ روش ۳ — Smoothing

اگر دسته‌ای فِرِکوئنسی کم داشته باشد
نباید میانگین Targetش صد درصد اعمال شود.

فرمول حرفه‌ای:

```
Te = (mean_cat * n + mean_global * alpha) / (n + alpha)
```

این روش فوق‌العاده است و در صنعت بسیار استفاده می‌شود.

---

## 🧪 ۵. مثال عددی — با Smoothing و بدون Leakage

فرض کن داریم:

| City   | Salary |
| ------ | ------ |
| Tehran | 50     |
| Tehran | 60     |
| Tabriz | 70     |
| Zanjan | 10     |

میانگین کلی = 47.5

خوب Zanjan فقط ۱ داده دارد → قابل اعتماد نیست.
با Smoothing:

```
Tehran = (55*2 + 47.5*5) / (7) ≈ 50.7
Zanjan = (10*1 + 47.5*5) / (6) ≈ 40.4
```

این یعنی مقدار Zanjan خیلی بهتر پیش‌بینی می‌شود.

---

## 💻 ۶. کد پایتون — Target Encoding با Smoothing


```python
import pandas as pd
import numpy as np

def target_encode(df, col, target, alpha=5):
    global_mean = df[target].mean()
    stats = df.groupby(col)[target].agg(['mean', 'count'])
    smooth = (stats['mean'] * stats['count'] + global_mean * alpha) / (stats['count'] + alpha)
    return df[col].map(smooth)

df = pd.DataFrame({
    "city": ["Tehran", "Tehran", "Tabriz", "Zanjan"],
    "salary": [50, 60, 70, 10]
})

df["city_encoded"] = target_encode(df, "city", "salary", alpha=5)
print(df)
```
