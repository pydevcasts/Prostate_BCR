### 🧠 مرحله ۱: شناسایی داده‌های گمشده

در پایتون با pandas خیلی راحت می‌تونی ببینی کجاها داده گمشده‌ست 👇

```python
import pandas as pd

data = pd.DataFrame({
    'age': [25, None, 40, 35],
    'income': [8000000, 9500000, None, 12000000],
    'gender': ['male', 'female', None, 'male']
})

print(data.isnull().sum())
```

📋 خروجی:

```
age       1
income    1
gender    1
dtype: int64
```

✅ یعنی هر ستون یکی از مقادیرش گم شده.

---

### 🧩 مرحله ۲: برخورد با مقادیر گمشده

سه راه اصلی داریم 👇

| روش                             | توضیح                     | کاربرد                 |
| :------------------------------ | :------------------------ | :--------------------- |
| 🗑️ حذف رکورد                   | حذف سطرهایی که داده ندارن | وقتی تعدادشون خیلی کمه |
| 🧮 جایگزینی با مقدار میانگین/مد | برای داده عددی            |                        |
| 🗂️ جایگزینی با بیشترین تکرار   | برای داده متنی            |                        |

مثلاً:

```python
data['age'].fillna(data['age'].mean(), inplace=True)
data['gender'].fillna(data['gender'].mode()[0], inplace=True)
```

---

### ⚙️ مرحله ۳: اصلاح نوع داده‌ها (Type Conversion)

گاهی اوقات نوع داده اشتباه خونده می‌شه.
مثلاً تاریخ‌ها به‌صورت رشته (string) ذخیره می‌شن، باید به datetime تبدیل بشن:

```python
data['purchase_date'] = pd.to_datetime(data['purchase_date'], errors='coerce')
```

📌 نکته: `errors='coerce'` باعث می‌شه تاریخ‌های اشتباه به مقدار گمشده تبدیل شن تا بعداً اصلاحشون کنی.

---

### 📈 مرحله ۴: شناسایی داده‌های پرت (Outliers)

داده پرت یعنی مقداری که خیلی با بقیه متفاوته (مثلاً سن = 250 سال!).
یکی از روش‌های ساده شناسایی، استفاده از نمودار Boxplot هست.

```python
import seaborn as sns
sns.boxplot(x=data['income'])
```

📊 اگر نقطه‌هایی خارج از محدوده‌ی جعبه دیدی، اون‌ها داده‌های پرت هستن.

می‌تونی اون‌ها رو حذف یا اصلاح کنی. مثلاً:

```python
q1 = data['income'].quantile(0.25)
q3 = data['income'].quantile(0.75)
iqr = q3 - q1
data = data[(data['income'] >= q1 - 1.5 * iqr) & (data['income'] <= q3 + 1.5 * iqr)]
```

---

### 🔁 مرحله ۵: حذف داده‌های تکراری

گاهی چند ردیف کاملاً یکسان تکرار می‌شن.
با دستور زیر راحت حذفشون کن:

```python
data.drop_duplicates(inplace=True)
```
