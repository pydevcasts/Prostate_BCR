---

### ⚙️ دسته‌بندی کلی روش‌های ریاضی برای ساخت ویژگی

| نوع روش                               | توضیح ساده                        | مثال کاربردی                 |
| :------------------------------------ | :-------------------------------- | :--------------------------- |
| ➕ **ترکیب خطی**                       | جمع یا تفریق چند ویژگی            | درآمد کل = حقوق + پاداش      |
| ✖️ **ترکیب غیرخطی**                   | ضرب، توان یا لگاریتم ویژگی‌ها     | قدرت خرید = درآمد × پس‌انداز |
| 🔢 **نسبتی (Ratio)**                  | تقسیم دو ویژگی برای یافتن تعادل   | نسبت هزینه به درآمد          |
| 📈 **تبدیل لگاریتمی (Log Transform)** | کاهش اثر داده‌های با مقیاس بزرگ   | log(درآمد)                   |
| 📊 **استانداردسازی و نرمال‌سازی**     | هم‌مقیاس کردن داده‌ها برای مدل‌ها | z = (x - mean) / std         |

---

### 🧮 مثال ۱: ترکیب خطی

فرض کن دو ویژگی داری:
`حقوق` و `پاداش`.
می‌خوای «درآمد کل» رو بسازی 👇

```python
import pandas as pd

data = pd.DataFrame({
    'salary': [10_000_000, 12_000_000, 15_000_000],
    'bonus': [2_000_000, 1_000_000, 3_000_000]
})

data['total_income'] = data['salary'] + data['bonus']
print(data)
```

📊 خروجی:

|  salary  |  bonus  | total_income |
| :------: | :-----: | :----------: |
| 10000000 | 2000000 |   12000000   |
| 12000000 | 1000000 |   13000000   |
| 15000000 | 3000000 |   18000000   |

💡 حالا مدل می‌تونه رابطه‌ی مستقیمی بین «درآمد کل» و رضایت شغلی پیدا کنه.

---

### 📉 مثال ۲: تبدیل لگاریتمی

وقتی داده‌هات مقیاس خیلی متفاوتی دارن (مثلاً درآمد از ۱ تا ۱۰۰ میلیون)،
می‌تونی با `log()` مقیاس رو منطقی‌تر کنی.

```python
import numpy as np

data['log_income'] = np.log(data['total_income'])
print(data)
```

📊 حالا ویژگی `log_income` باعث می‌شه مدل بهتر روی اختلاف‌های کوچک حساس باشه
و مقادیر خیلی بزرگ، اثر افراطی نداشته باشن ✨

---

### 🧮 مثال ۳: نسبت ویژگی‌ها

یکی از پرکاربردترین روش‌ها در تحلیل مالی و اقتصادی 💰

```python
data['bonus_ratio'] = data['bonus'] / data['salary']
print(data)
```

📊 خروجی:

|  salary  |  bonus  | bonus_ratio |
| :------: | :-----: | :---------: |
| 10000000 | 2000000 |     0.20    |
| 12000000 | 1000000 |     0.08    |
| 15000000 | 3000000 |     0.20    |

💡 نتیجه: کارمندان اول و سوم پاداش بیشتری نسبت به حقوقشون گرفتن.

---

### 📏 مثال ۴: استانداردسازی داده‌ها

وقتی ویژگی‌ها مقیاس متفاوت دارن (مثلاً سن بین ۲۰ تا ۶۰ و درآمد بین میلیون‌ها)،
مدل دچار سوگیری می‌شه. پس باید همه رو در یک مقیاس بیاریم 👇

```python
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
data_scaled = scaler.fit_transform(data[['salary', 'bonus', 'total_income']])
```

📘 حالا همه‌ی ویژگی‌ها میانگین صفر و واریانس یک دارن،
که برای الگوریتم‌هایی مثل Logistic Regression و KNN خیلی مهمه ⚖️

---

### 💬 گفت‌وگوی استاد و دانشجو

👩‍💻 دانشجو: استاد، همه‌ی این تبدیل‌ها لازمه؟
👨‍🏫 نه همیشه، ولی باید بدونی کی و کجا ازشون استفاده کنی.
👩‍💻 مثلاً اگه داده من درآمد باشه با تفاوت زیاد؟
👨‍🏫 اون موقع از log استفاده کن تا اثر مقادیر بزرگ کمتر بشه 😉

---

### 🧩 تمرین

با استفاده از داده‌ای شامل:
`سن، درآمد، هزینه_خانواده، پاداش`

ویژگی‌های زیر را بساز:
1️⃣ درآمد کل = درآمد + پاداش
2️⃣ نسبت هزینه به درآمد
3️⃣ log(درآمد کل)

سپس بررسی کن آیا ویژگی جدید با متغیر هدف (مثلاً رضایت مالی) ارتباط بهتری دارد یا خیر؟
