## 🧩 ۱. مرور روش‌ها به‌صورت خلاصه و کاربردی

| روش          | نوع      | توضیح کوتاه                      | مزایا            | معایب                       | مناسب برای          |
| :----------- | :------- | :------------------------------- | :--------------- | :-------------------------- | :------------------ |
| **Filter**   | آماری    | بدون نیاز به مدل                 | سریع، ساده       | نادیده گرفتن تعامل ویژگی‌ها | داده‌های زیاد و خام |
| **Wrapper**  | مدل‌محور | تست عملکرد مدل با ترکیب ویژگی‌ها | دقت بالا         | هزینه محاسباتی زیاد         | پروژه‌های کوچک      |
| **Embedded** | درون مدل | مدل خودش انتخاب می‌کند           | دقت بالا، خودکار | نیاز به مدل خاص             | پروژه‌های واقعی     |

---

## 🔎 ۲. تصمیم‌گیری در انتخاب روش

📘 *اگر سرعت مهم‌تر از دقت است* → Filter Methods
📘 *اگر دقت اولویت اصلی است* → Wrapper Methods
📘 *اگر با مدل‌های یادگیری ماشین واقعی کار می‌کنی (مثل Random Forest, XGBoost)* → Embedded Methods

---

## ⚙️ ۳. مثال عددی جامع

فرض کن داده‌ای با ۱۰۰ ویژگی داری، و می‌خواهی بهترین ویژگی‌ها را برای پیش‌بینی قیمت خانه‌ها انتخاب کنی 🏠

📍 **گام ۱:** استفاده از Filter برای حذف ویژگی‌های با همبستگی کمتر از ۰٫۱
📍 **گام ۲:** اجرای RFE با `LinearRegression` برای انتخاب ۱۰ ویژگی برتر
📍 **گام ۳:** آموزش مدل RandomForest برای بررسی اهمیت ویژگی‌ها و انتخاب ۵ ویژگی نهایی

💡 نتیجه:
ترکیب روش‌ها باعث می‌شود هم **سرعت بالا** باشد و هم **دقت نهایی عالی** 👌

---

## 💻 ۴. کد نمونه‌ی جامع

```python
import pandas as pd
from sklearn.datasets import load_boston
from sklearn.linear_model import LinearRegression
from sklearn.feature_selection import RFE
from sklearn.ensemble import RandomForestRegressor

# داده‌ی نمونه
X, y = load_boston(return_X_y=True)
df = pd.DataFrame(X)

# گام ۱: Filter - حذف ویژگی‌های کم‌ارتباط
corr = df.corrwith(pd.Series(y))
selected = corr[abs(corr) > 0.1].index
df = df[selected]

# گام ۲: Wrapper - انتخاب با RFE
model = LinearRegression()
rfe = RFE(model, n_features_to_select=10)
rfe.fit(df, y)
df = df[df.columns[rfe.support_]]

# گام ۳: Embedded - بررسی اهمیت در RandomForest
forest = RandomForestRegressor()
forest.fit(df, y)
importance = pd.Series(forest.feature_importances_, index=df.columns)

print("Top Features:\n", importance.sort_values(ascending=False))
```

📊 در خروجی، ۵ تا از مهم‌ترین ویژگی‌ها مشخص می‌شوند.

---

## 🧠 ۵. ترفندهای انتخاب ویژگی در پروژه‌های واقعی

💡 اگر داده‌ها نویز زیادی دارند → از روش‌های Embedded استفاده کن
💡 اگر هزاران ویژگی داری → اول Filter و بعد Wrapper
💡 برای مدل‌های عصبی → از LASSO یا Dropout برای انتخاب طبیعی ویژگی‌ها
💡 همیشه از **cross-validation** برای ارزیابی انتخاب ویژگی استفاده کن
