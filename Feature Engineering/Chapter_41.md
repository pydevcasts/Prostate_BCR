## 🔍 ۲. دو روش اصلی در Scaling

| نوع                    | نام انگلیسی     | توضیح کوتاه                                |
| :--------------------- | :-------------- | :----------------------------------------- |
| 📏 **Standardization** | Z-score scaling | تبدیل ویژگی‌ها به میانگین صفر و واریانس یک |
| 📉 **Normalization**   | Min-Max scaling | تبدیل داده‌ها به بازه‌ی مشخص مثل [0, 1]    |

---

## 📘 ۳. تفاوت استانداردسازی و نرمال‌سازی

| ویژگی              | Standardization                      | Normalization                                  |
| :----------------- | :----------------------------------- | :--------------------------------------------- |
| فرمول              | $$( z = \frac{x - \mu}{\sigma} )$$       | $$( x' = \frac{x - x_{min}}{x_{max} - x_{min}} )$$ |
| بازه خروجی         | -∞ تا +∞                             | معمولاً بین 0 تا 1                             |
| حساسیت به داده پرت | کمتر                                 | بیشتر                                          |
| مناسب برای         | الگوریتم‌های آماری مثل SVM، Logistic | شبکه‌های عصبی و kNN                            |

---

### 💬 مثال عددی

| مقدار اصلی | میانگین = 50 | انحراف معیار = 10 | Standardized | Normalized (min=0, max=100) |
| :--------: | :----------: | :---------------: | :----------: | :-------------------------: |
|     40     |      50      |         10        |      -1      |             0.4             |
|     50     |      50      |         10        |       0      |             0.5             |
|     70     |      50      |         10        |      +2      |             0.7             |

📈 می‌بینی؟
در روش Z-Score، داده‌ها حول صفر قرار می‌گیرن،
در روش Min-Max، به محدوده‌ی [0,1] فشرده می‌شن.

---

## 💻 ۴. مثال پایتون با هر دو روش

```python
import pandas as pd
from sklearn.preprocessing import StandardScaler, MinMaxScaler

data = pd.DataFrame({
    'Income': [20000, 35000, 50000, 80000, 100000],
    'Age': [20, 25, 30, 45, 60]
})

# Standardization
std_scaler = StandardScaler()
data_std = std_scaler.fit_transform(data)

# Normalization
minmax_scaler = MinMaxScaler()
data_norm = minmax_scaler.fit_transform(data)

print("🔹 Standardized:\n", pd.DataFrame(data_std, columns=data.columns))
print("\n🔹 Normalized:\n", pd.DataFrame(data_norm, columns=data.columns))
```
