## ⚙️ ۱. مفهوم Hash Encoding

در این روش، به جای ایجاد ستون جدید برای هر دسته (مثل One-Hot)،
هر مقدار متنی با استفاده از یک **تابع هش (Hash Function)** به عدد تبدیل می‌شه.

یعنی:
هر دسته به عددی یکتا **در یک بازه مشخص** نگاشت می‌شه.
این عدد معمولاً از طریق توابعی مثل `hash()` یا `md5` تولید می‌شه.

📘 مثال ساده:

| شهر    | Hash عددی |                           |
| :----- | :-------: | ------------------------- |
| تهران  |    183    |                           |
| تبریز  |    924    |                           |
| اصفهان |    582    |                           |
| مشهد   |    183    | ❗ (ممکنه تصادف هش رخ بده) |

---

## 💻 ۲. پیاده‌سازی Hash Encoding در پایتون

### ✳️ روش ساده با تابع `hash()`

```python
import pandas as pd

data = pd.DataFrame({
    'City': ['Tehran', 'Tabriz', 'Isfahan', 'Mashhad', 'Tehran']
})

# تعداد بکت‌ها (مثلاً 10 مقدار ممکن)
n_buckets = 10
data['City_hash'] = data['City'].apply(lambda x: hash(x) % n_buckets)

print(data)
```

📊 **خروجی احتمالی:**

```
      City  City_hash
0   Tehran          3
1   Tabriz          7
2  Isfahan          5
3  Mashhad          2
4   Tehran          3
```

🔹 مقدار hash ممکنه بین اجراها تغییر کنه (چون hash در هر سشن متفاوت تولید می‌شه).
🔹 برای پایداری، می‌تونی از Hash ثابت مثل `hashlib.md5()` استفاده کنی.

---

### ✳️ روش حرفه‌ای‌تر با کتابخانه `FeatureHasher`

```python
from sklearn.feature_extraction import FeatureHasher

data = [{'City': 'Tehran'}, {'City': 'Tabriz'}, {'City': 'Isfahan'}, {'City': 'Mashhad'}]
hasher = FeatureHasher(n_features=5, input_type='dict')
hashed = hasher.transform(data).toarray()

print(hashed)
```

📊 این خروجی یک **ماتریس فشرده‌ی عددی** با ابعاد دلخواه (تعداد feature تعیین‌شده) است.

## 🔍 ۳. مزایا و معایب

| مزایا                                     | معایب                                |
| :---------------------------------------- | :----------------------------------- |
| ✅ بسیار سریع و مقیاس‌پذیر                 | ⚠️ احتمال "Collision" (برخورد هش‌ها) |
| ✅ بدون نیاز به حفظ mapping بین دسته و عدد | ⚠️ غیرقابل تفسیر برای انسان          |
| ✅ مناسب برای میلیون‌ها مقدار متنی         | ⚠️ گاهی اطلاعات جزئی از بین می‌رود   |

---

## 💡 ۴. چه زمانی از Hash Encoding استفاده کنیم؟

🔸 وقتی داده‌ات بسیار بزرگه (مثل داده‌های کاربران، نام برندها، شناسه‌ها و ...)
🔸 وقتی تعداد دسته‌ها بیش از چند هزار تاست
🔸 زمانی که سرعت و حافظه از دقت مهم‌تره
🔸 در سیستم‌های آنلاین یا real-time (مثل پیشنهاد محصول در لحظه)

---

## 🎨 تصویر پیشنهادی

> دیاگرامی شامل بلوک‌های رنگی که از سمت چپ مقادیر متنی (Tehran, Tabriz, ...) وارد یک جعبه هش می‌شن
> و از سمت راست اعداد محدود (۰ تا ۹) خارج می‌شن.
> چند دسته مختلف به یک مقدار مشترک هش شده‌اند تا مفهوم Collision نمایش داده بشه.

---

### 💬 گفت‌وگوی استاد و دانشجو 🎓

👩‍🎓 استاد، اگه هش برخورد کنه چی؟ مثلاً دو شهر مقدار یکسان بگیرن؟
👨‍🏫 اون بهش می‌گن **Collision**، و اگر داده زیاد باشه اجتناب‌ناپذیره. ولی در داده‌های بزرگ ضررش ناچیزه.
👩‍🎓 پس بهتره تعداد featureها زیاد باشه؟
👨‍🏫 دقیقاً 👏 هرچقدر `n_features` بیشتر باشه، احتمال برخورد کمتر می‌شه.
