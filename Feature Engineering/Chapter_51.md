## 🧪 ۱. مفهوم Filter Methods

در این روش‌ها، بدون نیاز به هیچ مدل یادگیری، ویژگی‌ها با استفاده از **آزمون‌های آماری و معیارهای ریاضی** ارزیابی می‌شوند.

ویژگی‌هایی که **ارتباط بیشتری با متغیر هدف (Target)** دارند، نگه داشته می‌شوند
و بقیه حذف می‌گردند.

📘 مثل فیلتر کردن شن در الک: فقط ذرات مفید عبور می‌کنند.

---

## 🔍 ۲. انواع رایج روش‌های Filter

| روش                                           | نوع داده                       | توضیح                                  |
| :-------------------------------------------- | :----------------------------- | :------------------------------------- |
| 🔹 **Correlation Coefficient (ضریب همبستگی)** | داده‌های عددی                  | بررسی رابطه بین ویژگی و هدف            |
| 🔹 **Chi-Square Test (آزمون خی-دو)**          | داده‌های دسته‌ای (Categorical) | بررسی استقلال متغیرها                  |
| 🔹 **ANOVA (تحلیل واریانس)**                  | داده‌های عددی با هدف دسته‌ای   | بررسی تفاوت میانگین گروه‌ها            |
| 🔹 **Mutual Information (اطلاعات متقابل)**    | عددی و دسته‌ای                 | اندازه‌گیری وابستگی غیرخطی بین متغیرها |

---

## 💡 ۳. مثال عددی ساده

فرض کن دیتایی داری با این ویژگی‌ها:

| Age | Income | Height | Gender | Purchased |
| :-- | :----- | :----- | :----- | :-------- |
| 23  | 40000  | 175    | Male   | 1         |
| 45  | 80000  | 180    | Male   | 1         |
| 31  | 50000  | 168    | Female | 0         |
| 40  | 90000  | 185    | Male   | 1         |
| 22  | 35000  | 170    | Female | 0         |

می‌خواهیم ببینیم کدام ویژگی بیشترین ارتباط را با ستون **Purchased** دارد.

---

## 💻 ۴. پیاده‌سازی با Correlation در پایتون

```python
import pandas as pd

data = pd.DataFrame({
    'Age': [23, 45, 31, 40, 22],
    'Income': [40000, 80000, 50000, 90000, 35000],
    'Height': [175, 180, 168, 185, 170],
    'Purchased': [1, 1, 0, 1, 0]
})

# محاسبه همبستگی با هدف
corr = data.corr()['Purchased'].sort_values(ascending=False)
print(corr)
```

📊 **خروجی احتمالی:**

```
Purchased    1.00
Income       0.88
Age          0.65
Height       0.22
```

🔹 یعنی ویژگی **Income** بیشترین ارتباط را با خرید دارد → در مدل نگه می‌داریم.

---

## 📏 ۵. روش Chi-Square (برای داده‌های دسته‌ای)

```python
from sklearn.feature_selection import chi2, SelectKBest
import pandas as pd

data = pd.DataFrame({
    'Gender': [0, 0, 1, 0, 1],
    'Married': [1, 1, 0, 1, 0],
    'Purchased': [1, 1, 0, 1, 0]
})

X = data[['Gender', 'Married']]
y = data['Purchased']

selector = SelectKBest(score_func=chi2, k=1)
fit = selector.fit(X, y)

print("Scores:", fit.scores_)
print("Selected Feature:", X.columns[fit.get_support()][0])
```

📈 **نتیجه:**
اگر `Married` نمره بالاتری بگیرد، یعنی وضعیت تأهل بیشترین تأثیر را دارد.

---

## 🎯 ۶. روش ANOVA برای داده‌های عددی با هدف دسته‌ای

```python
from sklearn.feature_selection import f_classif, SelectKBest

X = data[['Age', 'Income', 'Height']]
y = data['Purchased']

anova_selector = SelectKBest(score_func=f_classif, k=2)
X_selected = anova_selector.fit_transform(X, y)

print("ANOVA Scores:", anova_selector.scores_)
```

📊 **خروجی:**
بیشترین مقدار نمره → ویژگی مؤثرتر روی خرید.

## ⚙️ ۷. مزایا و معایب Filter Methods

| مزایا                      | معایب                                           |
| :------------------------- | :---------------------------------------------- |
| ✅ سریع و مستقل از مدل      | ⚠️ فقط وابستگی تکی ویژگی‌ها را بررسی می‌کند     |
| ✅ مناسب برای داده‌های حجیم | ⚠️ تعامل بین ویژگی‌ها را نمی‌سنجد               |
| ✅ قابل‌فهم و ساده          | ⚠️ ممکن است برخی ویژگی‌های ترکیبی مفید حذف شوند |
